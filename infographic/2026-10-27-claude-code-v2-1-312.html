Claude Code v2.1.312

OIDC 認証の柔軟化とクリックで送信機能の追加、多数の不具合修正を含むリリース

📅 2026-10-27 | ソース: Claude Code Changelog

概要

🔑

oidc.user_id_claim の追加

Claude apps gateway で、Microsoft Entra ID の oid など sub 以外の id_token クレームでユーザーを識別できるようになった。

🖱️

クリックで送信

フルスクリーン表示で、キュー済みメッセージの「to send now」ヒントをクリックすると、対応するキーと同様に即時送信できる。

🛡️

巨大な CLAUDE.md の上書き防止

冒頭部分しか読んでいない状態での上書きを防止。Write ツールが全体を読むか、その場で編集するよう Claude に求めるようになった。

⚙️

未認識モデル名への短縮システムプロンプト

Bedrock / Vertex / Foundry / Mantle で、カスタムデプロイ名や推論プロファイル ARN に短いシステムプロンプトを使用するよう変更。

🔀

フックの同時実行数制限

プロンプト / エージェントフックの同時実行数を、サブエージェントを含めセッションあたり最大 24 に制限。

主要変更

✨ Added (新機能)

🔑 oidc.user_id_claim

Claude apps gateway に追加。Microsoft Entra ID の oid のように、sub 以外の id_token クレームでユーザーを識別できる。

🖱️ クリックで送信

フルスクリーン表示で、キュー済みメッセージの下に表示される「to send now」ヒントをクリックすると、そのメッセージを即時送信できる。

🔧 Fixed (修正)

🏢 managed settings 取得

VS Code 拡張機能からサインインした後、そのセッションの残りの間 managed settings と組織ポリシーが取得されない問題を修正。

📄 巨大ファイルの上書き防止

非常に大きな CLAUDE.md、rules ファイル、@-included ファイルを冒頭しか読まずに上書きしてしまう問題を修正。

📁 スキルが見つからない問題

git リポジトリ内で Bash の cd により深い階層へ移動した後、ディレクトリ単位および paths: 指定のスキルが見つからない問題を修正。

⌨️ vim モードの挙動

d、c、y に残り行数より大きいカウント付きの gj / gk を組み合わせるとテキストを削除またはコピーしてしまう問題を修正。

🖥️ claude -p の出力なし

無効な名前のコマンドがすべてのコマンドの読み込みを停止させ、claude -p が出力なしになることがある問題を修正。

ほか、セッション再開時の返信欠落、PDF 読み込みエラー、effort レベル表示など多数の修正あり

🔄 Changed (動作変更)

📝 短縮システムプロンプト

Bedrock / Vertex / Foundry / Mantle で、未認識のモデル名に短いシステムプロンプトを使用。CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0 で従来動作を維持できる。

🔁 自動モデル切り替えの拡大

フラグされたメッセージ後の自動モデル切り替えが、カスタムデプロイ名など未認識のモデル名もカバー。CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1 で無効化できる。

🔀 フック同時実行制限

プロンプト / エージェントフックはセッションあたり最大 24 並列。タイムアウト超過待機分は最大 12。1 秒未満の timeout は 1 秒として扱われる。

⏱️ 「5-hour limit」表記

使用量制限メッセージで、5 時間ウィンドウを「session limit」ではなく「5-hour limit」と呼ぶよう変更。

📊 OpenTelemetry の変更

mcp_server.name が公式マーケットプレイスプラグインの固定 URL リモート MCP サーバーの実際の名前を報告。claude_code.safety_event の送信は停止。

コンポーネント別の改善

💻 VSCode

組織設定の読み込み失敗時にタブへ理由を表示し、Retry または再サインインを選択可能に。使用量制限のリセット表示を時刻表示 ("Resets at 3:10 PM") に変更。

☁️ Cloud sessions

ルーティンのモデルピッカーに effort レベルを追加。セットアップスクリプト欄に Bash エディターを追加。リポジトリ追加時のステップ表示を改善。再送信の重複実行やエラー表示の問題を修正。

🎮 Remote Control

アーカイブ解除したセッションが再接続まで作業中として表示される問題を修正。アイドルとして表示されるようになった。

🏷️ Claude Tag

Slack のリトライ通知でモデル名やレート制限到達を表示。チャンネル ID 変更時の設定リセット、ネットワークアクセス None 環境での無応答、誤ったスレッドへのファイル投稿を修正。

🔍 Code Review

GitHub の push イベント遅延時に古いコミットをレビューする問題を修正。プルリクエストの現在のコミットをレビューするようになった。

技術詳細

🔑 OIDC 認証の柔軟化

oidc.user_id_claim により、Microsoft Entra ID など sub 以外のクレームを使う IdP との統合が容易になる。

flowchart LR
    IdP["🏢 IdP
Microsoft Entra ID など"] -->|"id_token"| GW["🔌 Claude apps gateway"]
    GW --> Claim{"🔑 oidc.user_id_claim"}
    Claim -->|"デフォルト"| Sub["sub クレーム"]
    Claim -.->|"カスタム指定"| Oid["oid など任意のクレーム"]
    Sub --> User(["👤 ユーザー識別"])
    Oid --> User

⚙️ 動作を制御する環境変数

サードパーティプラットフォームでの動作変更は、以下の環境変数で制御できる。

Bash 環境変数の設定例 
# Bedrock / Vertex / Foundry / Mantle の未認識モデル名に対し
# 従来のフルシステムプロンプトを維持する
export CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0

# フラグされたメッセージ後の自動モデル切り替えを無効化する
export CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1

# サブエージェントの autoCompactWindow の引き下げに対応
# (引き上げは引き続き行われない)
export CLAUDE_CODE_AUTO_COMPACT_WINDOW=<value>

🔀 フックの同時実行制限

プロンプト / エージェントフックはセッションあたり最大 24 並列 (サブエージェント含む)。イベントのタイムアウトより長く待機したものは最大 12 に制限される。

ユースケース

🏢 Microsoft Entra ID と連携するエンタープライズ管理者

Claude apps gateway の oidc.user_id_claim を設定することで、sub ではなく oid などの id_token クレームでユーザーを識別でき、既存の ID 基盤との統合が容易になる。

☁️ Bedrock / Vertex / Foundry / Mantle でカスタムデプロイを使うユーザー

カスタムデプロイ名や推論プロファイル ARN に対して短縮システムプロンプトが適用される。従来のフルプロンプトが必要な場合は CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0 を設定する。

🔀 多数のフックを並列実行する構成のユーザー

セッションあたり最大 24 の同時実行制限が導入されたため、プロンプトフック / エージェントフックを多数利用する構成では制限の影響を確認する。
