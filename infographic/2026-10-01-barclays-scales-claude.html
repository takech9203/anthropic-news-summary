🏦 Barclays が Claude を全社規模に拡大

英国のユニバーサルバンク Barclays が Anthropic との戦略的協業を拡大し、セキュアなエンタープライズ級 AI をグローバル業務全体に統合。業務変革と顧客体験向上を推進

📅 2026-10-01 ｜ ソース: Anthropic News

概要

Barclays は Anthropic との戦略的協業を拡大し、セキュアなエンタープライズ級 AI をグローバル業務全体に統合すると発表しました。規制の厳しい大規模金融機関における AI 実用化の重要なマイルストーンです。

💻

Claude Code を 2026 年末までに開発者の 50% が採用見込み

2027 年にはソフトウェアエンジニアの過半数へ展開予定。レガシーシステムの近代化、ソフトウェア品質向上、業務効率の改善を目的としています。

💬

Colleague Knowledge Assistant が本番稼働中

英国リテール部門で 16,000 人以上の従業員が利用し、100 万件以上の検索を処理。2,000 万人超の英国リテール顧客へのサポートを迅速化しています。

📨

Global Markets 業務で 1 日約 12 万件のメール処理

受信メールの分類、情報付加、最適な処理ルートの判定に Claude を活用し、手作業の削減と関連情報の迅速な特定を実現しています。

🛡️

責任ある AI 展開の枠組み

堅牢なガバナンス、セキュリティ管理、人間による監督を適用。規制の厳しい大規模組織での導入には技術力と規律あるガバナンスの両方が必要との認識を両社で共有しています。

🔄

単なる技術採用ではなく業務変革

Barclays グループ共同 COO の Anne Marie Darling 氏は、プロセスの再構築と顧客・クライアント体験の向上を目指すと位置づけ。定型業務の削減により、従業員はより複雑な問題解決に注力できるようになります。

背景

Barclays は 2,000 万人超の英国リテール顧客を抱える世界最大級の金融機関であり、規制の厳しい金融業界において AI 導入には技術力と規律あるガバナンスの両方が求められます。本発表は、2025 年から稼働している既存のユースケースでの実績を基盤に、Anthropic との協業を全社規模へと拡大するものです。

  2. エンタープライズアーキテクト: RAG アーキテクチャによるナレッジ検索基盤や、大量メール処理のユースケース設計パターンを検討する
  3. Claude Code 導入検討者: レガシーシステム近代化やソフトウェア品質向上の適用例として、段階的な展開計画 (開発者の 50% → 過半数) を参考にする

🔀 移行ガイド: 同様の導入を検討する場合のステップ

本発表はビジネスパートナーシップの拡大であり、一般の開発者に技術的な移行作業は不要です。金融業界で同様の導入を検討する場合は、以下のステップが参考になります。

  1. 特定部門での限定的なユースケースから開始する (例: ナレッジ検索、メール処理)
  2. ガバナンス、セキュリティ管理、人間による監督の体制を整備する
  3. 実績を基に Claude Code などの開発者向けツールを段階的に展開する
  4. 全社規模への拡大と長期的な業務変革ロードマップを策定する

ユースケース

💬 従業員向けナレッジ検索基盤 (RAG アーキテクチャ)

英国リテール部門の Colleague Knowledge Assistant は、Claude を用いた RAG (検索拡張生成) アーキテクチャで 16,000 人以上の従業員のナレッジ検索を支え、100 万件以上の検索を処理。2,000 万人超の英国リテール顧客へのサポートを迅速化しています。社内ナレッジ基盤を構築するチームの設計パターンとして参考になります。

📨 大量メールのインテリジェント処理

Global Markets 業務では、受信メールの分類、情報付加、最適な処理ルートの判定に Claude を活用し、1 日あたり約 12 万件のメールを処理。手作業の削減と関連情報の迅速な特定を実現しており、大量ドキュメント処理のエージェント型ワークフロー設計の実例となっています。

💻 Claude Code によるレガシーシステム近代化

2026 年末までに開発者の 50%、2027 年にはソフトウェアエンジニアの過半数へと段階的に Claude Code を展開し、レガシーシステムの近代化、ソフトウェア品質向上、業務効率の改善を進めます。大規模組織での AI 支援開発の普及モデルとして参考になります。

まとめ

Barclays と Anthropic の協業拡大は、規制の厳しい金融業界におけるエンタープライズ AI 導入の成熟を示す発表です。以下の 3 つの観点で特に重要な意義を持ちます。

  1. 実証済みのユースケースを基盤とした拡大: 2025 年から稼働する Colleague Knowledge Assistant (16,000 人以上が利用、100 万件以上の検索) や、1 日あたり約 12 万件のメール処理という具体的な実績を基に全社展開へ進んでおり、パイロット段階を超えた本番運用の成功事例となっています
  2. 開発者組織への段階的展開: Claude Code を 2026 年末までに開発者の 50%、2027 年にはソフトウェアエンジニアの過半数へ展開するという明確なロードマップは、大規模金融機関における AI 支援開発の普及モデルを示しています
  3. 責任ある AI 展開の枠組み: 堅牢なガバナンス、セキュリティ管理、人間による監督を組み合わせたアプローチは、規制産業で AI を大規模導入する際のベストプラクティスとして、他の金融機関にとっても参考になります

Anthropic にとって本提携は英国市場における重要なマイルストーンであり、フロンティア AI 能力と責任あるイノベーションの組み合わせが、世界最大級の金融機関の業務変革を支える段階に到達したことを示しています。
