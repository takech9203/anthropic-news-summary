概要

🖥️

VSCode に Focus view を追加

ツールアクティビティを展開可能なターンごとのサマリーの背後に隠し、チャットの可読性を大きく向上。Ctrl+Alt+F で切り替え可能

サンドボックス認証情報の mask モード

Linux/WSL で、サンドボックス内のコマンドにはセンチネル (ダミー値) を見せ、外部送信時のみプロキシが実際の値へ置換。認証情報の露出を防ぐ

🔒

zsh 権限チェックバイパスのセキュリティ修正

zsh の [[ ]] 正規表現条件式に隠されたコマンドが権限チェックをすり抜ける問題を修正。速やかなアップデートを推奨

🌿

バックグラウンドセッションの Git 動作変更

常にドラフト PR を開くのではなく、コミットとプッシュで作業を保全し、タスクが必要とする場合のみドラフト PR を作成するように変更

⚡

プロンプトキャッシュコストの削減と多数の修正

auto モードの権限チェックがキャッシュ効率の良い方式になりコストを削減。Vim モード、MCP、Bedrock 認証など多数の修正も含まれる

セキュリティ修正

🚨

Bash ツールの権限チェックバイパス修正 (zsh)

zsh では [[ string =~ pattern ]] のような条件式の評価中にコマンド置換などが実行される可能性があり、これが権限チェックの解析対象から漏れていた。修正後は、該当するコマンドに権限プロンプトが表示される。サンドボックスや権限設定でコマンド実行を制御している環境では重要な修正であり、速やかなアップデートを推奨する。

  • 🪟PowerShell の権限チェック修正: Windows で引用符を含むパスの権限チェックが誤って処理される問題を修正

主要機能

🖥️ VSCode Focus view

ツールアクティビティを展開可能なターンごとのサマリーの背後に隠すチャットメニューのトグル。実行中のツールはライブインジケーターで表示。Ctrl+Alt+F または「Claude Code: Toggle Focus view」コマンドで切り替え。

🎭 認証情報 mask モード

Linux/WSL でサンドボックス化されたコマンドはセンチネルのコピーを読み取り、サンドボックスプロキシが外部送信時に実際の値へ置換。macOS では deny にフォールバック。

🌿 バックグラウンドセッションの Git 動作

作業を保全するためにコミットとプッシュを行い、タスクが必要とする場合のみドラフト PR を開くように変更。不要なドラフト PR の量産を防止。

🔍 claude plugin validate の警告

マーケットプレイスまたはプラグイン名が Claude Desktop のマネージドマーケットプレイス同期で拒否される場合に警告を表示。

📋 claude-api スキルの prompt-audit

旧世代モデル向けに書かれたパターンがないか、プロンプトとツール説明を監査するサブコマンドが追加された。

  • 調査タスクでも PR が作成される

技術詳細

🎭 mask モードにおけるサンドボックスプロキシの動作

従来はアクセスの許可か拒否 (deny) の二択だったが、mode: "mask" ではサンドボックス内のプロセスやその出力に実際の認証情報を露出させることなく、認証が必要な外部通信を成立させられる。

JSON .claude/settings.json - mask モード設定 
{
  "sandbox": {
    "credentialFiles": [
      {
        "path": "~/.npmrc",
        "mode": "mask"
      }
    ]
  }
}

この設定により、Linux/WSL ではサンドボックス化されたコマンドは ~/.npmrc のセンチネルコピーを読み取り、サンドボックスプロキシが外部送信時に実際の値へ置換する。macOS では deny として動作する。

バグ修正

  • 🧠思考トグル: 思考オフで開始したセッションで、セッションの残りの間トグルが効かない問題を修正
  • 🔌print モードの MCP 接続: --mcp-config の MCP サーバーが -p の最初のターンの前に接続されない問題を修正
  • 📎@ メンションファイル: Esc で取り消して再送信した際に @ メンションファイルが暗黙的に破棄される問題を修正
  • 💥SDK MCP ツールのクラッシュ: constructor などの組み込みプロパティと同名のツールでクラッシュする問題を修正
  • 🔎WebSearch の 400 エラー: 思考無効時に effort xhigh/max で失敗する問題を修正
  • 📤サンドボックスの大容量アップロード: プロキシ経由の大容量アップロードが TLS エラーで失敗する問題を修正
  • 📊利用上限メッセージ: Team/Enterprise で誤って組織の月次上限を原因として表示する問題を修正
  • ☁️Bedrock 認証: Windows のデスクトップ管理セッションで AWS SSO の名前付きプロファイル認証が失敗する問題を修正
  • ⏸️中断ターン自動再開: CLAUDE_CODE_RESUME_INTERRUPTED_TURN=0 が無効化されない問題を修正
  • 😴スリープ復帰時の競合: 2 つのプロセスが同じ MCP コネクタや WIF OAuth トークンを同時に更新し得る競合を修正
  • 🔄セッション名同期: Claude Code Desktop や claude.ai からの名前変更が CLI に反映されない問題を修正
  • 🧩スキル呼び出し: 組み込み機能と同名のプラグイン/組織配布スキルが非対話セッションで呼び出せない問題を修正
  • 🔔プラグイン通知: リロード後も「Plugins changed」通知が残り続ける問題を修正
  • ⌨️Vim モード (2 件): ヤンクレジスタがダイアログ・履歴検索・トランスクリプトビューをまたいで保持。空プロンプトまで undo した際の確認も有効化

改善と動作変更

⚡ 改善

  • 🔧Google Vertex AI のツール検索: Claude 4.5 世代以降のモデルでツール検索が再有効化
  • 💰auto モードの権限チェック効率化: キャッシュ済みの会話プレフィックスを再利用し、プロンプトキャッシュのコストを削減
  • 📈Stats パネル: トークン合計にキャッシュトークンが内訳付きでカウント
  • 📝/ultrareview: リポジトリがベースと履歴を共有しない場合のエラーメッセージを改善
  • 🚀Windows 起動の高速化: プロセス作成時刻の取得をネイティブの kernel32 呼び出しに変更

🔀 動作変更

  • 🧩/plugin install: 古いマーケットプレイスカタログを更新してリトライ。インストールしたプラグインは安全な場合は即座に有効化。"." を skills パスとして受け付け
  • 📟/status: セッションの種類 (interactive、または attached/unattended のバックグラウンドジョブ) を表示
  • 😀絵文字オートコンプリート: 一般的な代替ショートコードを受け付け
  • 🌱/fork: フォークしたセッションは独自の新しい worktree を作成
  • 🌐Claude in Chrome: 開いたブラウザタブが不要になったら閉じるように変更
  • ⚡fast モード: セッション中に利用クレジットが尽きた際、ストリーム上で報告
  • 👀Monitor: 出力を生成せずに終了した watch はその旨を表示
  • 🛂Gateway: model フィールドに文字列以外の値を指定すると 400 エラーで拒否
  • 🔕通知の削除: auto モード分類器のキュー中に表示される繰り返し通知を削除

ユースケース

🖥️

VSCode でコードに集中したい開発者

ツール実行ログが大量に流れるチャットで Focus view を有効にすれば、各ターンのサマリーだけが表示され、会話の流れを追いやすくなる。詳細が必要なときはサマリーを展開して確認できる。

🔐

Linux/WSL で認証情報を扱うサンドボックス運用

deny にしていた ~/.npmrc などの認証情報ファイルを mask に変更すれば、サンドボックス内に実際の値を露出させることなく npm install などの外部通信を成立させられる。

🤖

バックグラウンドセッションでの調査・実験タスク

調査タスクや実験的な変更では不要なドラフト PR が作成されなくなり、コミットとプッシュで作業が保全される。PR 作成を前提とするワークフローでは、タスク指示に PR 作成を明記する。
