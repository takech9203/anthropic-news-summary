Claude Code v2.1.222: worktree 分離の強化とバックグラウンドタスクの権限修正

2026-08-04

v2.1.222 🔒 セキュリティ修正あり

概要

🌿

worktree 分離の強化

分離セッションとそのサブエージェントがメインチェックアウトへ破壊的な git コマンドを実行できてしまう問題を修正。分離はすべてのセッション種別でファイル編集と Bash に適用される

🪝

PreToolUse auto-allow フックのバイパス修正

サマリー生成、コンパクション、リネームなどのバックグラウンドエージェントタスクで、auto-allow フックがツール制限をバイパスできてしまう問題を修正

🛡️

auto モードの安全性向上

SendMessage で他のエージェントセッションへ送信されるメッセージが、送信前に権限分類器で評価されるようになった

🔧

プロキシ・ゲートウェイ環境の安定性向上

HTTPS プロキシ背後での起動時接続チェックのハング、カスタム ANTHROPIC_BASE_URL ゲートウェイでのストリームアイドルタイムアウトなどを修正

📊

/usage の帰属精度改善と ultraplan の削除

MCP サーバーへの使用量の過剰帰属を修正し、実際にツール結果を消費したリクエストのみを反映。ultraplan 機能は削除された

セキュリティ修正

🚨

worktree 分離セッションからの破壊的 git コマンドを遮断

worktree はメインの作業ディレクトリと同じ .git リポジトリを共有するため、修正前は分離セッションやそのサブエージェントが git reset --hard や git checkout のような破壊的な git コマンドをメインチェックアウトに対して実行できてしまう経路が存在した。v2.1.222 では、分離がファイル編集と Bash の両方に対して、すべてのセッション種別 (サブエージェントを含む) で一貫して適用される。

🪝

バックグラウンドタスクでのツール制限をフックより優先

PreToolUse の auto-allow フックは権限プロンプトなしにツール実行を許可できるが、修正前はこの判定がバックグラウンドエージェントタスク (サマリー生成、コンパクション、リネーム) のツール制限より優先され、本来使えないはずのツールを実行できる可能性があった。修正後は、ツール制限がフックの判定に関係なく適用される。

主要な変更点

🌿 worktree 分離の強化

分離セッションとサブエージェントからメインチェックアウトを破壊する経路を遮断。ファイル編集と Bash の両方に、すべてのセッション種別で分離を適用。

🪝 フックバイパスの修正

バックグラウンドエージェントタスクにおいて、PreToolUse の auto-allow フックよりツール制限を優先。制限された文脈での想定外のツール実行を防止。

🛡️ SendMessage の権限分類

auto モードで、他のエージェントセッションへ送信されるメッセージを送信前に権限分類器で評価。エージェント間の指示の連鎖を通じた制御の迂回に防御層を追加。

📄 /diff ビューの改善

/diff ビュー、Remote Control のワークスペース diff、Claude Code on the web の diff が、diff ドライバーや textconv を無視して生の git blob コンテンツを使用。

📱 Remote Control 自動起動のスコープ変更

リポジトリローカル設定からの自動起動の有効化を廃止 (無効化は引き続き可能)。クローンしただけで意図せず有効化されることを防止。有効化は /config から。

Before / After: 分離と権限の境界

Before - v2.1.221 まで

  • 分離セッションからメインチェックアウトへ破壊的 git コマンドを実行できる経路が存在
  • auto-allow フックがバックグラウンドタスクのツール制限をバイパス可能
  • SendMessage のメッセージは権限分類器の評価対象外
  • リポジトリローカル設定で Remote Control の自動起動を有効化可能

After - v2.1.222

  • 分離をすべてのセッション種別でファイル編集と Bash に適用
  • ツール制限がフックの判定に関係なく適用される
  • SendMessage のメッセージを送信前に権限分類器で評価
  • 自動起動の有効化はユーザースコープの /config のみ (無効化は引き続き可能)

🛡️ auto モードにおける SendMessage の権限分類

マルチエージェント構成では SendMessage ツールでエージェントセッション間のメッセージ交換ができる。修正前は送信されるメッセージ自体が権限分類器の評価対象外だったが、v2.1.222 からは送信前にメッセージ内容が評価され、危険な指示が他のエージェントセッションへそのまま渡ることを防げる。あわせて、長いサマリーが拒否される問題も修正され、文字数制限を超えた場合は切り詰められるようになった。

📄 /diff ビューでの生の git blob コンテンツの使用

git では .gitattributes などでカスタム diff ドライバーや textconv を設定でき、git diff の出力を変換できる。Claude Code の diff 表示がこれらの変換に依存すると、実際のファイル内容と表示される差分が一致しない可能性があるため、v2.1.222 ではこれらを無視して生の git blob コンテンツを使用する。表示される差分は常にファイルの実際の変更内容を反映する。

バグ修正

  • 💳/usage-credits: Team/Enterprise で、以前のリクエストが却下されたメンバーが新しい利用クレジットリクエストを送信できない問題を修正
  • 🌐HTTPS プロキシ環境の起動時接続チェック: プロキシ背後でハングした後に失敗する問題を修正。API リクエストと同じプロキシ対応トランスポートを使用し、明確なメッセージとともにタイムアウト
  • 🔌Connection closed mid-response: 実際には完了していたレスポンスにエラーが報告される問題を修正
  • 📊/usage の MCP サーバー帰属: 呼び出し以降のすべてのターンではなく、ツール結果を実際に消費したリクエストのみを反映するように修正
  • 🔀プルリクエストとのセッション連携: ブランチのプッシュ後に作成された PR (GitHub REST API 経由を含む) にセッションがリンクされない問題を修正
  • 🤖モデルファミリーエイリアスのステップダウン: 組織で制限された model: opus のようなエイリアスが、親モデルへのフォールバックではなく、許可された同ファミリーの最新モデルへ正しくステップダウン
  • ⏱️カスタムゲートウェイのストリームアイドルタイムアウト: キープアライブ ping が届いているにもかかわらずタイムアウトが発生する問題を修正
  • 🔑claude.ai コネクタ: セッショントークンが無効な場合に誤って「認可が必要」と表示される問題を修正。代わりに /login のヒントを表示
  • 🧰利用不可ツールのエラー表示: MCP サーバーの削除後など、ローカルで利用できなくなったツールのエラーが表示されない問題を修正
  • ✉️SendMessage の長いサマリー: 拒否される問題を修正。文字数制限を超えた場合は切り詰められ、送信が失敗しなくなった
  • 🏷️サブエージェントの effort 表示: スピナーがサブエージェント自身の effort: 設定ではなくセッションの effort レベルを表示する問題を修正
  • 💥ファイルウォッチャーのクラッシュ: ファイルシステムエラー遭遇時や、ティアダウン中にまれに発生するクラッシュを修正
  • 🗣️スクリーンリーダーの読み上げ: --ax-screen-reader モードでバックスペースのたびに入力行全体が再読み上げされる問題を修正。行末での削除は削除した文字だけをエコー
  • 🖥️ホストのモデル選択キー: CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST 設定時に、古いディスク上の managed-settings.json より優先されない問題を修正

ユースケース

🌿

worktree 分離での並行作業

分離セッションやサブエージェントに並行作業させている間も、メインチェックアウトの作業状態が破壊される心配がなくなった。分離はファイル編集と Bash の両方に一貫して適用されるため、安心して複数タスクを同時に走らせられる。

🪝

PreToolUse フックで auto-allow を運用する管理者

auto-allow フックを設定していても、サマリー生成やコンパクションなどのバックグラウンドタスクではツール制限が確実に適用される。フック経由で制限が緩んでいないか個別に確認する必要がなくなった。

🤖

SendMessage を使うマルチエージェント構成

auto モードで複数のエージェントセッションを連携させる場合も、エージェント間のメッセージが送信前に権限分類器で評価されるため、危険な指示の連鎖による制御の迂回を防げる。

まとめ

🎯

分離と権限の境界を厳密にしたセキュリティ重点リリース

worktree 分離がすべてのセッション種別でファイル編集と Bash に適用され、メインチェックアウトを破壊する経路が塞がれた。PreToolUse auto-allow フックのバイパス修正と SendMessage の権限分類により、フックやエージェント間通信を通じた制限の迂回に対する防御も強化された。プロキシ環境やカスタムゲートウェイでの安定性向上、/usage の帰属精度改善、アクセシビリティの改善も含まれるため、全ユーザーに速やかなアップデートを推奨する。
