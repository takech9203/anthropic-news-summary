Claude API

🛠️ Admin API が ant CLI と 7 言語の SDK で利用可能に

📅 2026-08-26 | Claude Platform Release Notes

組織管理の自動化が、curl の独自実装から型付きクライアントとコマンドラインへ。推論系 API と同じクライアントで組織を管理できるようになりました。

📌 概要

📦

7 言語 SDK + ant CLI 対応

Admin API が Python、TypeScript、C#、Go、Java、PHP、Ruby の SDK と ant CLI から利用可能に。SDK は client.beta.organization、CLI は ant beta:organization の名前空間で提供されます。

🗂️

幅広いリソースをカバー

組織情報、メンバー、招待、ワークスペースとワークスペースメンバー、API キー、レート制限、サービスアカウント、WIF 発行者・ルール、顧客管理暗号鍵 (CMK) が対象です。

🔐

2 種類の認証を自動読み込み

Admin API キー (ANTHROPIC_API_KEY) または org:admin スコープの OAuth ベアラートークン (ANTHROPIC_AUTH_TOKEN) を環境変数から自動的に読み込みます。

🔁

自動ページネーション

Python、TypeScript、C#、Go、Java の SDK では、リストメソッドが追加ページを自動取得するイテレーターを返し、手動ページネーションが不要になります。

🌀

一部エンドポイントは curl のみ

使用量・コストレポートおよび Claude Enterprise のユーザー管理・分析エンドポイントは、引き続き curl のみの対応です。

🔄 Before / After

Before

  • Admin API の操作は curl などで REST エンドポイントを直接呼び出す必要があった
  • エラーハンドリング、ページネーション、型安全性をチームごとに作り込む負担
  • 組織管理の自動化における障壁に

After

  • 7 言語の型付き SDK と ant CLI から組織管理を自動化
  • 推論系 API と同じクライアントで組織管理も実行可能
  • 自動ページネーションと型安全性を標準で利用できる

✨ 主な機能

⌨️ ant CLI 対応

ant beta:organization 名前空間で、メンバー管理や API キー監査などの組織管理操作をコマンドラインから実行できます。--limit オプションで一覧結果の上限を指定可能です。

📦 7 言語の型付き SDK

Python、TypeScript、C#、Go、Java、PHP、Ruby の公式 SDK で client.beta.organization 名前空間を提供。型安全なクライアントで組織管理ツールを構築できます。

🔁 自動ページネーション

Python、TypeScript、C#、Go、Java のリストメソッドは追加ページを自動取得するイテレーターを返します。limit は合計件数ではなくページサイズの指定です。PHP、Ruby と curl は 1 ページ分を返します。

🤖 サービスアカウント / WIF

WIF トークンが行動する非人間 ID (サービスアカウント) の作成・管理、OIDC 発行者の登録、トークンとサービスアカウントのマッピング管理に対応。CI などの非対話ワークロードで自動トークン交換を利用できます。

🔑 API キー管理と CMK

API キーの一覧取得、名前変更、有効化・無効化、レート制限の読み取り、顧客管理暗号鍵 (CMK) の管理をサポートします。

🔐 認証 (2 種類のクレデンシャル)

SDK と CLI のデフォルトクライアントは、環境変数から自動的にクレデンシャルを読み込みます。

クレデンシャル 環境変数 送信ヘッダー 発行できるロール
🔑 Admin API キー (sk-ant-admin...) ANTHROPIC_API_KEY x-api-key admin ロールを持つ組織メンバーのみ
🎫 OAuth ベアラートークン (org:admin スコープ) ANTHROPIC_AUTH_TOKEN authorization: Bearer admin、owner、primary owner ロールのメンバー
⚠️ OAuth トークン限定のエンドポイント サービスアカウント、WIF 発行者、WIF ルールのエンドポイントは org:admin OAuth トークンのみを受け付けます (Admin API キーでは不可)。ベアラートークンを使用する場合は、同じシェルで ANTHROPIC_API_KEY を未設定にしておきます。

OAuth トークンは ant CLI で専用プロファイルにログインして取得します。

Bash OAuth トークンの取得 
ant auth login --profile admin --scope "org:admin"
export ANTHROPIC_AUTH_TOKEN=$(ant auth print-credentials --profile admin --access-token)
💡 トークンの更新 対話的に取得したトークンは短命であり、401 が返り始めたら export コマンドを再実行して更新します。CI などの非対話ワークロードでは、WIF による自動トークン交換を利用できます。

🔁 ページネーションの挙動

  • Python、TypeScript、C#、Go、Java の SDK: リストメソッドは、必要に応じて追加ページを自動取得するイテレーターを返す。limit は合計件数ではなくページサイズを指定する
  • PHP、Ruby の SDK と curl: 1 ページ分を返す
  • CLI: --limit がメンバー、招待、ワークスペース、ワークスペースメンバー、API キーの一覧結果の上限として機能する

💻 コード例

🏛️ 組織情報の取得

Bash CLI 
ant beta:organization retrieve
Python SDK 
import anthropic

client = anthropic.Anthropic()  # ANTHROPIC_API_KEY または ANTHROPIC_AUTH_TOKEN を自動で読み込む

organization = client.beta.organization.retrieve()
print(f"id: {organization.id}")
print(f"name: {organization.name}")

👥 メンバー一覧の取得

Bash CLI 
ant beta:organization:users list --limit 10
TypeScript SDK (自動ページネーション) 
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();

const users = await client.beta.organization.users.list({ limit: 10 });

// 必要に応じて追加ページを自動取得する
for await (const user of users) {
  console.log(`${user.id}: ${user.email} (${user.role})`);
}

✉️ 招待の作成

Bash CLI 
ant beta:organization:invites create --email user@example.com --role developer
Go SDK 
client := anthropic.NewClient()

invite, err := client.Beta.Organization.Invites.New(context.Background(), anthropic.BetaOrganizationInviteNewParams{
	Email: "user@example.com",
	Role:  anthropic.BetaOrganizationInviteNewParamsRoleDeveloper,
})
if err != nil {
	log.Fatal(err)
}

fmt.Printf("id: %s\n", invite.ID)
fmt.Printf("status: %s\n", invite.Status)

🎯 ユースケース

🏢 オンボーディング・オフボーディングの自動化

IT チームは、招待の作成、メンバーのロール変更・削除、ワークスペースメンバーの追加・削除を、使い慣れた言語の型付きクライアントや CLI から自動化できます。

🔑 API キーの監査・ローテーションのスクリプト化

管理者は、ワークスペースごとの API キー一覧の取得、名前変更、有効化・無効化を SDK / CLI でスクリプト化し、監査やローテーションの運用を効率化できます。

🌐 WIF を利用した CI / 自動化ワークロード

プラットフォームチームは、サービスアカウントと WIF 発行者・ルールを管理し、CI などの非対話ワークロードで WIF による自動トークン交換を利用した組織管理を構築できます。

🔌 API 変更点

📦 対応 SDK / CLI 一覧

⌨️ ant CLI 🐍 Python 🟦 TypeScript 🎼 C# 🐹 Go ☕ Java 🐘 PHP 💎 Ruby

7 言語すべての SDK で client.beta.organization 系の名前空間が追加され、CLI では ant beta:organization コマンド群が利用できます。

🛠️ 必要なアクション

  1. SDK の更新: client.beta.organization 名前空間を含む最新バージョンの SDK にアップデートする
  2. 認証情報の設定: Admin API キーを ANTHROPIC_API_KEY に、または org:admin OAuth トークンを ANTHROPIC_AUTH_TOKEN に設定する
  3. 既存スクリプトの移行検討: curl ベースの組織管理スクリプトを SDK / CLI ベースに置き換えることで、型安全性と自動ページネーションの恩恵を受けられる

🧳 移行時の注意点

curl ベースの既存スクリプトは引き続き動作するため、移行は必須ではありません。移行する場合は以下の点に注意してください。

  • 使用量・コストレポートと Claude Enterprise のユーザー管理・分析エンドポイントは SDK / CLI 非対応のため、これらの処理は curl のまま残す
  • Python、TypeScript、C#、Go、Java では、リストメソッドがページを自動取得するイテレーターを返すため、has_more を確認する手動ページネーションのロジックは不要になる
  • サービスアカウントと WIF 関連の操作には org:admin OAuth トークンが必要 (Admin API キーでは不可)

👥 対象となる開発者

  • 組織のオンボーディング・オフボーディングを自動化する IT チーム
  • API キーの監査やローテーションをスクリプト化する管理者
  • WIF を利用した CI / 自動化ワークロードを構築するプラットフォームチーム
  • 組織管理ツールを Python、TypeScript、C#、Go、Java、PHP、Ruby で開発するエンジニア

📝 まとめ

今回のアップデートにより、Admin API が ant CLI と 7 言語 SDK から利用できるようになり、組織管理の自動化に curl ベースの独自実装が不要となりました。推論系 API と同じクライアントで、組織情報、メンバー、招待、ワークスペース、API キー、レート制限、サービスアカウント、WIF、CMK を扱えます。

  • SDK は client.beta.organization、CLI は ant beta:organization の名前空間で提供される
  • 認証は ANTHROPIC_API_KEY の Admin API キー、または ANTHROPIC_AUTH_TOKEN の org:admin OAuth トークンを自動で読み込む
  • Python、TypeScript、C#、Go、Java の SDK はリスト取得時にページを自動でたどるイテレーターを返す
  • サービスアカウントと WIF 関連の操作は org:admin OAuth トークンのみ対応
  • 使用量・コストレポートと Claude Enterprise のユーザー管理・分析エンドポイントは引き続き curl のみの対応

2026 年 7 月の Claude Enterprise 向けユーザー管理 API、8 月 19 日の Admin API GA に続く今回の SDK / CLI 対応により、組織管理の開発者体験が大きく向上しました。IT チームはオンボーディング自動化や API キー監査のツールを、使い慣れた言語の型付きクライアントで構築できます。
