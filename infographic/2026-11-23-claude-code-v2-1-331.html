Claude Code v2.1.331

主要クラウドプラットフォームでの Code Mode 対応とプラグイン optionalDependencies を含む 134 項目のアップデート

📅 2026-11-23 | ソース: Claude Code Changelog

概要 - キーポイント

☁️

Code Mode の対応プラットフォーム拡大 (重要)

Amazon Bedrock、Google Cloud の Agent Platform、Microsoft Foundry、Claude Platform on AWS のターミナルセッションで Code Mode がサポートされた。サードパーティプロバイダー経由の環境でも、スクリプトによるツール呼び出しの集約が可能になる

🔌

MCP ツール呼び出しの最長 30 分ハングを修正 (重要)

ローカルまたは WebSocket サーバーの不正な応答で、MCP ツール呼び出しが最長 30 分ハングする問題を修正。ローカル / WebSocket MCP サーバーの信頼性が向上した

🧩

プラグインマニフェストの optionalDependencies

列挙したプラグインと一緒にインストールされるが、単独で無効化・アンインストールできる。必須の依存関係と異なり、ユーザーが不要な付属プラグインを外せるようになる

🩺

claude doctor の API 接続性セクション

API に到達できるかどうかを HTTP ステータスまたはエラーとともに報告し、テストされなかった場合はその理由を表示する。プロキシやファイアウォール起因の接続問題の切り分けが容易になる

💻

VS Code 拡張は 78 項目の大規模更新

"Fix with Claude Code" や "Resolve Merge Conflicts" などのエディター統合の新機能に加え、長いチャットの応答性やリモートウィンドウ (SSH、WSL、コンテナー) での速度が大きく改善された

主要な変更点

☁️ Code Mode の拡大と修正

  • Bedrock / Google Cloud Agent Platform / Microsoft Foundry / Claude Platform on AWS のターミナルセッションで Code Mode をサポート
  • --resume / --continue で別の権限モードから再開したセッションが thinking とプロンプトキャッシュを失う問題を修正
  • 長いスクリプト出力の中間部分が失われる問題を修正。切り詰められていないテキストへのパスが Claude に渡される
  • --bare 使用時にスクリプトの呼び出し対象が伝えられない問題と、スクリプト実行中の ! / スラッシュコマンド入力で約 1 秒ごとにリクエストが送信される問題を修正
  • ツール検索が MCP ツールの説明 (制限、フォーマット、デフォルト値) をより多く表示

🧩 プラグインの optionalDependencies

  • 一緒にインストールされるが、単独で無効化・アンインストール可能な付属プラグインを定義できる
  • 中断・失敗したプラグイン更新が不完全なフォルダーを残し、コンポーネントが欠けた状態で読み込まれる問題を修正
  • claude plugin install などが managed settings の承認を求められない状況で出力なしにハングする問題を修正
  • 自動更新の通知が、依存関係として新規インストールされたプラグインを更新分と分けて表示

🩺 claude doctor の API 接続性診断

  • API への到達可否を HTTP ステータスまたはエラーとともに報告
  • テストされなかった場合はその理由を表示
  • プロキシ・ファイアウォール起因の接続問題の切り分けが容易に

🏢 ゲートウェイとエンタープライズ機能

  • oidc.groups_jsonpath: JSONPath (RFC 9535) の小さなサブセットで、オブジェクトのリストの一致エントリからグループを読み取り可能に
  • CLAUDE_GATEWAY_IDP_CONNECT_BY_HOSTNAME=1: NO_PROXY 設定時もサインインリクエストが https の IdP のホスト名をプロキシに渡す
  • CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION: 圧縮レスポンスを切断するプロキシの背後で非圧縮レスポンスを要求
  • OpenTelemetry: claude_code.llm_request スパンに gen_ai.usage.*、gen_ai.response.model、gen_ai.operation.name を追加

🔌 MCP とツール呼び出しの修正

  • 不正な応答による最長 30 分のハングを修正
  • ツール名のないツール呼び出しを返すカスタム API エンドポイントでのクラッシュを修正 (呼び出しはエラーとなりセッションは継続)
  • 思考中に応答が途絶えた場合のクラウドセッションの失敗・タイムアウトを修正 (リクエストを 1 回再試行)
  • Workflow エージェントのバックグラウンドシェルと MCP サーバーがレポート返却後も実行されたままになる問題を修正

🪟 Windows 関連の修正

  • レジストリの managed settings に日本語などの非 ASCII 文字が含まれると起動しない問題を修正
  • FAT32 / exFAT ドライブへの書き込みが一部のプラグインセッションで毎回権限を求める問題を修正
  • メモリがほぼ枯渇したマシンでのクラッシュの可能性と、/desktop が古いインストーラーをダウンロードする問題を修正
  • 注意: HKLM ポリシーは managed-settings.json より優先され、壊れた値は起動を停止させることがある

💻 VS Code 拡張の更新 (78 項目)

  • "Fix with Claude Code": エラー・警告のクイックフィックスと失敗テストから問題をチャットボックスに投入
  • "Resolve Merge Conflicts"、"Add Cell to Chat"、Source Control の "Add to Chat" を追加
  • 長いチャットの応答性・パネル起動・リモートウィンドウでの速度を改善
  • 提案 diff の保存は提案側をクリックまたは入力した後にのみ受け入れ

✨ そのほかの新機能と改善

  • タップモードの音声入力が自動停止した際に通知を表示 (認識できる音声なしで 15 秒経過または 2 分の上限)
  • 起動時間の改善: 直前のセッション直後はモデルリストを待たず、git リポジトリ外では git を待たない
  • スクリーンリーダーモードの入力速度を改善 (特に長いセッション)
  • /login と claude auth login --console の Console サインインリンクが大幅に短縮

🧩 プラグインマニフェストの optionalDependencies

付属プラグインを単独で無効化・アンインストール可能にするには、dependencies ではなく optionalDependencies に列挙する。

JSON plugin.json - 付属プラグインの定義 
{
  "name": "my-plugin",
  "version": "1.0.0",
  "optionalDependencies": {
    "helper-plugin": ">=1.0.0"
  }
}

🔀 プロキシ環境での非圧縮レスポンス要求

圧縮レスポンスを途中で切断するプロキシの背後では、環境変数で非圧縮レスポンスを要求できる。

Bash プロキシが圧縮レスポンスを切断する場合に設定 
# プロキシが圧縮レスポンスを切断する場合に設定
# Self-hosted runner と Remote Control ではまだ非推奨
export CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION=1

🔄 マーケットプレイス自動更新のオプトアウト

2026 年 11 月 30 日以降のリリースで、managed extraKnownMarketplaces に含まれるプラグインマーケットプレイスがデフォルトで自動更新されるようになる。自動更新を避けたいマーケットプレイスには設定を追加する。

JSON managed settings - autoUpdate のオプトアウト 
{
  "extraKnownMarketplaces": {
    "internal-marketplace": {
      "source": {
        "source": "github",
        "repo": "my-org/claude-plugins"
      },
      "autoUpdate": false
    }
  }
}

カテゴリ別の修正・変更の要約

💻 VS Code 拡張のパフォーマンス改善

  • 長いチャットでの応答性が改善。返信のストリーミング中もスムーズな入力と大きなファイル書き込みが可能になり、権限プロンプトの表示が高速化
  • パネルと新しいチャットタブが速く開き、リモートウィンドウ (SSH、WSL、コンテナー) でもパネル起動・返信表示・セッション再開が高速化
  • 長い会話のフォークや巻き戻しのたびにメモリが増え続ける問題を修正
  • 非常に大きな選択範囲や添付テキストファイルの送信前に通知を表示し、"Prompt is too long" の下に大きい部分と対処方法を表示

🐛 VS Code 拡張の注目の修正と変更

  • フォークした会話が元の会話のプランファイルを上書きする問題を修正
  • allowManagedPermissionRulesOnly 設定時、許可ルールを提示する権限カードは Yes と No のみを表示
  • Claude やフック、MCP サーバーから Electron アプリや拡張テストが起動しない問題を修正。VS Code を Node として実行するラッパーやフックは ELECTRON_RUN_AS_NODE=1 の設定が必要に
  • files.encoding が UTF-8 以外のときの提案 diff の文字化けと、ヘブライ語・アラビア語・ペルシア語の行で右から左へのマークが \u200F というリテラルのエスケープ文字列として保存される問題を修正

🔧 CLI の注目のバグ修正 (抜粋)

  • @ メンション: @file#10-12 形式が指定行ではなくファイル全体を添付する問題を修正
  • コンパクション: /compact と自動コンパクションが特定の XML タグを引用した要約の一部を失うことがある問題を修正
  • 巻き戻し: 復元失敗後の巻き戻しがファイルを削除する問題を修正

📅 今後の変更予告 (注意)

  • 2026 年 11 月 30 日以降のリリースで、managed extraKnownMarketplaces に含まれるプラグインマーケットプレイスがデフォルトで自動更新される。オプトアウトするには、該当エントリに "autoUpdate": false を設定する

ユースケース - 開発者への影響

☁️ Bedrock / Google Cloud / Microsoft Foundry / Claude Platform on AWS の利用者

ターミナルセッションで Code Mode が利用可能になった。組織で Code Mode を制御している場合は、これらの環境にも適用範囲が広がる点に留意する。プラグイン作者は optionalDependencies により、ユーザーが個別に無効化・削除できる付属プラグインを定義できるようになった

🏢 ゲートウェイ運用者・MCP サーバーの利用者

oidc.groups_jsonpath と CLAUDE_GATEWAY_IDP_CONNECT_BY_HOSTNAME により、OIDC グループの読み取りとプロキシ経由のサインインの構成の柔軟性が向上した。MCP では不正な応答による最長 30 分のハングが解消され、ローカル / WebSocket サーバーの信頼性が向上した

🪟 Windows ユーザー・VS Code 拡張の利用者

レジストリの managed settings に非 ASCII 文字が含まれる環境での起動不能が修正された。一方で HKLM ポリシーの優先順位に関する注意が追加された。VS Code では "Fix with Claude Code" などのエディター統合の新機能に加え、長いチャットの応答性やリモートウィンドウでの速度が大きく改善された

必要なアクション

  1. アップデートの適用: MCP ハングや CLI フリーズなど安定性に関わる修正が多いため、早期の更新を推奨する
  2. マーケットプレイス設定の確認: managed extraKnownMarketplaces を使っている場合、2026 年 11 月 30 日以降の自動更新デフォルト化に備え、必要なら "autoUpdate": false を設定する
  3. Windows の managed settings の確認: レジストリにポリシーを配布している場合、アップグレード前に HKLM の値が正しいか確認する。壊れた値は起動を停止させることがある
  4. VS Code で Electron アプリを起動するフックの確認: VS Code を Node として実行するラッパー・フック・MCP サーバーは ELECTRON_RUN_AS_NODE=1 の設定が必要になった
  5. 接続問題の診断: API への接続に問題がある場合は、claude doctor の API 接続性セクションで HTTP ステータスやエラーを確認する
移行ガイド (該当する場合): VS Code で提案 diff の保存で編集を受け入れていた場合、保存だけでは受け入れられなくなった。提案側 (右側) をクリックまたは入力してから保存するか、Accept ボタンを使用する。圧縮レスポンスを切断するプロキシの背後で応答が途切れる場合は、CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION の設定を検討する (Self-hosted runner と Remote Control では非推奨)

まとめ

Claude Code v2.1.331 は、Code Mode を Amazon Bedrock、Google Cloud の Agent Platform、Microsoft Foundry、Claude Platform on AWS のターミナルセッションへ拡大し、プラグインの optionalDependencies、claude doctor の API 接続性診断、ゲートウェイの oidc.groups_jsonpath といったエンタープライズ向け機能を加えたリリースである。MCP ツール呼び出しの最長 30 分のハング解消や Windows の非 ASCII managed settings 対応など、安定性の修正も幅広い。VS Code 拡張は "Fix with Claude Code" や "Resolve Merge Conflicts" などのエディター統合と大規模なパフォーマンス改善を含む 78 項目の更新となった。managed マーケットプレイスの自動更新が 2026 年 11 月 30 日以降デフォルト化される予告が含まれるため、該当する組織は事前の設定確認を推奨する
