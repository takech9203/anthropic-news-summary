Claude Code v2.1.291

クラウドセッションの権限プロンプト回答と終了時のメッセージ喪失、2 件のリグレッションを修正するホットフィックス

📅 2026-10-06 ｜ ソース: Claude Code Changelog

概要

Claude Code v2.1.291 がリリースされました。変更は修正 (Fixed) 2 件のみで、いずれも過去バージョンで混入したリグレッションを解消するホットフィックスリリースです。新機能の追加や挙動変更は含まれません。どちらもセッションの入出力の信頼性に直結する不具合であり、該当バージョンを利用しているユーザーには早めの更新が推奨されます。

☁️

クラウドセッションの権限プロンプト回答の喪失を修正

v2.1.290 で発生した、クラウドセッションが権限プロンプトへの回答を取りこぼすことがある問題が修正されました。承認したはずの操作が進まない、プロンプトが未回答のまま残るといった影響が解消されます。

💾

終了時のセッション末尾メッセージの喪失を修正

v2.1.288 で発生した、終了時にセッションの最後のメッセージが失われることがある問題が修正されました。--resume で再開した際に会話履歴の一部が欠落する影響が解消されます。

🩹

修正 2 件のみの小規模ホットフィックス

新機能や挙動変更はなく、更新のリスクは小さいリリースです。v2.1.288 - v2.1.290 を利用している場合は v2.1.291 への更新が推奨されます。

修正 1: クラウドセッションの権限プロンプト回答の喪失

1

☁️ 権限プロンプトへの回答の取りこぼしを修正

v2.1.290 のリグレッション

v2.1.290 で、クラウドセッションが権限プロンプトへの回答を取りこぼす (drop する) ことがある問題が発生していました。クラウドセッションでは、ツール実行などの承認をリモートから回答する仕組みになっていますが、回答がセッションに反映されず、承認したはずの操作が進まない、あるいはプロンプトが未回答のまま残るといった影響が考えられます。本バージョンでこのリグレッションが修正されました。

❌ Before (v2.1.290)

権限プロンプトへの回答がセッションに反映されないことがあり、承認したはずの操作が進まない、プロンプトが未回答のまま残るといった影響が発生

✅ After (v2.1.291)

リモートからの権限プロンプトへの回答が確実にセッションへ反映され、承認した操作が正しく進行する

修正 2: 終了時のセッション末尾メッセージの喪失

2

💾 終了時に最後のメッセージが失われる問題を修正

v2.1.288 のリグレッション

v2.1.288 で、Claude Code を終了 (quit) した際にセッションの最後のメッセージが失われることがある問題が発生していました。この場合、--resume などでセッションを再開してもターン末尾のやり取りが復元されず、会話履歴の一部が欠落する影響が考えられます。本バージョンでこのリグレッションが修正されました。

❌ Before (v2.1.288 - v2.1.290)

終了時にセッション末尾のメッセージが保存されないことがあり、--resume で再開しても直前のやり取りが欠落

✅ After (v2.1.291)

終了時にセッション末尾のメッセージまで確実に保存され、再開時に会話履歴が完全に復元される

技術的な詳細

本バージョンの変更は上記 2 件の修正のみです。影響範囲と混入バージョンを以下に整理します。

修正内容混入バージョン影響する利用形態
権限プロンプトへの回答の取りこぼし v2.1.290 クラウドセッション
終了時のセッション末尾メッセージの喪失 v2.1.288 - v2.1.290 ローカルセッション全般 (終了・再開の操作)

開発者への影響

🎯 対象

  • ☁️ クラウドセッションを利用しているユーザー v2.1.290 を利用中の場合、権限プロンプトの回答が反映されないことがあります。
  • 💻 v2.1.288 以降を利用しているすべてのユーザー 終了時にセッション末尾のメッセージが失われることがあります。

✅ 必要なアクション

  • ⬆️ アップデートの実施 v2.1.288 - v2.1.290 を利用している場合は v2.1.291 への更新を推奨します。特にクラウドセッションの権限プロンプトが未回答のまま進まない事象や、再開したセッションで直前のやり取りが欠けている事象に心当たりがある場合は、本バージョンで解消されます。
  • 🔎 欠落した履歴の確認 旧バージョンの終了時に失われたメッセージは本バージョンでは復元されないため、重要なやり取りが欠けていないかを必要に応じて確認します。

🚧 移行ガイド (該当する場合)

✅ 更新のみで対応完了

破壊的変更や挙動変更はありません。アップデートのみで対応は完了します。

まとめ

Claude Code v2.1.291 は、修正 2 件のみの小規模なホットフィックスリリースです。v2.1.290 で混入したクラウドセッションの権限プロンプト回答の取りこぼしと、v2.1.288 で混入した終了時のセッション末尾メッセージの喪失という、いずれもセッションの信頼性に関わるリグレッションを解消しました。

新機能や挙動変更はなく更新のリスクは小さいため、該当バージョンを利用しているユーザーは早めのアップデートが推奨されます。
