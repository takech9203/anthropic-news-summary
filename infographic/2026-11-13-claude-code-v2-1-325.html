Claude Code v2.1.325 リリース

サンドボックス動作の既定値変更を含む大規模メンテナンスリリース。約 140 項目のセキュリティ修正と堅牢化

📅 2026-11-13 | ソース: Claude Code Changelog

概要 - キーポイント

🏖️

最重要: サンドボックスの既定動作が変更

サンドボックス化された Bash コマンドも既定で通常の権限フロー (allow / ask / deny) に従うようになった。従来のプロンプトなし実行を維持するには sandbox.autoAllowBashIfSandboxed: true の設定が必要

🔒

多数のセキュリティ修正

zstd 圧縮レスポンスのデコード、Bash 権限チェックのギャップ、deny / ask ルールの適用漏れ、サンドボックス保護の抜けなどを広範に修正。早期のアップデートを推奨

🛡️

権限・信頼まわりの強化

信頼していないリポジトリでの読み取り専用 git コマンドの確認、スケジュールタスクや /loop でのスキル実行前確認など、保守的な方針へ変更

⚙️

MCP タスク・バックグラウンドタスクの改善

回答待ちタスクの /tasks への誘導、Esc での「後で回答」、入力中メッセージを妨げない質問表示など UX を多数改善

💻

VS Code 拡張の改善

Tab キーで受け入れられるプロンプトサジェストと、API キーを作成しないキーレス Console サインインが追加された

Before / After - サンドボックスと権限フロー

サンドボックスを「権限確認の代替」ではなく「権限確認に加えた防御層」として扱う方針が明確になった。

Before (〜 v2.1.324)

サンドボックス内のコマンドは「隔離されているため安全」とみなされ、権限プロンプトなしで実行されていた

After (v2.1.325 〜)

サンドボックス化の有無にかかわらず通常の権限フロー (allow / ask / deny ルールと確認プロンプト) が既定で適用される

組織の管理者向け: 管理対象設定 (managed settings) でサンドボックスを有効にしている組織は、従来の動作を維持する場合、最上位の管理ソースに sandbox.autoAllowBashIfSandboxed: true を追加する必要がある

主要な変更点

🔒 セキュリティ修正

  • zstd 圧縮レスポンスのデコードに関する問題を修正
  • 一部の複合コマンドが確認なしで実行され得た Bash 権限チェックのギャップを修正
  • 相対パスの deny / ask ルール (例: Read(./.env)) が cd 後に効かなくなる問題などを修正
  • サンドボックスが起動するプログラムからサインイントークンや API キーを分離

🏖️ サンドボックス動作の変更

  • サンドボックス内コマンドも既定で通常の権限フローに従う
  • 追加ディレクトリ内の .claude 配下 (設定、スキル、フックなど) への書き込みも拒否
  • ワークツリーの設定・フックや共有 git フォルダの保護を強化
  • クラウドセッションは sandbox.failIfUnavailable 設定時でも起動可能に

🛡️ 権限・信頼まわりの強化

  • 信頼していないリポジトリでは読み取り専用 git コマンドでも確認 (--add-dir 指定で回避)
  • スケジュールタスクと /loop はスキル実行前に確認 (無人実行は Skill(name) を許可)
  • 組織外公開アーティファクトの確認スキップを修正

⚙️ MCP タスク・バックグラウンドタスク

  • 回答待ちタスクを Claude が認識し /tasks へ誘導
  • 質問に Esc で「後で回答」。質問は /tasks に残る
  • 入力中のメッセージの上に質問が開かないように改善
  • バックグラウンドセッションが別のサインインの API キーを使用 (課金) する問題を修正

🧩 プラグイン関連

  • MCP バンドル (.mcpb、.dxt) の展開先変更で読み取り専用フォルダに対応
  • pluginDigests は非推奨に。prependPlugins / appendPlugins へ移行
  • マーケットプレースの ref がコミット完全 ID のピン指定に対応

💻 VS Code 拡張の改善

  • Tab キーで受け入れるプロンプトサジェストを追加 (promptSuggestionEnabled: false で無効化)
  • API キーを作成しないキーレス Console サインイン
  • SSH / WSL / コンテナでの MCP サインイン用リダイレクト URL フィールドを追加

技術詳細 - サンドボックスと権限フローの関係

⚙️ 従来の動作を維持する設定例

サンドボックス内のコマンドをプロンプトなしで実行し続けたい場合は、settings.json に以下を追加する。管理対象設定でサンドボックスを有効化している組織では、最上位の管理ソースに設定する。

JSON settings.json - サンドボックスの従来動作を維持 
{
  "sandbox": {
    "autoAllowBashIfSandboxed": true
  }
}

📝 そのほかの修正と改善

  • サードパーティゲートウェイや Foundry 上のセッションが毎ターンコンテキスト長エラーで停止する問題を修正
  • 正常終了しなかったセッションの再開時に直近のターンが失われる問題を修正
  • 保存済みの sonnet[1m] モデル設定が無効な ID に書き換えられる問題を修正
  • Code Mode スクリプトが EnterWorktree のワークツリーを無視する問題など Code Mode 関連の複数の修正
  • 出力トークン上限で打ち切られたサブエージェントは、より簡潔に全体の回答を再度求められるように改善
  • OpenTelemetry の user_prompt イベントの欠落を修正 (ツール実行中のメッセージは delivery.mode: "mid_turn" を持つ)
  • Windows のスタートアップ停滞や /resume のドライブレター大文字小文字の問題などプラットフォーム固有の修正

ユースケース - 開発者への影響

🏖️ サンドボックスを有効にしている開発者・組織

サンドボックス内コマンドが権限プロンプトを出すようになるため、既定動作の変更に直接影響を受ける。権限プロンプトが増えた場合はワークフローを確認のうえ、必要に応じて sandbox.autoAllowBashIfSandboxed: true を設定する。管理対象設定でサンドボックスを有効化している組織は、最上位の管理ソースへの設定追加を検討する

⏰ スケジュールタスクや /loop で自動実行している利用者

allowed-tools やフックを宣言するスキルの実行前に確認が求められるようになった。無人実行を維持するには permissions.allow に Skill(name) を追加する。信頼していないリポジトリで読み取り専用 git コマンドをプロンプトなしで実行するには、additionalDirectories 設定ではなく --add-dir で指定する

🧩 プラグイン開発者・マーケットプレース運営者

.mcpb の展開先変更により読み取り専用のプラグインフォルダでもロード可能になった。pluginDigests は非推奨となり無視されるため prependPlugins / appendPlugins へ移行する。マーケットプレースをコミット ID でピンする場合、v2.1.325 より前のクライアントではロードできない点に注意する

必要なアクション

  1. アップデートの適用: セキュリティ修正が多数含まれるため、早期の更新を推奨
  2. サンドボックス設定の確認: 権限プロンプトが増えた場合は sandbox.autoAllowBashIfSandboxed: true の設定を検討する
  3. 自動実行タスクの見直し: スケジュールタスクや /loop の無人実行には permissions.allow に Skill(name) を追加する
  4. プロジェクト外リポジトリの指定方法の変更: additionalDirectories 設定ではなく --add-dir で指定する
  5. Remote Control をサービス運用している場合: claude remote-control の終了ステータス変更 (自律停止で 4、登録不可で 69) に合わせて再起動条件を確認する

まとめ

Claude Code v2.1.325 は、新機能よりも堅牢化に軸足を置いた大規模メンテナンスリリースである。最大の変更点はサンドボックス化された Bash コマンドが既定で通常の権限フローに従うようになったことで、サンドボックスを「権限確認の代替」ではなく「権限確認に加えた防御層」として扱う方針が明確になった。zstd デコードのセキュリティ修正や Bash 権限チェックのギャップ修正も含まれるため、すべての利用者に早期のアップデートを推奨する。サンドボックスや自動実行タスクを活用している環境では、プロンプト動作の変化に合わせた設定の見直しが必要になる
