Claude Code v2.1.227

Claude Code v2.1.227
期限切れトークン起動時のプラン誤判定修正、claude-code-action の Bash 実行不能修正、スラッシュコマンドメニュー改善

📅 2026-08-10 | ソース: Claude Code Changelog

概要

Claude Code v2.1.227 (2026 年 8 月 10 日、npm 公開日時: 2026-08-10T20:56:57Z) がリリースされた。本バージョンは修正 3 件と改善 2 件の計 5 項目で構成される、修正中心のメンテナンスリリースである。

🎫

期限切れトークン起動時のプラン誤判定を修正

期限切れのログイントークンでセッションを開始すると、フィーチャーフラグがサブスクリプションプラン情報なしで評価され、Max プランのユーザーに Fable 向け使用量クレジットの有効化を誤って促す問題を修正

🤖

claude-code-action の Bash 実行不能を修正

GitHub ホストランナー上で allowed_non_write_users を設定した claude-code-action において、すべての Bash コマンドが失敗する問題を修正

⏪

/tui による巻き戻し済み会話の復活を修正

最初のメッセージより前まで巻き戻した会話が、/tui の実行によって復活してしまう問題を修正

🎨

スラッシュコマンドメニューの視認性向上

青色のハイライトは選択中の行のみに適用され、検索一致文字は太字で表示。絵文字やアクセント記号付きのコマンド名でもグリフが正しく保持される

⚡

イベントループ停止の削減

ファイルが見つからない場合の候補表示と、アットメンションのサイズチェックにおけるイベントループの停止が削減された

📖 背景

🔑 認証安定性修正の流れを継承

直前のリリース v2.1.225 および v2.1.226 (2026 年 8 月 8 日) では、CLAUDE_CODE_OAUTH_TOKEN の上書き問題や macOS キーチェーン起因の 401 エラー連発など、認証関連の安定性修正が行われた。本リリース v2.1.227 はその流れを継ぎ、期限切れトークンでの起動時にフィーチャーフラグ評価が不正確になる問題に対処している。

🤖 CI/CD 環境での問題報告への対応

CI/CD 環境で Claude Code を利用する claude-code-action については、書き込み権限を持たないユーザーの利用を許可する allowed_non_write_users 設定と GitHub ホストランナーの組み合わせで Bash コマンドが機能しない問題が報告されており、本リリースで修正された。

🔧 修正 (3 件)

🎫 フィーチャーフラグ誤評価の修正

期限切れのログイントークンでセッションを開始すると、フィーチャーフラグがユーザーのサブスクリプションプラン情報なしで評価され、Max プランのユーザーに対して Fable 向け使用量クレジットの有効化を誤って促すことがあった問題を修正。

🤖 claude-code-action の Bash 全滅修正

GitHub ホストランナー上で allowed_non_write_users を設定した claude-code-action において、すべての Bash コマンドが失敗する問題を修正。

⏪ /tui による会話復活の修正

最初のメッセージより前まで巻き戻した (rewind した) 会話が、/tui の実行によって復活してしまう問題を修正。

✨ 改善 (2 件)

🎨 スラッシュコマンドメニューの表示改善

青色のハイライトは選択中の行のみに適用され、検索で一致した文字は色変更ではなく太字で表示されるようになった。また、絵文字やアクセント記号付きのコマンド名でもグリフが正しく保持される。

⚡ パフォーマンス改善

ファイルが見つからない場合の候補表示 (file-not-found suggestions) と、アットメンションのサイズチェックにおけるイベントループの停止 (event-loop stalls) が削減された。

🔬 技術的な詳細

🎫 期限切れトークンとフィーチャーフラグ評価

Claude Code は起動時にフィーチャーフラグを評価し、ユーザーのサブスクリプションプランに応じて機能や案内の表示を切り替える。修正前は、ログイントークンが期限切れの状態でセッションを開始すると、プラン情報 (subscription tier) が取得できないままフラグが評価されるため、Max プランのユーザーが未加入ユーザーと同様に扱われ、Fable モデル向けの使用量クレジット有効化を促すプロンプトが誤って表示されることがあった。修正後は、この状況でプランを無視したフラグ評価が行われなくなった。

Before: 期限切れトークンでの起動

プラン情報なしでフィーチャーフラグが評価され、Max プランのユーザーが未加入ユーザーと同様に扱われ、Fable 向け使用量クレジットの有効化を誤って促された。

After: v2.1.227 での修正後

プラン情報が取得できない状況では、プランを無視したフラグ評価が行われなくなり、誤ったプロンプトが表示されない。

🤖 claude-code-action の allowed_non_write_users

claude-code-action はリポジトリへの書き込み権限を持つユーザーのみに実行を許可するのが既定の動作であり、allowed_non_write_users は書き込み権限のないユーザーにも実行を許可するための設定である。修正前は、この設定を GitHub ホストランナー上で使用すると、実行環境の制約との組み合わせによりすべての Bash コマンドが失敗し、ワークフローが実質的に機能しない状態になっていた。本修正により、この構成でも Bash コマンドが正常に実行される。

⚡ イベントループ停止の削減

Claude Code は Node.js 上で動作する TUI アプリケーションであり、イベントループが長時間ブロックされると入力や描画が停止する。修正前は、存在しないファイルパスに対する候補提示や、アットメンション (@ によるファイル参照) のサイズチェックの処理でイベントループの停止が発生することがあった。本改善により、これらの処理に起因する体感的な引っかかりが軽減された。

👥 開発者への影響: 対象

👤
Max プランのユーザー 期限切れトークンでの起動時に、Fable 向け使用量クレジットの有効化を誤って促されることがなくなった
🤖
claude-code-action の利用者 GitHub ホストランナーで allowed_non_write_users を設定している場合、Bash コマンドが失敗する問題が解消された。該当する構成の CI/CD ワークフローでは本バージョンへの更新を推奨
🖥️
TUI ユーザー 巻き戻した会話が /tui で復活する問題の解消に加え、スラッシュコマンドメニューの視認性向上とイベントループ停止の削減により、日常的な操作の体験が改善された

💻 コード例

claude-code-action での allowed_non_write_users の利用例。v2.1.227 で GitHub ホストランナーでも Bash コマンドが正常に動作するようになった。

YAML .github/workflows/claude.yml 
# .github/workflows/claude.yml
# v2.1.227 で修正: GitHub ホストランナーでも Bash コマンドが正常に動作
jobs:
  claude:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          allowed_non_write_users: |
            trusted-contributor

💡 ユースケース

🤖 外部コントリビューターを含む CI/CD 運用

書き込み権限を持たない信頼できるコントリビューターにも claude-code-action の実行を許可したいチームでは、allowed_non_write_users と GitHub ホストランナーの組み合わせで Bash コマンドがすべて失敗する問題が解消され、追加のセルフホストランナーを用意せずにワークフローを運用できる。

👤 Max プランでの安定したセッション開始

長期間セッションを開かずにトークンが期限切れになった Max プランのユーザーでも、起動時に Fable 向け使用量クレジットの有効化を誤って促されることがなくなり、プランに応じた正しい案内のもとで作業を再開できる。

🖥️ 日常的な TUI 操作の快適化

スラッシュコマンドメニューの視認性向上 (選択行のみのハイライト、一致文字の太字表示、絵文字グリフの保持) と、ファイル候補表示やアットメンション処理のイベントループ停止削減により、コマンド入力やファイル参照時の引っかかりが軽減される。

📝 まとめ

修正 3 件と改善 2 件で構成される小規模なメンテナンスリリース

Claude Code v2.1.227 は、修正 3 件と改善 2 件で構成される小規模なメンテナンスリリースである。新機能の追加はないが、期限切れトークン起動時の Max プラン誤判定、GitHub ホストランナー上での claude-code-action の Bash 実行不能という、影響範囲の明確な問題が修正されている。

特に、allowed_non_write_users を設定した claude-code-action を GitHub ホストランナーで運用しているチームは、すべての Bash コマンドが失敗する問題の修正を含むため、本バージョンへの更新を推奨する。日常的に TUI を利用するユーザーにとっても、スラッシュコマンドメニューの視認性向上とイベントループ停止の削減による体験改善が見込める。
