🛡️ Managed Agents ネットワーキング強化

limited ネットワーキングの allowed_hosts が Web ツールにも適用され、サンドボックスと Web ツールのネットワーク制御が一元化。web_fetch は既出 URL のみフェッチ可能になり、データ流出経路を遮断します。

API 変更点: Managed Agents の Web ツール制限

limited ネットワーキングのクラウド環境が対象です (unrestricted ネットワーキングとセルフホスト環境は対象外)。

変更点 挙動
url_not_allowed エラー web_fetch で allowed_hosts に一致しないホストの URL をフェッチすると、エージェントにエラー結果が返ります。
url_not_in_prior_context エラー web_fetch でセッション内に未出の URL をフェッチすると、エージェントにエラー結果が返ります。URL を許可するには user.message イベントのテキストで送信します。
web_search の結果フィルタ allowed_hosts に一致しないホストの結果は検索結果から除外されます。allowed_hosts が空の場合、どちらのツールもページ・検索結果を返しません。
セッション作成・更新の 400 エラー Web ツールの allowed_domains に allowed_hosts 外のエントリがあると、セッション作成・更新が 400 エラーで失敗します。構成時に設定ミスを早期検出できます。
ホストのマッチングルール allowed_hosts のエントリは *. で始まらない限り単一の完全一致ホストにのみマッチ。docs.example.com は ["example.com"] の範囲外です。
その他の設定 allow_package_managers と allow_mcp_servers は Web ツールにホストを追加しません。許可するには allowed_hosts に追加します (サンドボックスからもアクセス可能になります)。

既出と見なされる例

技術詳細: Web ツール制御フロー

今回のネットワーキング変更は、サンドボックスのネットワーク制御と Web ツールの制御を allowed_hosts に一元化する設計です。allowed_domains との整合性もセッション作成時点で検証されるため、設定ミスを実行時ではなく構成時に検出できます。

コードサンプル: SDK ブラウザツールセットクラス

SDK のブラウザツールセットクラスを使う Python の例です (公式ドキュメントのサンプルを抜粋・短縮)。backend は Playwright などのブラウザ自動化ライブラリの自前ラッパーを表します。

Python ブラウザ使用ツールセットの実装例 
from anthropic import Anthropic
from anthropic.tools import ToolError
from anthropic.tools.browser import (
    BetaAbstractBrowserToolset20260801,
    BetaBrowserNavigateResult,
    BetaScreenshotResult,
    BetaToolsetCallContext,
    BetaURLContext,
)


class MyBrowser(BetaAbstractBrowserToolset20260801):
    def __init__(self, backend, **options):
        super().__init__(**options)
        self.backend = backend

    def navigate(self, context, input) -> BetaBrowserNavigateResult:
        page = self.backend.goto(input.url, input.tab_id)
        return BetaBrowserNavigateResult(
            url=page.url, status=page.status, title=page.title
        )

    def screenshot(self, context, input) -> BetaScreenshotResult:
        data = self.backend.png_base64(input.tab_id)
        return BetaScreenshotResult(data=data, media_type="image/png")

    # left_click など他のメンバーツールと、状態レポート _browser_state も実装する


def url_policy(context: BetaURLContext, url: str) -> None:
    if not is_allowed(url):  # 自前の URL 判定ロジック
        raise ToolError(f"blocked: {url} is not on an allowed host")


client = Anthropic()
with MyBrowser(backend, url_policy=url_policy) as browser:
    runner = client.beta.messages.tool_runner(
        model="claude-opus-5-5",
        max_tokens=1024,
        tools=[browser],
        messages=[
            {"role": "user", "content": "Open example.com and tell me the page heading."}
        ],
        stream=True,
        run_tools_eagerly=True,
    )
    for stream in runner:
        print(stream.get_final_message())

💡 SDK がツールループ・URL ポリシーの適用・tool_result の構築を担うため、開発者はブラウザ操作のメソッド実装に集中できます。コンピュータ使用ツールの場合は BetaAbstractComputerToolset20260801 を同様にサブクラス化します (URL ポリシー・ファイルポリシー・状態レポートはブラウザ専用のため不要)。SDK にはブラウザ、デスクトップ、既製ドライバ、URL ポリシーは含まれず、CDP (ブラウザ) や VNC (デスクトップ) を使った最小サンプルが claude-quickstarts リポジトリで公開されています。

ユースケース

🔁 長いシステムプロンプトを繰り返し使うエージェントのコスト削減

長いシステムプロンプトやツール定義をキャッシュして繰り返し利用するエージェントワークフローでは、入力コストの大部分がキャッシュ読み取りで占められます。Sonnet 5.5 のキャッシュ読み取り半額化により、アクション不要で実質的なコストが大きく下がります。

🖥️ ブラウザ・デスクトップ自動化エージェントの定型コード削減

自前のツールループでブラウザ使用・コンピュータ使用ツールを実装している場合、SDK のベータクラスへ移行することで、呼び出しルーティングやポリシー実行、tool_result 構築などの定型コードを削減し、ブラウザ操作のメソッド実装に集中できます。

🔐 Managed Agents のセキュアな Web アクセス運用

limited ネットワーキングで Web ツールを使う場合、機密データを埋め込んだ URL をエージェント自身が組み立てて外部に送信するような流出経路が遮断されます。既存ワークフローは、アクセスしたいホストの allowed_hosts への追加と、フェッチさせたい URL を user.message イベントで渡す形への変更を確認してください。

必要なアクション (Managed Agents 利用者は要確認)

  • web_search/web_fetch でアクセスしたいホストが allowed_hosts に含まれているか確認する
  • allowed_domains のエントリがすべて allowed_hosts の範囲内か確認する (範囲外があるとセッション作成・更新が 400 エラー)
  • サブドメインを使う場合、完全一致または *. プレフィックスで指定しているか確認する
  • エージェントにフェッチさせたい URL は user.message イベントのテキストで渡す (システムプロンプトやツール出力の URL は url_not_in_prior_context エラーになる)
  • Max/Team プランのユーザーは、公式ドキュメントの手順に従って月次 API クレジットを受け取る
注意: SDK ツールセットクラスはベータ機能のため、仕様は変更される可能性があります。最新情報は公式ドキュメントを参照してください。
