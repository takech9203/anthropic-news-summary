概要: キーポイント

Claude Code v2.1.306 は、2 件のバグ修正のみを含む小規模なメンテナンスリリースである。新機能の追加や破壊的変更はなく、移行作業は不要である。

🔐

Cloud sessions での claude -p の認証エラー修正

Cloud sessions 内で、セッションの環境変数なしで claude -p を起動した場合に「Not logged in」と報告される問題を修正。

🧰

MCP ツール多数時のエラー表示とコンパクションの修正

多数の MCP ツールを持つセッションで、API エラーが「prompt is too long」というメッセージに置き換えられ、不要なコンパクションが実行される問題を修正。

主な変更点: バグ修正 2 件

🔐 Cloud sessions の認証エラー

Cloud sessions 内で、セッションの環境変数なしで claude -p (ヘッドレスモード) を起動した場合に「Not logged in」と報告される問題を修正した。

🧰 MCP ツール多数時の挙動

多数の MCP ツールを持つセッションで、API エラーが「prompt is too long」というメッセージに置き換えられ、不要なコンパクションが実行される問題を修正した。

技術詳細: Before / After

Before (v2.1.306 より前)

🔐 Cloud sessions 内でセッションの環境変数なしに claude -p を起動すると「Not logged in」と報告される。

🧰 多数の MCP ツールを持つセッションで、API エラーが「prompt is too long」に置き換えられ、不要なコンパクションが実行される。

After (v2.1.306)

🔐 Cloud sessions 内での claude -p の認証エラーが解消される。

🧰 API エラーが正しく表示され、不要なコンパクションが実行されなくなる。

開発者への影響: 対象

☁️ Cloud sessions で claude -p を利用するユーザー

Cloud sessions 内で claude -p (ヘッドレスモード) を利用するユーザーが対象。セッションの環境変数なしで起動した際の「Not logged in」エラーが解消される。

🧰 多数の MCP ツールを登録したセッションを利用するユーザー

多数の MCP ツールを登録したセッションを利用するユーザーが対象。API エラーが「prompt is too long」に置き換えられる問題と、不要なコンパクションが解消される。

必要なアクション

  • アップデートの適用: claude update または npm 経由で v2.1.306 に更新する。該当する問題に遭遇していた場合は、更新により解消される

破壊的変更はなく、移行作業は不要である。

Bash 更新コマンド 
claude update

まとめ

v2.1.306 は、Cloud sessions での認証エラーと MCP ツール多数時のエラー表示・不要なコンパクションという 2 件の不具合を解消する小規模リリースである。該当する環境を利用している場合は、アップデートの適用を推奨する。
