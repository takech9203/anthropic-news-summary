主な変更点

⚡ Vertex AI でのファストモード対応

Vertex AI の global、us、eu リージョンでファストモードが追加された。これまでの提供経路に加え、Vertex AI 経由で Claude Code を利用する環境でもファストモードを選択できる

🔄 自動フォールバック

Vertex がファストモードを拒否した場合、リクエストは標準速度にフォールバックして処理が継続される。既存ワークフローへの破壊的な影響はない

🚀 Claude Fable 5.2 向け高速推論

ファストモードは 2026-11-09 に提供が開始された Claude Fable 5.2 向けの高速推論オプションで、最大 2.5 倍の出力速度を実現する

⚡ ファストモードの背景

ファストモードは、2026-11-09 に提供が開始された Claude Fable 5.2 向けの高速推論オプションで、最大 2.5 倍の出力速度を実現する。料金は入力 $16/MTok、出力 $80/MTok である

コストへの注意: ファストモードは標準より高い料金 (入力 $16/MTok、出力 $80/MTok) が適用されるため、コストへの影響を事前に確認する

ユースケース - 開発者への影響

☁️ Vertex AI 経由で Claude Code を利用する開発者・組織

Vertex AI の global、us、eu リージョンを利用している場合、ファストモードの利用を検討する。Vertex が拒否した場合は標準速度に自動フォールバックするため、既存ワークフローへの破壊的な影響はない

⚡ 応答速度を重視するワークフローを運用するユーザー

対話的なコーディングセッションなど、応答速度を重視するワークフローで最大 2.5 倍の出力速度を活用できる。ただし、ファストモードは標準より高い料金が適用されるため、コストへの影響を事前に確認する

まとめ

Claude Code v2.1.322 は、Vertex AI の global、us、eu リージョンでファストモードを利用可能にする単一変更のリリースである。前日 (2026-11-09) に提供が開始された Claude Fable 5.2 のファストモード (最大 2.5 倍の出力速度) を Vertex AI 経由の環境にも広げるもので、拒否時には標準速度へ自動フォールバックするため安全に導入できる。Vertex AI 上で Claude Code を運用し、応答速度を改善したい組織に関係するアップデートである
