Claude Fable 5.2 / Claude Mythos 5.2 発表

高度な技術作業向け最上位モデルがコーディング・金融・科学で新基準を確立。出力速度は最大 30% 高速化し、価格は入力 $8/MTok・出力 $40/MTok に値下げ

📅 2026-11-09 | ソース: Anthropic News / Claude API リリースノート

概要 - キーポイント

⭐

最上位モデルラインの新バージョン

Fable 5.2 と Mythos 5.2 は同一の基盤モデル。Opus・Sonnet・Haiku の上位に位置し、最も野心的でオープンエンドな技術作業向け。日常的な用途には Opus 5.5 が推奨される

🛡️

提供形態が異なる 2 モデル

Fable 5.2 はサイバーセキュリティ・生物学分野のセーフガード付きで一般提供。セーフガードを緩和した Mythos 5.2 は Life Sciences Verification Program または Cyber Verification Program の審査通過組織のみ利用可能

💰

高速化と値下げを同時に実現

出力速度は Fable / Mythos 5.1 比で最大 30% 高速化。価格は入力 $8/MTok・出力 $40/MTok と前バージョンより値下げされた

⚡

ファストモードを提供開始

Fable 5.2 で最大 2.5 倍の出力速度を実現するファストモードが利用可能に。リクエストに speed: "fast" を指定するだけで、ベータヘッダーは不要

🤝

アドバイザー / オーケストレーター設計

小型モデルから相談を受ける「アドバイザー」として、あるいは小型モデルへ作業を委譲する「オーケストレーター」として機能できる設計

Fable 5.2 と Mythos 5.2 の違い

📖 Claude Fable 5.2

サイバーセキュリティおよび生物学分野のセーフガードを追加し、一般提供が可能。Claude Platform、AWS、Google Cloud、Microsoft Azure で本日から利用できる

🔬 Claude Mythos 5.2

セーフガードを緩和したバージョン。Cyber Verification Program または Life Sciences Verification Program の審査を通過した組織のみ利用可能。Enterprise 向け Claude Security にも搭載

主要機能・モデル仕様

🪟 1M トークンコンテキスト

コンテキストウィンドウは 100 万トークン。大規模コードベースや長大なドキュメントを丸ごと扱える

📤 128k トークン出力

最大出力は 128k トークン。長大なコード生成や詳細なレポート作成に対応する

🧠 常時適応思考

思考モードは常時適応思考。タスクに応じて推論の深さを自動的に調整する

⚡ ファストモード

最大 2.5 倍の出力速度。speed: "fast" を指定するだけで利用でき、ベータヘッダーは不要。Mythos のファストモードは Verification Program メンバー限定

🤝 アドバイザーツール (ベータ)

executor がアドバイザーとして受け付けるのは Fable 5.2 / Mythos 5.2 の 2 モデルのみ。他モデルを指定すると 400 エラーになる

🆔 モデル ID

claude-fable-5-2 / claude-mythos-5-2。出力速度は 5.1 比で最大 30% 高速化

特筆すべき成果

  • コーディング: Anthropic のコアコードベースへのマージの 90% 以上が、人間のガイダンスのもと Claude によって書かれている。実験では 1,000 以上のサブエージェントを 8 日間協調させ、カーネルレベルの機能・ドライバー・ファイルストレージ・ウィンドウシステムを備えた起動可能なプロトタイプ OS を構築
  • 科学: Mythos 5.2 はオープンソースのタンパク質フォールディングモデルを活用した新手法を考案し、34 個の AAV カプシドのうち 28 個を正確にモデル化 (Cα RMSD 3 Å 以内)。ホログラフィック双対性を用いてブラックホール物理学の未解決問題 2 件を解決し、プレプリントが公開されている
  • 数学: 1,000 個の Fable 5.2 エージェントがフェルマーの最終定理の形式化を 30 時間で完了 (従来は 11 日間)。アクショントークンは 3 分の 1、証明は 7 分の 1 の長さ
  • ハードウェア: 1 段落のプロンプトから、4 層 PCB・3D プリント筐体・ソフトウェアを含む 3 種類の動作デバイスを設計し、いずれも電気的な修正なしで動作

技術詳細 - API に関する重要な変更点

  • プレフィックスチェックの強制: 両モデルは全アカウントでプレフィックスチェックを強制する。system・tools・過去メッセージを編集した後に thinking ブロックを返送すると 400 エラーになる
  • 会話移行時の推論保持: Claude API と Google Cloud (Google managed) では、Fable 5.2 / Mythos 5.2 への会話移行時に他モデルの推論が保持される。逆方向の移行では thinking ブロックは破棄されるが、リクエストは成功する
  • コンピュータ使用ツールセット: computer_toolset_20260801 のみ対応。旧 computer_20251124 は Bedrock 以外で 400 エラーになる
  • アドバイザーツール (ベータ): executor がアドバイザーとして受け付けるのは同 2 モデルのみ。他モデルを指定すると 400 エラーになる
  • データ保持: 両モデルは 30 日間のデータ保持が必須。Anthropic の明示的な許可なしにはゼロデータ保持 (ZDR) では利用できない
  • thinking ブロックの有効範囲: 生成元アカウント (またはリンクされたアカウント) でのみ有効
  • ファストモード: Fable 5.2 で提供開始。最大 2.5 倍の出力速度で、リクエストに speed: "fast" を指定する (ベータヘッダー不要)

💻 コードサンプル

Python ファストモードを指定したリクエスト (ベータヘッダー不要) 
import anthropic

client = anthropic.Anthropic()

# ファストモードを指定したリクエスト (ベータヘッダー不要)
message = client.messages.create(
    model="claude-fable-5-2",
    max_tokens=128000,
    speed="fast",
    messages=[
        {
            "role": "user",
            "content": "大規模コードベースの Python から Rust への移行計画を作成してください。",
        }
    ],
)
print(message.content)

安全性とセーフガード

  • 約 1,900 シナリオの自動行動監査で、Mythos 5.2 は 2.67 (低いほど良好) を記録し、Opus 5.5 (2.79) や Mythos 5.1 (3.28) を上回った
  • サンドボックス脱出の敵対的評価 (1,800 以上のシナリオ) では、脱出率 3.1% と Mythos 5.1 の 21% から大幅に改善
  • Fable 5.2 のブロック数は Fable 5.1 比で約 55% 減少 (サイバー分野で約 60% 減、生物学分野で約 40% 減)。ブロックされたクエリは Opus 4.8 (サイバー) または Opus 5 (生物学) にフォールバックする
  • 蒸留対策はこれまでで最も強力で、収集データを 90 - 99% 削減。preserved thinking は全 API アカウントに適用される
  • 外部プレリリーステストは UK AI Security Institute、Frontier Design、METR が実施

ユースケース - 開発者への影響

🧑‍💻 大規模・長時間のエージェントコーディングや研究タスクに取り組む開発者

FrontierCode 2.0 や FrontierSWE v2 で大幅な性能向上を示し、1M コンテキストと 128k 出力により大規模コードベースの移行や長時間の自律タスクに適する。タスクあたりのコストは Opus 5.5 の約半分 (FrontierCode 2.0、High 設定)

🔬 サイバーセキュリティ・ライフサイエンス分野の組織

Mythos 5.2 は CVE Rediscovery 89.6% などサイバーセキュリティ分野でさらに高い性能を示す。利用には Cyber Verification Program または Life Sciences Verification Program の審査が必要

🤝 マルチエージェント構成のシステム設計者

オーケストレーターとして小型モデルへ作業を委譲、またはアドバイザーとして小型モデルから相談を受ける構成が可能。アドバイザーツール (ベータ) で executor が受け付けるのは Fable 5.2 / Mythos 5.2 のみ

✅ 必要なアクション

  • thinking ブロックの取り扱いを確認: system・tools・過去メッセージの編集後に thinking ブロックを返送する実装は 400 エラーになるため、会話履歴の管理ロジックを見直す
  • コンピュータ使用の移行: computer_20251124 を使用している場合、Bedrock 以外では computer_toolset_20260801 への移行が必要
  • ZDR 利用者の確認: ゼロデータ保持契約のアカウントは、Anthropic の明示的な許可がない限り両モデルを利用できない
  • モデル間移行の方向性に注意: 他モデルから Fable 5.2 / Mythos 5.2 への移行では推論が保持されるが、逆方向では thinking ブロックが破棄される

🌐 利用可能なプラットフォーム

  • Fable 5.2: Claude Platform、AWS、Google Cloud、Microsoft Azure で本日から利用可能
  • Mythos 5.2: Cyber Verification Program または Life Sciences Verification Program 経由。Enterprise 向け Claude Security にも搭載
  • ファストモード: Claude Code、Claude Platform、Google Cloud (Anthropic 管理・Google 管理)、Microsoft Foundry (Anthropic ホスト) で提供。Mythos のファストモードは Verification Program メンバー限定

まとめ

Claude Fable 5.2 と Claude Mythos 5.2 は、コーディング・金融・科学分野で新基準を打ち立てる Anthropic の最上位モデルです。前バージョンから大幅な性能向上と値下げ (入力 $8/MTok・出力 $40/MTok) を同時に実現し、ファストモードによる最大 2.5 倍の高速出力オプションも追加されました。一方で、プレフィックスチェックの強制、30 日間のデータ保持必須、コンピュータ使用ツールセットの刷新など、既存実装に影響する API 変更も含まれるため、導入前に移行要件の確認が必要です
