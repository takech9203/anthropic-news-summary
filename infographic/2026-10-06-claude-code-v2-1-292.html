Claude Code v2.1.292

概要

Claude Code v2.1.292 がリリースされました。92 項目の変更を含む大型リリースであり、内訳は追加 (Added) 8 件、修正 (Fixed) 64 件、改善 (Improved) 13 件、変更 (Changed) 7 件です。同日未明のホットフィックス v2.1.291 に続く、機能追加と品質改善をまとめた本編といえるリリースです。

🤖

Agent ツールに effort パラメータが追加

Claude がサブエージェントを起動する際、要求された effort レベルで実行できるようになりました。タスクの難易度に応じてサブエージェントの推論の深さを調整できます。

🧩

plugin install に --marketplace オプションが追加

claude plugin install --marketplace <source> で、マーケットプレイスの追加とプラグインのインストールを 1 コマンドで行えます。マーケットプレイスの追加には claude plugin marketplace add と同じポリシーチェックが適用されます。

⚡

モッド向け $.model.complete のプロンプトキャッシュ対応

prompt と system がテキストブロックの配列を受け取り、cache: true を付けたブロックまでのリクエストがキャッシュされます。モッドが繰り返し行うモデル呼び出しのコストとレイテンシを下げられます。

🔒

サンドボックス・権限のセキュリティ修正群

UNC パスの読み取りによる権限プロンプトの迂回、読み取り中のリンク差し替えによる承認外ファイルの返却、改ざんされた設定キャッシュによるポリシープラグインの無効化など、権限システムの迂回経路がふさがれました。すべてのユーザーに更新が推奨されます。

🔌

stdio MCP のプロトコルネゴシエーションがデフォルト変更

ローカル (stdio) MCP サーバーの接続が、Bedrock、Vertex、Foundry を含むすべてのインストールでプロトコルバージョン 2026-07-28 をデフォルトでネゴシエートするようになりました (MCP_PROTOCOL_NEGOTIATION=legacy でオプトアウト可能)。

追加機能 (Added: 8 件)

🤖 Agent ツールの effort パラメータ

Claude がサブエージェントを起動する際、要求された effort レベルで実行できます。タスクの難易度に応じてサブエージェントの推論の深さを調整できます。

🧩 claude plugin install --marketplace

必要に応じてマーケットプレイスを追加してから、そこからプラグインをインストールします。マーケットプレイスの追加には claude plugin marketplace add と同じポリシーチェックが適用されます。

⚡ $.model.complete のプロンプトキャッシュ

prompt と system がテキストブロックの配列を受け取り、ブロックに cache: true を付けると、そのブロックまでのリクエストがキャッシュされます。モッドが繰り返し行うモデル呼び出しのコストとレイテンシを下げられます。

💡 モッド向け prompt.autocomplete イベント

モッドがフックして、プロンプト入力欄の補完リストに独自の行を追加できます。

🪝 agent.spawn フックへのワークフローエージェントの提供

ワークフローのエージェントが run とインデックスとともにモッドの agent.spawn フックに渡されるようになり、モッドがそれらを拒否できます。

⏱️ 529 リトライのベース遅延を設定する環境変数

CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS で、過負荷 (529) リクエストをリトライする際のバックオフのベース遅延を長く設定できます。

🏷️ [Claude Tag] Allowed domains カードの Edit ボタン

チャンネルの Configure ページから、Enterprise 管理者がチャンネルのドメインを設定するアクセスバンドルを開けるようになりました。

📊 [Code Review] PRs reviewed チャートの拡充

期間合計と前期間からの変化、リポジトリ別の内訳が Code Review アナリティクスに追加されました。

サンドボックス・権限のセキュリティ修正

本バージョンで特に重要なのが、権限システムの迂回につながる問題の修正群です。

📤 /ultrareview アップロードの読み取り

サンドボックス化されたコマンドが、~/.claude/seed-admin 配下にある /ultrareview アップロードのステージングコピーを読み取れていた問題を修正しました。

🚫 セッション途中の read-deny パス

管理設定のサンドボックス read-deny パス (およびその横のユーザー設定のパス) がセッション途中に出現・変更された場合に、その内側のプロジェクト許可が取り消されず、カバーされるファイルからの資格情報注入も止まらなかった問題を修正しました。

🔗 読み取り中のリンク差し替え

macOS と Windows で、ノートブックや PDF の読み取りが、読み取り中に差し替えられたリンクを通じて承認範囲外のファイルを返せていた問題を修正しました。

🗄️ サーバー管理設定キャッシュの改ざん

設定のフェッチが失敗している間、改ざんされたディスク上のキャッシュがビルトインのポリシープラグインを無効化・置換できていた問題を修正しました。

🪟 Windows の別名表記による削除

ホームフォルダーやドライブの 8.3 短縮名などの別表記に対する rm -rf が、それらの削除として扱われていなかった問題を修正しました。

🌐 UNC パスの読み取り

PreToolUse フックの承認と auto モードが、ネットワーク (UNC) パスからのファイル読み取りで権限プロンプトを迂回していた問題を修正しました。

♻️ allowed-tools ルールの再出現

スキルやスラッシュコマンドの allowed-tools ルールが、そのターンの途中で auto モードやプランモードを抜けた後のターンで復活していた問題を修正しました。

👤 ユーザー専用スキルの起動

/name を繰り返したコンパクション要約によって、ユーザー専用に予約されたスキルを Claude が起動できていた問題を修正しました。

技術的な詳細

⚡ モッド向け $.model.complete のプロンプトキャッシュ

コード例

マーケットプレイスの追加とプラグインのインストールは 1 コマンドで行えます。

Bash 新しいオプション・環境変数の使用例 
# マーケットプレイスを (必要なら) 追加してからプラグインをインストール
claude plugin install my-plugin --marketplace owner/repo

# 過負荷 (529) リトライのベース遅延を延長する
export CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS=5000

# stdio MCP のプロトコルネゴシエーションを旧方式に戻す
export MCP_PROTOCOL_NEGOTIATION=legacy

モッドからのモデル呼び出しでは、ブロック単位のプロンプトキャッシュを利用できます (Changelog の記載に基づく概形)。

JavaScript $.model.complete のプロンプトキャッシュ 
// prompt と system はテキストブロックの配列を受け取り、
// cache: true を付けたブロックまでのリクエストがキャッシュされる
const result = await $.model.complete({
  system: [{ text: longSystemPrompt, cache: true }],
  prompt: [{ text: userInput }],
});

ユースケース / 開発者への影響

🧩 モッド・プラグイン開発者

繰り返しのモデル呼び出しがある場合は $.model.complete の cache: true によるキャッシュを検討できます。prompt.autocomplete イベントで補完候補の拡張、agent.spawn でワークフローエージェントの制御も可能になりました。一方、next(e) 後に拒否するフックは「失敗」として報告されるようになったため、エラーハンドリングの前提の見直しが必要です。また claude plugin test で黙って成功していたテストが失敗するようになる可能性があるため、CI でのテスト結果を確認します。

🔒 セキュリティ・権限設定を運用する組織

UNC パス、read-deny パス、サーバー管理設定キャッシュ、/ultrareview ステージングコピーなど、権限プロンプトの迂回やサンドボックスの読み取り範囲に関わるセキュリティ修正が複数含まれるため、すべてのユーザーに更新が推奨されます。

⚙️ 自動化・MCP を運用する開発者

claude -p・Agent SDK・CI の自動化では、バックグラウンドコマンドと wakeup が待機されるようになり、MCP resources/list を待たない起動で高速化されます。stdio MCP サーバーがプロトコルバージョン 2026-07-28 のネゴシエーションで問題を起こす場合は MCP_PROTOCOL_NEGOTIATION=legacy でオプトアウトしつつ、サーバー側の対応を進めます。256 文字を超えるエージェント名やスキル・プラグインの name は拒否・無視されるため、該当する場合は短縮します。

🚧 移行ガイド (該当する場合)

✅ 破壊的変更はなし

破壊的変更はありませんが、以下の挙動変更に注意が必要です。

  • stdio MCP サーバーは、Bedrock、Vertex、Foundry を含むすべてのインストールでプロトコルバージョン 2026-07-28 をデフォルトでネゴシエートします
  • claude plugin test は、フック内の expect の失敗とエンジンが拒否するスタブ回答をテストの失敗として扱います
  • エージェント名は最大 256 文字に制限されます
  • スケジュール実行と Run now のルーチン実行は、本人のみ閲覧できるアーティファクトを承認なしで公開します

まとめ

Claude Code v2.1.292 は、92 項目 (追加 8 件、修正 64 件、改善 13 件、変更 7 件) からなる大型リリースです。Agent ツールの effort パラメータ、claude plugin install --marketplace、モッド向けの $.model.complete プロンプトキャッシュと prompt.autocomplete など、サブエージェントとプラグインエコシステムを広げる追加が揃いました。

修正の柱は 2 つあります。1 つはサンドボックス・権限システムのセキュリティ修正群であり、UNC パスやリンク差し替えによる承認範囲外アクセス、改ざんされた設定キャッシュによるポリシープラグインの無効化といった迂回経路がふさがれました。もう 1 つはモッド・プラグイン基盤の堅牢化であり、フックワーカーの再起動時にフックが素通りする問題や next(e) の意味論など、権限フックの信頼性に直結する修正が積み上げられました。stdio MCP のプロトコルネゴシエーションのデフォルト変更という足回りの更新も含め、セキュリティ修正の重要性からすべてのユーザーに更新を推奨できるリリースです。
