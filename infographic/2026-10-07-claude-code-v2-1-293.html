Claude Code v2.1.293

Claude Haiku 5.5 がデフォルト Haiku モデルに、コンパクション後の作業取り消し問題の修正、MCP メモリリーク修正など 56 件の変更

📅 2026-10-07 ｜ ソース: Claude Code Changelog

概要

Claude Code v2.1.293 がリリースされました。56 件の変更を含むリリースで、内訳は追加 (Added) 7 件、修正 (Fixed) 36 件、変更・改善 (Changed / Improved) 13 件 (うち取り消し 2 件) です。新モデル Claude Haiku 5.5 の提供開始にあわせたリリースであると同時に、長時間セッション・マルチセッション運用での信頼性を高める修正が中心となっています。

🐦

新モデル Claude Haiku 5.5 がデフォルト Haiku モデルに

claude-haiku-5-5 が追加され、Anthropic API のデフォルト Haiku モデルになりました。1M トークンのコンテキストをサポートし、価格は入力 $0.10 / 出力 $0.50 (100 万トークンあたり、100K トークン超のプロンプトは $0.50 / $2.50) です。

🗜️

コンパクション後の作業取り消し問題の修正

コンテキストのコンパクション後に Claude が自身の直前の作業の完了状態を誤認し、完了した作業を取り消したりやり直したりする問題が修正されました。長時間セッションの信頼性に直結する重要な修正です。

🔌

HTTP MCP 接続のメモリリーク修正

HTTP MCP 接続が、クローズされるまで送信したすべてのリクエストを保持し続けるメモリリークが修正されました。長時間接続で MCP サーバーを利用する開発者に効く修正です。

📜

Bash 経由のファイル閲覧でもルールを読み込み

Bash ツールの cat、head、tail などの単一ファイル閲覧コマンドで、パススコープのルールとネストした CLAUDE.md が読み込まれない問題が修正されました。

🧩

モッド API の拡張

subagentStatusLine への agentType の追加、$.tool.register の isDeferred オプションの追加など、モッド・プラグイン開発者向けの API が拡張されました。

2. エージェント動作の信頼性修正

  • 🗜️ コンパクション後の作業取り消し問題 コンテキストのコンパクション直前に Claude 自身が行った最後のアクションを、コンパクション後に「完了済み」と誤って扱い、完了済みの作業を取り消したりやり直したりすることがある問題を修正しました。長時間セッションでの作業の一貫性に直結する重要な修正です。
  • 🔌 HTTP MCP 接続のメモリリーク HTTP MCP 接続が、クローズされるまで送信したすべてのリクエストを保持し続けるメモリリークを修正しました。
  • 📜 Bash 経由のファイル閲覧時のルール読み込み Claude が Read ツールではなく Bash ツールの単一ファイル向け cat、head、tail、sed -n、grep コマンドでファイルを閲覧した場合に、パススコープのルールとネストした CLAUDE.md ファイルが読み込まれない問題を修正しました。
  • 📨 SendMessage ツールの誤案内 ホスト、権限ルール、--tools リストで SendMessage ツールが削除されたセッション (再開セッションを含む) で、Claude がサブエージェントへの継続指示やメッセージ送信を促されていた問題を修正しました。
  • 🧰 サブエージェントのツール可用性の誤案内 サブエージェントと --agent セッションが、自身のツールリストから外れているだけの組み込みツールを「セッション全体で無効」と案内されていた問題を修正しました。

  • 🏷️ subagentStatusLine に agentType を追加 ステータスラインスクリプトがカスタムサブエージェントの種類を判別できるようになりました。
  • ⚙️ $.tool.register に isDeferred を追加 false を指定すると、ツールのスキーマがツール検索の背後ではなく最初からプロンプトに記載されます。
  • 🧪 claude plugin test と $.session.append $.session.append を呼ぶモッドで claude plugin test が失敗する問題を修正しました。テストは新しい mock.session で追記された行を読み戻せます。
  • 🪝 classic.* イベントのフックのスキップ プラグインフックワーカーの再起動中に、モッドの classic.* イベントのフックがスキップされ、settings のフックだけで応答されていた問題を修正しました。

4. セッション操作・UI の修正

  • ⬅️ ← によるバックグラウンド移動の改善 Claude の作業中に送信したメッセージが、← でセッションをバックグラウンドへ移動した際に失われる問題を修正しました。キュー済みメッセージを移動できない場合は、移動せずその旨を表示します。また、プロンプトに未送信テキストがある場合や質問への回答待ちの場合に 10 秒後にバックグラウンド化してしまう問題、← 直後の権限プロンプトで Esc や No がターンを停止しない問題も修正されました。
  • 🎚️ /model の effort 設定 ←/→ キーが最高・最低レベルを超えて循環し、誤って Low がモデルのデフォルト effort として保存されることがある問題を修正しました。
  • 🔓 claude agents の bypass permissions 同意が .claude/settings.local.json や --settings ファイルにのみ保存されている場合に、バックグラウンドセッションが bypass permissions を無視する問題を修正しました。先に同意を求め、bypass を無視するセッションには常設の通知を表示します。
  • 📋 ペースト処理の修正 同じ語で始まり同じ語で終わるペーストテキストが入力扱いで送信される問題、ペースト直後のアクセント入力でスキル名が入力扱いになる問題を修正しました。
  • ⌨️ vim モードの修正 スペースのみの行での >>・<< のカーソル位置、Visual mode での行削除後のカーソル位置と . の動作を修正しました。
  • 🧹 claude purge の改善 ファイルやフォルダーを削除できない場合に黙って停止 (exit 0 またはハング) する問題を修正しました。残りを削除し、削除できなかったものを列挙して exit 1 で終了します。

技術的な詳細

🗜️ コンパクション後の作業認識の修正

長時間セッションではコンテキストが上限に近づくと会話が自動的にコンパクション (要約・圧縮) されます。v2.1.292 以前は、コンパクション直前の Claude 自身のアクションの完了状態が要約に正しく反映されず、完了済みの作業を未完了と見なして取り消す、あるいはやり直すことがありました。

📜 Bash 経由のファイル閲覧とルール読み込み

Claude Code は、Read ツールでファイルを閲覧した際にパススコープのルール (path-scoped rules) やネストした CLAUDE.md を文脈として読み込みます。v2.1.292 以前は、Claude が Read ツールの代わりに Bash ツールの cat、head、tail、sed -n、grep といった単一ファイル向けコマンドでファイルを閲覧すると、この読み込みが行われませんでした。v2.1.293 からは、どちらの経路でも同じようにルールが適用されるため、ディレクトリごとの規約やガイドラインの実効性が向上します。

コード例

モッドからツールを登録する際、isDeferred: false を指定するとツール検索の背後に置かれず、最初からプロンプトにスキーマが記載されます。

JavaScript モッドのフックモジュールでのツール登録 
// モッドのフックモジュールでのツール登録
$.tool.register({
  name: "my_tool",
  description: "常に利用可能にしたいツール",
  // false: ツール検索の背後ではなく、最初からスキーマをプロンプトに記載する
  isDeferred: false,
  /* input schema, handler など */
});

claude plugin test では、$.session.append で追記した行を新しい mock.session で読み戻してテストできます。

  • 🐦 Haiku モデルの利用者 デフォルト Haiku モデルが Claude Haiku 5.5 になりました。100K トークン超のプロンプトでは価格が $0.50 / $2.50 に上がる 2 段階価格のため、1M コンテキストを活用する場合はコストへの影響を確認します。

🚧 移行ガイド (該当する場合)

⚠️ 注意が必要な挙動変更

破壊的変更はありませんが、以下の挙動変更に注意が必要です。

ユースケース

🐦 サブエージェント・バックグラウンド処理での Haiku 5.5 活用

Claude Haiku 5.5 は入力 $0.10 / 出力 $0.50 (100 万トークンあたり) の低価格で 1M トークンのコンテキストを持つため、サブエージェントでの大量のファイル読み込みや探索タスク、バックグラウンドの定型処理などに適しています。100K トークン超のプロンプトでは $0.50 / $2.50 の 2 段階価格になる点を踏まえて、コストと性能のバランスを設計できます。

🗜️ 長時間セッションでの大規模リファクタリング

コンパクションが複数回発生するような長時間の作業でも、直前に完了した作業が「未完了」と誤認されて取り消される問題が解消されました。コンパクション後も作業の一貫性が保たれるため、大規模なリファクタリングや複数ファイルにまたがる変更を安心して任せられます。

📜 ディレクトリごとの規約運用の実効性向上

パススコープのルールやネストした CLAUDE.md でディレクトリごとの規約を管理しているチームでは、Claude が Bash の cat や head でファイルを閲覧した場合でも規約が読み込まれるようになり、Read ツール経由と同じガイドラインの実効性が得られます。

まとめ

Claude Code v2.1.293 は、56 件 (追加 7 件、修正 36 件、変更・改善 13 件、うち取り消し 2 件) からなるリリースです。最大のトピックは Claude Haiku 5.5 の追加で、1M コンテキストと入力 $0.10 / 出力 $0.50 (100 万トークンあたり) という低価格により、サブエージェントやバックグラウンド処理での軽量モデル活用の幅が広がります。

品質面では、コンパクション後に完了済みの作業を取り消す問題の修正が長時間セッションの信頼性を大きく改善するほか、HTTP MCP のメモリリーク修正、Bash 経由のファイル閲覧でもパススコープのルールと CLAUDE.md が読み込まれる修正など、エージェントの実運用に効く修正が揃いました。モッド開発者には agentType・isDeferred・mock.session の追加が、Slack 連携を使う組織には Claude Tag の修正群が、それぞれ着実な改善となります。Haiku 5.5 の 2 段階価格とクラウドセッションのウェイクアップ修正の取り消しには注意しつつ、幅広い利用者に更新を推奨できるリリースといえます。
