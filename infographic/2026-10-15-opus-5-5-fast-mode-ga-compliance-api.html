Claude API ファストモード Compliance API

Claude Opus 5.5 ファストモードがリサーチプレビュー終了、Compliance API にユーザー設定取得機能を追加

📅 2026-10-15 | ソース: Claude Developer Platform Release Notes

Claude Opus 5.5 のファストモードがアクセス申請・ベータヘッダー不要で一般提供に。Azure ホストの Microsoft Foundry にも提供範囲が拡大し、Compliance API にはユーザー設定取得エンドポイント (ベータ) が追加されました。

概要

⚡

Opus 5.5 ファストモードがリサーチプレビューを終了

アクセス申請が不要になり、fast-mode-2026-02-01 ベータヘッダーなしで利用できるようになりました (送信し続けても動作は継続します)。

📊

各使用ティアにデフォルトレート制限を設定

Start、Build、Scale の各使用ティアにデフォルトのファストモードレート制限が設定されました。Evaluation ティアの組織は、Start、Build、Scale ティアに移行するとファストモードを利用できます。

🪟

Claude in Microsoft Foundry でも提供開始

Azure でホストされるデプロイメント向けに、Claude in Microsoft Foundry で Opus 5.5 のファストモードが利用可能になりました。Anthropic でホストされる Microsoft Foundry デプロイメントでは利用できません。

🛡️

Compliance API にユーザー設定取得エンドポイントを追加 (ベータ)

組織メンバーが claude.ai で保存した「Instructions for Claude」および Cowork の「Global instructions」のテキストを取得できます。Claude Enterprise 組織向けのベータ機能です。

🔬

Opus 5 / Opus 4.8 は引き続きリサーチプレビュー

Claude Opus 5 と Claude Opus 4.8 のファストモードはリサーチプレビューのままであり、これらのモデルにはベータヘッダーの送信とアクセス申請が引き続き必要です。

背景

ファストモードは、同一のモデルをより高速な推論構成で実行する機能であり、標準速度と比較して最大 2.5 倍の出力トークン毎秒 (OTPS) を実現します。モデルの重みや動作は変わらず、知能や機能に変化はありません。2026 年 2 月のリサーチプレビュー開始以降、利用にはアクセス申請と fast-mode-2026-02-01 ベータヘッダーの送信が必要でした。

Compliance API は、Claude Enterprise 組織のコンプライアンス担当者が組織内のデータを監査するための API であり、これまでにチャットデータ取得などのエンドポイントが提供されてきました。

Before / After: Opus 5.5 ファストモード

Before (リサーチプレビュー)

  • アクセス申請が必要
  • fast-mode-2026-02-01 ベータヘッダーの送信が必須
  • 提供は Claude API のみ

After (一般提供)

  • アクセス申請は不要
  • ベータヘッダー不要 (speed: "fast" の指定のみ)
  • Start / Build / Scale ティアにデフォルトレート制限を設定
  • Claude in Microsoft Foundry (Azure ホスト) でも利用可能

主な変更点

⚡ Opus 5.5 ファストモードの GA

アクセス申請とベータヘッダーが不要になり、speed: "fast" を設定するだけで利用できます。Start、Build、Scale の各使用ティアにデフォルトのファストモードレート制限が設定されました。Evaluation ティアの組織は上位ティアへの移行で利用可能になります。

🪟 Microsoft Foundry での提供

Azure でホストされるデプロイメント向けに、Claude in Microsoft Foundry で Opus 5.5 のファストモードが利用可能になりました。Anthropic でホストされる Microsoft Foundry デプロイメントでは利用できない点に注意が必要です。

🛡️ Compliance API の新エンドポイント

各組織メンバーが claude.ai で保存した「Instructions for Claude」および Cowork の「Global instructions」のテキストを返すエンドポイントが追加されました。Claude Enterprise 組織向けのベータ機能で、既存の Compliance Access Key と read:compliance_user_data スコープで呼び出します。

技術的な詳細

🚀 ファストモードの利用方法

リクエストに speed: "fast" を設定するだけで有効化できます。レスポンスの usage.speed フィールドで、実際に使用された速度 ("fast" または "standard") を確認できます。

🗂️ 対応モデルとプラットフォーム

モデル 対応プラットフォーム ステータス
Claude Opus 5.5 (claude-opus-5-5) Claude API (Managed Agents 含む)、Claude in Microsoft Foundry (Azure ホスト) 一般提供
Claude Opus 5 (claude-opus-5) Claude API (Managed Agents 含む) リサーチプレビュー
Claude Opus 4.8 (claude-opus-4-8) Claude API (Managed Agents 含む) リサーチプレビュー

📏 ファストモードのレート制限

ファストモードには標準の Opus レート制限とは別の専用レート制限があります。制限を超えると API は retry-after ヘッダー付きの 429 エラーを返します。レスポンスヘッダー (anthropic-fast-input-tokens-limit など) でファストモードのレート制限状況を確認できます。

🚧 ファストモードの制約事項

ドキュメントによると、以下の制約があります。

  • ファストモードと標準速度を切り替えるとプロンプトキャッシュが無効になる (異なる速度のリクエストはキャッシュされたプレフィックスを共有しない)
  • 速度向上は出力トークン毎秒 (OTPS) に焦点があり、最初のトークンまでの時間 (TTFT) は対象外
  • Batch API では利用できない
  • Priority Tier コミットメントでは利用できない
  • Claude Platform on AWS では現在利用できない

料金情報: ファストモード料金

ファストモードは標準料金に対するプレミアム価格で提供され、200K 入力トークンを超えるリクエストを含むフルコンテキストウィンドウに適用されます。

モデル 入力 出力
Claude Opus 5.5 $8 USD / MTok $40 USD / MTok
Claude Opus 5 / Claude Opus 4.8 $10 USD / MTok $50 USD / MTok
ℹ️ 補足: プロンプトキャッシュやデータレジデンシーの料金乗数は、ファストモード料金の上に重ねて適用されます。

API 変更点

🔁 ヘッダー変更: ファストモード

対象 変更内容
Claude Opus 5.5 へのリクエスト fast-mode-2026-02-01 ベータヘッダーが不要に (送信し続けても動作は継続)
Claude Opus 5 / Opus 4.8 へのリクエスト ベータヘッダーの送信とアクセス申請が引き続き必要
レスポンスヘッダー anthropic-fast-input-tokens-limit などでファストモードのレート制限状況を確認可能。超過時は retry-after 付き 429 エラー

➕ 新エンドポイント: Compliance API ユーザー設定取得 (ベータ)

項目 内容
エンドポイント GET /v1/compliance/organizations/{org_uuid}/user_preferences
認証 既存の Compliance Access Key と read:compliance_user_data スコープ
返されるデータ 各組織メンバーが claude.ai で保存した「Instructions for Claude」および Cowork の「Global instructions」のテキスト
対象 Claude Enterprise 組織 (ベータ)

コード例

Claude Opus 5.5 でファストモードを利用する例 (ベータヘッダー不要)。

Python Opus 5.5 ファストモードの利用 
import anthropic

client = anthropic.Anthropic()

response = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=4096,
    speed="fast",  # ファストモードを有効化
    messages=[
        {"role": "user", "content": "Refactor this module to use dependency injection"}
    ],
)

# 実際に使用された速度を確認
print(response.usage.speed)  # "fast" または "standard"

Compliance API でユーザー設定を取得する例。

Bash Compliance API ユーザー設定の取得 
curl "https://api.anthropic.com/v1/compliance/organizations/{org_uuid}/user_preferences" \
  -H "x-api-key: $COMPLIANCE_ACCESS_KEY" \
  -H "anthropic-version: 2023-06-01"

開発者への影響・ユースケース

🎯 対象

Claude Opus 5.5 を利用する API 開発者

特に Start、Build、Scale ティアの組織。アクセス申請なしで speed: "fast" を設定するだけで、最大 2.5 倍の出力速度を本番ワークロードに適用できます。

Azure 上で Claude in Microsoft Foundry を利用する開発者

Azure でホストされるデプロイメントで Opus 5.5 のファストモードが利用できるようになり、Azure 環境のまま高速な推論構成を選択できます。

Claude Enterprise 組織のコンプライアンス担当者・監査ツール開発者

新しいユーザー設定取得エンドポイントにより、組織メンバーが保存したカスタム指示 (Instructions for Claude、Cowork の Global instructions) を監査対象に含められます。

✅ 必要なアクション

  1. Opus 5.5 でファストモードを使う開発者: アクセス申請は不要。リクエストに speed: "fast" を設定するだけで利用できます。fast-mode-2026-02-01 ベータヘッダーは削除してかまいません (残しても動作します)
  2. Opus 5 / Opus 4.8 でファストモードを使う開発者: 引き続きリサーチプレビューのため、ベータヘッダーの送信とアクセス申請が必要です
  3. Compliance API 利用者: 既存の Compliance Access Key に read:compliance_user_data スコープを付与し、新エンドポイントを呼び出します

🔀 移行ガイド

Opus 5.5 向けのファストモードリクエストからベータヘッダーを削除できます。ただし削除は必須ではなく、ヘッダーを送信し続けてもリクエストは正常に動作します。旧モデルでファストモードを利用していた場合は、ファストモード対応モデルへの移行が推奨されています。

まとめ

Claude Opus 5.5 のファストモードがリサーチプレビューを終了し、アクセス申請やベータヘッダーなしで speed: "fast" を指定するだけで最大 2.5 倍の出力速度を利用できるようになりました。Start、Build、Scale ティアにはデフォルトレート制限が設定され、Azure ホストの Microsoft Foundry にも提供範囲が拡大しました。一方、Opus 5 と Opus 4.8 のファストモードは引き続きリサーチプレビューである点に注意が必要です。

あわせて Compliance API にユーザー設定取得エンドポイントが追加され、Claude Enterprise 組織の監査機能が強化されました。
