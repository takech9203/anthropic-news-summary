💡 概要 (キーポイント)

🔀

API version 移行支援コマンドの追加

API version 2026-10-21 への移行を支援する /claude-api api-version コマンドが追加された。

📡

安全機構の介入を記録する OpenTelemetry イベント

権限ルール、auto モード、安全性チェック、フック、サンドボックスの介入を記録する claude_code.safety_event イベントが追加された。

🔌

MCP サーバー接続の信頼性向上

macOS キーチェーンロック時の表示、スリープ中の接続タイムアウト、HTTP MCP ツール呼び出しの二重送信防止など、MCP まわりの修正が多数含まれる。

🔁

解析不能なツール呼び出しのリトライとフォーク改善

ツール呼び出しが解析できない場合に最大 2 回リトライするようになり、フォークサブエージェントの同時起動時の取り違えも大幅に減少した。

🌐

周辺機能にも広く変更

VSCode 拡張、Cloud sessions、自己ホスト型ランナー、Code Review (@claude review stop の追加) など、複数の実行環境に変更が及んでいる。

🕐 背景: 変更が及ぶ範囲

✨ 新機能 (追加)

🔀 /claude-api api-version コマンド

Claude API を利用するコードを API version 2026-10-21 へ移行するためのコマンドが追加された。

📡 claude_code.safety_event OpenTelemetry イベント

権限ルール、auto モード、安全性チェック、フック、サンドボックスのいずれかがツール呼び出しを停止・確認 (プロンプト) ・差し戻しした際に、その都度記録されるイベントが追加された。

🔍 Code Review@claude review stop

@claude review always によるプルリクエストのレビュー購読を、新しいレビューを開始せずに終了できるコマンドが追加された。off、pause も利用可能。

🎤 VSCode音声入力停止時の通知

音声入力が自動停止した場合 (認識可能な音声が 15 秒ない、または 2 分の上限到達)、マイクボタンに理由と「それまでのテキストは保持される」旨の通知が表示されるようになった。

🐛 主なバグ修正 (26 件)

🤖 モデル・API 関連 3 件

  • CLAUDE_CODE_DISABLE_1M_CONTEXT 設定時に、opus[1m] のような [1m] サフィックス付きエイリアスのモデルでリクエストが model-not-found エラーになる問題を修正
  • カスタム ANTHROPIC_BASE_URL ゲートウェイの背後や Foundry 上で、効果のない prompt-caching-scope ベータヘッダーが送信されていた問題を修正
  • Agent SDK の setModel() によるモデル切り替え (およびその上に構築されたアプリ) が、API の確認に 5 秒以上かかると拒否されていた問題を修正。最大 15 秒まで待機するようになった

🔌 MCP サーバー関連 5 件

  • macOS でログインキーチェーンがロックされている間、claude -p で MCP サーバーが「needs authentication」と表示されていた問題を修正。理由が表示されるようになり、ロック解除後の次回実行では再サインインなしで接続される
  • macOS または Linux で接続中にコンピューターがスリープすると、MCP サーバーがタイムアウトとして報告され、ヘッドレス実行では失敗したままになる問題を修正
  • 呼び出し中に接続が閉じた際、HTTP MCP ツール呼び出しが 2 回送信される問題を修正。読み取り専用または冪等なツールのみがリトライされるようになった
  • バックグラウンドタスクの実行中に、SDK MCP サーバーの最新のツールなしでターンが開始されることがある問題を修正
  • デスクトップアプリの Code タブで、直接設定された GitHub MCP サーバーの書き込みツールが、何も作成せずに閉じるフォームを表示していた問題を修正

☁️ セッション・クラウド関連 8 件

  • 多数の PDF ページ、画像、その他の大きなツール結果を読み取ったターンで発生していた一部の「Autocompact is thrashing」エラーを修正
  • クラウドセッションの /autocompact が、セッション再起動後にデフォルトのウィンドウに戻ってしまう問題を修正
  • /clear で消去した会話が、クラウドまたは自己ホスト型ランナーのセッション再起動時に復活することがある問題を修正
  • Claude apps gateway セッションで CLAUDE_STREAM_FIRST_BYTE_TIMEOUT_MS が無視されていた問題を修正
  • OTEL_EXPORTER_OTLP_HEADERS 設定時に、Claude apps gateway 背後の Claude Desktop セッションからのテレメトリが拒否される問題を修正
  • Cowork クラウドセッションの WebFetch が、サイトの 4xx 応答や robots.txt による拒否をツールエラーとして報告していた問題を修正。ローカルセッションと同様に通常の結果として扱われる
  • Cloud sessions検索の実行中にリポジトリピッカーが「No repositories match」と表示していた問題を修正。結果が届くまで「Searching…」と表示される
  • Cloud sessions自己ホスト環境で「Waiting for a runner」の表示が途切れていた問題を修正。オンデマンドランナーでは最後のメッセージからの経過時間と失敗した試行が表示される

🖥️ UI・その他 10 件

  • /permissions の「Recently denied」に拒否されたシェルコマンドが表示されず、auto モードのローカル分類器がリトライされたコマンドの確認時にそこでの承認を無視していた問題を修正。行の承認時には説明ではなくコマンド名が表示される
  • /help と / コマンドメニューが、/claude-api などのバンドルスキルについて短い説明ではなく長いモデル向け説明を表示していた問題を修正
  • ストリーミング応答で、サブエージェントのトランスクリプトにプレースホルダーのトークン使用量と空の停止理由が記録されていた問題を修正
  • 接続されたアプリ経由で停止されたバックグラウンドコマンド (デスクトップアプリがアイドルセッションをアーカイブした場合など) が、ユーザーによる停止として Claude に報告されていた問題を修正。通知には出力ファイル名が示される
  • 再利用された接続をサーバーが閉じていた場合に、Artifact ツールの読み取りが接続リセットで失敗する問題を修正
  • 自己ホスト型ランナー: --use-anthropic-git-proxy を使用するセッションが、以前のセッションがクローンに残した .claude/settings.local.json をコミットしてしまう問題を修正
  • 自己ホスト型ランナー: チェックアウトフックの実行中にセッションのアーカイブ・再キュー・ランナーの停止を行うと、フックのプロセスが実行されたままになり、ランナーのスロットが占有され続ける問題を修正
  • VSCode「Show more」で展開した長いプロンプトがチャットパネル全体を覆っていた問題を修正。固定表示されるプロンプトはパネルの 40% までに制限され、スクロールできる
  • VSCodeLaTeX 数式を含むリスト項目やテーブルセルの一部が、リッチテキストエディターに新しいリストやテーブルとして貼り付けられる問題を修正
  • VSCodeNODE_EXTRA_CA_CERTS が ~/.claude/settings.json にのみ設定されている場合、TLS 検査プロキシの背後で音声入力が失敗する問題を修正。CLAUDE_CODE_CERT_STORE にも従うようになった

⚡ 改善

🔁 解析不能なツール呼び出しからの回復

ツール呼び出しが解析できない場合、エラーでターンを終了する前に最大 2 回リトライするようになった。

🍴 フォークサブエージェントの同時起動

同時に起動された各フォークに、どの起動が自分のものかが伝えられるようになり、フォーク同士が互いの作業を始めてしまう可能性が大幅に減少した。

🔑 ブラウザーサインイン

アカウントプロフィールの読み込みを待たず、サインイン完了と同時に成功ページが表示されるようになった。

🔎 Web 検索エラーの表示

クラウドおよび自己ホスト型ランナーのセッションで、理由付きの 403 で拒否された検索は、汎用的な「Authentication error」ではなくその理由を表示するようになった。

⏱️ クラウドセッションの初回応答時間

デスクトップアプリの MCP サーバーのいずれかが接続できない場合の、最初の応答までの時間が短縮された。

📱 Remote Control の接続時間

トランスクリプトに大きな貼り付け画像や PDF 読み取りを含むセッションの接続時間が改善された。

🔄 動作変更

🔍

WebSearch 予算の通知

WebSearch の予算を使い切った際に Claude へ送られる通知が、ブラウザーやコンピューター操作経由でも検索エンジンに問い合わせないよう指示する内容に変更された。

♿

axScreenReader 設定の適用範囲

axScreenReader 設定と settings の env ブロック内の CLAUDE_AX_SCREEN_READER は、ユーザー設定、管理設定、--settings 設定からのみ適用されるようになった (v2.1.305 から)。

⏲️

自己ホスト型ランナーのチェックアウトフック

チェックアウトフックはデフォルトで 30 分後に停止され、セッションのセットアップが失敗するようになった。より長い時間が必要な場合は --checkout-hook-timeout-min を引き上げるか 0 に設定する。

📜

自己ホスト型ランナーの証明書フィルタリング

Anthropic 管理の git 用に構築される証明書ファイルが、CLI と同様に信頼する証明書をフィルタリングするようになった。除外された数は [runner:warn] 行に表示される。

🧩

VSCode「still open somewhere else」通知

拡張機能の再起動で残った Claude プロセス (通常は約 10 分以内に自然終了する) もこの通知の対象になった。

🔐

VSCode証明書の扱い

音声入力と拡張機能自身のリクエストが、CLI と同様に信頼する証明書をフィルタリングするようになった。拡張機能のリクエストは、環境またはユーザー設定で指定された NODE_EXTRA_CA_CERTS ファイルも信頼する。

  • 🛠️Claude Code CLI / VSCode 拡張 / Cloud sessions / 自己ホスト型ランナーのすべてのユーザー
  • 🔌MCP サーバーを利用・開発しているユーザー (特に macOS 環境、HTTP MCP サーバー)

  • 💻Claude API を利用するコードを保守している開発者

✅ 必要なアクション

アップデートの適用

claude update または npm 経由で v2.1.307 に更新する。HTTP MCP ツール呼び出しの二重送信防止など、副作用に関わる修正が含まれるため、MCP サーバーを利用している場合は早期の適用を推奨する。

API version 移行

Claude API を利用するコードがある場合、/claude-api api-version を実行すると API version 2026-10-21 への移行を支援してもらえる。

テレメトリ管理者

claude_code.safety_event イベントを収集パイプラインに組み込むことで、権限ルール、auto モード、安全性チェック、フック、サンドボックスによる介入を可視化できる。

自己ホスト型ランナー管理者

チェックアウトフックに 30 分を超える処理がある場合、--checkout-hook-timeout-min の調整が必要になる。

Code Review 利用者

常時レビューの購読を解除したいプルリクエストでは @claude review stop を利用できる。

🧭 移行ガイド

破壊的変更はないが、以下の動作変更に注意が必要である。

  • 自己ホスト型ランナーのチェックアウトフックは、デフォルトで 30 分後に停止されるようになった
  • axScreenReader 設定と settings の env ブロック内の CLAUDE_AX_SCREEN_READER は、ユーザー設定、管理設定、--settings 設定からのみ適用される
  • 接続断時の HTTP MCP ツール呼び出しのリトライは、読み取り専用または冪等なツールに限定される

📝 まとめ

v2.1.307 は、API version 2026-10-21 への移行支援コマンドと安全機構の OpenTelemetry イベントという 2 つの新機能に加えて、MCP サーバー接続の信頼性向上とクラウドセッションの安定化を中心とした保守リリースである。特に HTTP MCP ツール呼び出しの二重送信防止は副作用のあるツールの安全性に直結するため、MCP サーバーを活用している開発者は早めのアップデートが望ましい。
