主要機能

🏢 code ポリシーキー

Claude apps gateway の managed.policies[] に追加。cli と同じ設定内容を持ち、Claude Desktop の Code タブにも適用される。desktop キーと併用するとゲートウェイモードが有効化。セッションを開始できない場合は理由が返信として表示される。

🗜️ autoCompactWindow

サブエージェントのフロントマターと --agents 定義に追加。メイン会話より早いタイミングで自動コンパクトを発動でき、大量のファイルを読むサブエージェントのコンテキスト溢れを個別に防げる。

⚙️ CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL

すべてのワークフローエージェントを 1 つのモデルで実行する環境変数。ワークフロー以外のサブエージェントは各自のモデル設定を維持する。529 エラー対策の CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS も追加。

📖 Read ツールの allow_large

コンテキストに余裕がある場合、通常のサイズ制限を超えるテキストファイルを 1 回の呼び出しで読み切れる。従来の offset / limit による分割読み込みが不要になり、往復回数を削減。

🛡️ セキュリティ修正

BASH_ARGV0 代入による権限チェックバイパスを修正し、該当コマンドは承認を求めるように。シークレットのマスキング漏れ、Git Bash の rm -rf 確認漏れ、managed settings の hook の強制力も修正。

📝 非 UTF-8 ファイルの破壊防止

Edit / NotebookEdit が Shift-JIS、Windows-1252、GBK などのファイルの非 ASCII 文字を壊す問題を修正。該当ファイルへの編集は拒否されるようになり、日本語環境のレガシーファイルを保護。

💰 Sonnet 5.5 のキャッシュ読み取り価格の更新

Before

$0.20 / MTok

従来のキャッシュ読み取り価格で /cost や --max-budget-usd を計算

After

$0.10 / MTok

/cost、ステータスライン、--max-budget-usd、SDK のコスト計算が新価格に対応。キャッシュ読み取りはセッションのトークンの大半を占めることが多く、表示コストと予算判定が実態に合わせて下がる

💻 コードサンプル

サブエージェントのフロントマターで autoCompactWindow を指定する例。このサブエージェントはメイン会話よりも早いタイミングで自動コンパクトを行う (値は例示)。

Markdown .claude/agents/log-analyzer.md 
---
name: log-analyzer
description: 大量のログファイルを解析するサブエージェント
autoCompactWindow: 100000
---

ログファイルを読み込み、エラーパターンを抽出して要約する。

ワークフローエージェントのモデルを一括指定する環境変数の例。

Bash ワークフローのモデルを一括指定 
export CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL=haiku

その他の修正・変更 (抜粋)

  • 🧩headless / SDK: 無効化された .mcp.json やプラグイン MCP サーバーがリロード後に起動する問題、UserPromptSubmit hook 中の割り込みが headless セッションを終了させる問題などを修正。
  • 🔑ゲートウェイとログイン: allowedProviders の "gateway" 指定による締め出し、forceLoginMethod: gateway で保存済みサインインが無視されるリグレッションを修正。
  • 🔤Unicode: U+2028 / U+2029 を含むメッセージが保存トランスクリプトから欠落する問題と、claude purge が履歴ファイルに残す問題を修正。
  • 🪟Windows: 約 1 KB を超える PowerShell コマンドが常に許可を求めていた問題を修正し、allow ルールが 32 KB まで適用に。stdio MCP サーバーのシャットダウン手順も改善。
  • 🔄動作変更: MCP ツール説明と instructions のデフォルト上限が 2,048 文字から 4,096 文字に拡大。← でのバックグラウンド移動時、進行中のターンや ! コマンドは停止されるように。
  • 🧰VSCode / Cloud sessions / Claude Tag / Code Review: Claude in Chrome のブラウザー操作前確認、Activity タブのステータスフィルター追加、Memory タブでのメモリファイル管理、PR チェックが「in progress」のまま残る問題の修正など計 17 件。

ユースケース

🏢 エンタープライズ管理者: Claude Desktop の Code タブを一元管理

Claude apps gateway を運用する組織は、managed.policies[] に code キーを追加するだけで、CLI 向けに整備したポリシーを Claude Desktop の Code タブにもそのまま展開できる。desktop キーと併用すればゲートウェイモードも有効化できる。

🤖 開発者: コンテキスト消費の激しいサブエージェントの安定化

大量のログ解析やコードベース探索を行うサブエージェントに autoCompactWindow を指定して途中破綻を防止。ワークフロー全体を軽量モデルで動かしたい場合は CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL で一括指定できる。

📝 日本語環境: Shift-JIS レガシーファイルの保護とコスト管理

Shift-JIS など非 UTF-8 のレガシーファイルを含むリポジトリでは、Edit による文字化け破壊が防止される (該当ファイルへの編集は拒否)。Sonnet 5.5 利用時は /cost と --max-budget-usd がキャッシュ読み取り $0.10 で計算され、予算判定が実態に合う。
