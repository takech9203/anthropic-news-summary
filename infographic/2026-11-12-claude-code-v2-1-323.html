主要機能・変更点

⚡ Code Mode (実験的)

Claude が JavaScript を書いてツールを呼び出す。従来の 1 回ずつの呼び出しと異なり、複数のツール呼び出しをプログラムとして組み合わせられる。有効化と組織単位での無効化の手順は公式ドキュメントに記載

🧩 プラグイン開発者向け強化

  • engines["claude-code"] で対応バージョン範囲を宣言。範囲外ではインストール・更新・ロードされない
  • claude plugin validate が TypeScript フックを型チェック (--strict で失敗扱い)
  • mod の engine.create フック検証を追加
  • プラグインの agent 設定が非推奨に

🔒 セキュリティ・権限の修正

  • Bash(ls*) など接尾ワイルドカード付き allow ルールの権限プロンプト省略を修正
  • sudo や env などラッパー経由のコマンドを deny / ask ルールが見逃す問題を修正
  • サンドボックスのシンボリックリンク経由の書き込みを無効化
  • シークレットを含むように見えるルールはセッション限りに

🔑 認証・サインインの修正

  • /fork や --bg で別のサインインへ移る問題を修正
  • MCP ツールが TOKEN_EXPIRED で終了する代わりに再サインインを要求
  • /login と claude setup-token のエラー表示を改善

🚀 安定性・パフォーマンス

  • 巨大ファイル変更後のメモリ急増を修正
  • /compact 再実行時の未応答メッセージ喪失を修正
  • 多数のサブエージェント使用時のメモリ使用量を改善
  • WebFetch の速度とメモリ使用量を改善

⚠️ 注意が必要な挙動変更

  • 未知のモデル ID のコンテキストウィンドウ既定値が 200K から 1M に変更 (CLAUDE_CODE_DISABLE_1M_CONTEXT=1 で維持)
  • v1 MCP クライアントが削除 (互換モードとして動作)
  • セッション間メッセージ上限が約 20 から 100,000 に拡大
  • 内部の ripgrep / git がトークンなしで実行され漏えいを防止

技術詳細 - Code Mode の仕組み

従来のツール呼び出しでは、Claude がツールを 1 回呼び出すたびにモデルとの往復が発生する。Code Mode では Claude が JavaScript コードを生成し、そのコード内から複数のツールを呼び出すため、ループ処理や中間結果の加工をコード側で完結できる。

🧩 plugin.json のバージョン範囲指定

プラグインが対応する Claude Code のバージョン範囲を engines["claude-code"] で宣言できる。npm の engines フィールドに似たセマンティクスで、プラグインの互換性を宣言的に管理できる。

JSON plugin.json の engines 設定例 
{
  "name": "my-plugin",
  "version": "1.2.0",
  "engines": {
    "claude-code": ">=2.1.323"
  }
}
動作: 範囲外の環境ではプラグインはインストール・更新・ロードされず、インストールと更新は範囲に収まる最新バージョンを自動的に選択する

ユースケース - 開発者への影響

👩‍💻 Claude Code を日常利用する開発者

セキュリティ修正が多数含まれるため、早期のアップデートを推奨。Code Mode を試す場合は公式ドキュメント (https://code.claude.com/docs/en/code-mode) で有効化手順を確認する。Bash(ls*) のような接尾ワイルドカードや変数名を含む allow ルールの挙動が変わったため、保存済みの権限ルールが期待どおりに動作するか見直す

🧩 プラグイン開発者

plugin.json に engines["claude-code"] を追加して互換範囲を宣言し、claude plugin validate --strict で TypeScript フックの型エラーを確認する。非推奨になった agent 設定は、将来の削除に備えて移行を検討する

🏢 組織の管理者・他ベンダーモデル利用者

Code Mode の組織単位での有効化・無効化を検討し、セキュリティ修正を適用する。1M 未満のコンテキストウィンドウを持つ未知のモデル ID を使う場合は CLAUDE_CODE_DISABLE_1M_CONTEXT=1 の設定を検討する。v1 MCP クライアント利用者は、互換モード (MCP_SDK_GENERATION=v1) での動作確認のうえ通常の v2 への移行を推奨

まとめ

Claude Code v2.1.323 は、ツール呼び出しの新パラダイムとなり得る Code Mode を実験的に導入しつつ、Bash 権限チェック・サンドボックス・認証まわりの大量の堅牢化を取り込んだ大型リリースである。プラグイン開発者には engines によるバージョン範囲指定と TypeScript フックの型チェックという実用的なツールが提供された。セキュリティ修正の比重が大きいため、すべての利用者に早期のアップデートを推奨する。Code Mode はオプトインの実験的機能であり、挙動の詳細は公式ドキュメントで確認したうえで試すことが望ましい
