GSA との提携拡大により Claude をあらゆるレベルの政府機関へ提供

2026-10-27 | Anthropic News

概要

💰

Claude 製品を 40% 割引で提供

GSA (米国一般調達局) との提携拡大により、Claude Enterprise、Claude for Government、Claude API のすべてに割引を適用。Anthropic として初めて全製品が割引対象となる。

🏛️

連邦政府に加え SLTT 政府も対象

連邦政府だけでなく、州・地方・部族・準州 (SLTT) の政府機関も割引の対象となる。

🛒

OneGov 割引価格で発表当日から購入可能

GSA の Multiple Award Schedule を通じて購入できる。今後数か月以内にクラウドプロバイダー経由の購入にも適用予定。

📊

政府全体で 10 億ドルの節約見込み

最低支出額のコミットメントは不要で、使用した分だけ支払う従量課金方式を採用している。

📈

政府部門での需要が急拡大

現在約 500 の米国連邦・州・地方政府組織が Claude を使用。Claude for Government の週間アクティブユーザーは 2 月比で約 8 倍、連邦文民機関での使用は 1 年で約 20 倍に成長。

新契約の主要ポイント

💰 40% 割引

Claude Enterprise、Claude for Government、Claude API のすべてに適用。Anthropic として初めて全製品が割引対象になる。

🏛️ 連邦・SLTT 政府機関が対象

連邦政府に加え、州・地方・部族・準州 (SLTT) の政府も割引の対象となり、あらゆるレベルの政府機関が利用できる。

💳 従量課金方式

最低支出額のコミットメントは不要。使用した分だけ支払う柔軟な方式で、導入の障壁を下げる。

🛒 GSA Multiple Award Schedule

OneGov 割引価格での購入が発表当日から可能。今後数か月以内にクラウドプロバイダー経由の購入にも適用予定。

🤝 導入支援プログラム

民間顧客向けのベストプラクティスを公共部門に展開する専用プログラムを今後数週間以内に開始予定。

セキュリティ要件への対応

🛡️
Claude for Government: FedRAMP High 認証レベルで商用版とほぼ同等の機能を提供。2026 年 9 月 30 日に一般提供を開始
☁️
Amazon Bedrock 経由: FedRAMP High 認証。一部モデルは AWS GovCloud で DoD IL4・IL5 ワークロードに対応
☁️
Google Cloud Vertex AI 経由: FedRAMP High 認証
🏢
Claude Enterprise: FedRAMP 20x プログラムを通じて FedRAMP Moderate 認証を申請中

政府機関での活用実績

🏔️ ユタ州: 開発者の生産性向上

10 の州機関の開発者 34 名に Claude Code を提供。80% が 30 分以内に環境を構築し、71% が 4 週間で 20 時間以上の節約を報告した。また、ある州の IT 開発者は約 900 の API メソッドを 2 日で新フレームワークに移行 (当初の見積もりは 1 か月)。

🔐 サイバーセキュリティ対応の高速化

ある州の CIO は、通常 2〜3 日かかるランサムウェア攻撃への対応を 8 分で完了。連邦セキュリティチームは、重要本番システムの乗っ取りにつながる脆弱性を約 2 日で検出・修正した (前月の人間によるペネトレーションテストでは見逃されていた)。米国の州の半数以上、大規模自治体、重要インフラ事業者が SLTT サイバー防衛プログラムに参加している。

📚 レガシーシステムの文書化

ある州の IT ディレクターは、レガシーコードリポジトリ 12 件を文書化し、467 のデータベーステーブルをマッピング、27 のリスクを特定した。

まとめ

今回の GSA との提携拡大により、Claude Enterprise、Claude for Government、Claude API のすべてが 40% 割引で米国のあらゆるレベルの政府機関に提供される。FedRAMP High 認証や DoD IL4・IL5 対応などのセキュリティ要件への対応と、最低支出額不要の柔軟な契約条件により、政府機関における AI 導入の障壁が大きく下がることが期待される。クラウドプロバイダー経由の購入への割引適用と導入支援プログラムの開始が今後予定されており、続報に注目したい。
