コード例

JSON sandbox.network.strictAllowlist 
{
  "sandbox": {
    "network": {
      "strictAllowlist": true,
      "allowlist": [
        "registry.npmjs.org",
        "github.com",
        "api.anthropic.com"
      ]
    }
  }
}
JSON DirectoryAdded hook 
{
  "hooks": {
    "DirectoryAdded": [
      {
        "command": "cd $DIRECTORY && git status --short",
        "description": "追加ディレクトリの Git 状態確認"
      }
    ]
  }
}

ユースケース

🏢 エンタープライズセキュリティ

strictAllowlist で外部通信を制限。許可リストに含まれないホストへのアクセスをプロンプトなしで即時拒否し、企業ネットワークポリシーに準拠。

🤖 マルチエージェント開発

3 階層のサブエージェントで複雑なタスク分解。親エージェントから子、孫エージェントへの委任が可能になり、大規模なコードベースの並列処理を実現。

🔧 CI/CD 統合

DirectoryAdded フックでモノレポのディレクトリ登録を検知。新規パッケージの追加時に自動で Git 状態チェックや依存関係の検証を実行。
