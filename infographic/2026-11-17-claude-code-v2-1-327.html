Claude Code v2.1.327 リリース

stdin からの MCP 登録と /status 診断強化を含む約 175 項目のアップデート。データ消失につながる不具合の修正に重点

📅 2026-11-17 | ソース: Claude Code Changelog

概要 - キーポイント

🔐

stdin からの MCP サーバー登録 (新機能)

claude mcp add-json <name> - でサーバーの JSON 定義を stdin から読み込めるようになった。API トークンなどの秘密情報をコマンドライン引数に渡す必要がなくなり、シェル履歴やプロセス一覧への露出を防げる

🩺

/status の破損ファイル一覧 (新機能)

破損したエージェント・スキル・コマンド・出力スタイルのファイル、キーバインドエラー、利用できないサンドボックス、無視された権限設定、一致しないフックマッチャーを 1 か所で診断できるようになった

💾

データ消失につながる不具合の修正 (重要)

Remote Control の worktree モード停止時の .env 削除、claude mcp add / remove による .mcp.json の他キー削除、/export の確認なし上書きなど、データ保全に関わる修正を多数含む

🛡️

権限・セキュリティの厳格化が継続

一部のシンボリックリンクの拒否、作業ディレクトリ判定の変更、auto モードでの Bash(pnpm dlx *) のような任意パッケージ実行ルールの無視など、v2.1.325 以降の堅牢化路線を引き継ぐ

🔧

約 100 項目のバグ修正と VS Code 拡張の改善

ハング対策、セッション復元、サブエージェントの挙動など安定性の修正が大半。VS Code 拡張にはエクスプローラー右クリックからの "Add to Chat" が追加された

主要な変更点

🔐 stdin からの MCP サーバー登録

  • claude mcp add-json <name> - で JSON 定義を stdin から読み込み
  • トークンをコマンドライン引数として渡す必要がなくなった
  • シェル履歴・プロセス一覧への露出を防止
  • Claude Code セッション内では利用できない

🩺 /status の破損ファイル一覧

  • 破損したエージェント・スキル・コマンド・出力スタイルのファイルを表示
  • キーバインドエラー、利用できないサンドボックスを表示
  • 無視された権限設定、一度も一致しないフックマッチャーを表示
  • /config には他の設定が行を上書きしている場合の注記を追加

✨ そのほかの新機能

  • /install-github-app がリポジトリ変更前に確認ダイアログを表示
  • /tui classic: 非フルスクリーンレンダラーの新名称
  • 再開セッションで過去メッセージをロードできない場合の注意表示
  • ゲートウェイヒントヘッダーに x-claude-code-managed-settings-checksum を追加、attributionProject 設定で課金グループに名前付け

🛡️ 権限・セキュリティの挙動変更

  • 一部のシンボリックリンクを拒否。作業ディレクトリ判定の範囲も変更
  • blockReadsOutsideWorkingDirectories が bypass / auto モードでより多くの Bash コマンドを確認・拒否
  • auto モードは Bash(pnpm dlx *) のような任意パッケージ実行ルールを無視
  • ExitWorktree は未保存の作業を含み得る worktree の削除前に確認
  • 非常に長いテキストに展開される変数を含む Bash コマンドは拒否

🚀 パフォーマンス・使い勝手の改善

  • シェル起動ファイルを承認前に実行し、最初の Bash コマンドを高速化 (CLAUDE_CODE_DISABLE_SHELL_HEAD_START=1 で無効化)
  • 秘密情報を含む可能性が高いファイルをコミットしないよう Claude に指示
  • Windows の起動時間と PowerShell ツールの速度を改善
  • Bedrock / Vertex / Foundry のサブエージェント進捗サマリーのトークン消費を大幅削減

💻 VS Code 拡張の更新

  • エクスプローラー右クリックに "Claude Code: Add to Chat" を追加
  • PreToolUse フックの確認理由が権限プロンプトに表示されない問題を修正
  • Escape がダイアログを閉じる際に応答まで停止する問題を修正
  • 連続する編集の速度を改善、rg がある場合の @ メンション検索を高速化

技術詳細 - stdin からの MCP サーバー登録

トークンを含む MCP サーバー定義を、コマンドライン引数に露出させずに登録できる。従来はシェル履歴やプロセス一覧に秘密情報が残るリスクがあった。

Bash stdin 経由の MCP サーバー登録 
# JSON を stdin 経由で渡す (トークンがシェル履歴に残らない)
cat server.json | claude mcp add-json my-server -

# もしくはヒアドキュメントで渡す
claude mcp add-json my-server - <<'EOF'
{
  "type": "http",
  "url": "https://example.com/mcp",
  "headers": {
    "Authorization": "Bearer ${MY_TOKEN}"
  }
}
EOF

📁 .mcp.json の保護 - Before / After

Before (〜 v2.1.326)

project スコープの claude mcp add / claude mcp remove が、$schema や他ツールの servers など、他のトップレベルキーを削除してしまうことがあった。/export も既存ファイルを確認なしで上書きしていた

After (v2.1.327 〜)

他のトップレベルキーは保持される。mcpServers キーなしでサーバーを列挙するファイルは上書きせず停止。/export は確認を求め、/export <name> は既存ファイルを保持する

💰 ゲートウェイ・課金グループの設定

Claude apps ゲートウェイで admin.billing_group_tag を設定している環境では、attributionProject 設定でセッションの課金グループに名前を付けられる。

JSON settings.json - 課金グループの設定 
{
  "attributionProject": "my-team-project"
}

カテゴリ別の修正の要約 (約 100 項目)

💾 データ消失につながる不具合 (重要)

  • Remote Control: worktree モードでサーバー停止時に実行中セッションの .env などの git-ignored ファイルが削除される問題を修正
  • .mcp.json: claude mcp add / remove が他のトップレベルキーを削除する問題を修正
  • /export: 既存ファイルを確認なしで上書きする問題を修正
  • セルフホストランナー: --use-anthropic-git-proxy 使用時に GIT_CONFIG_GLOBAL が指す空でないディレクトリを起動時に削除する問題を修正
  • セッション復元: headless 再開時の保存済みメッセージ喪失、/clear 後のタスク喪失・復活、コンパクションによるツール呼び出し喪失などを修正

🧯 安定性・ハング対策

  • claude -p がモデル設定の取得停滞で最初のリクエスト前にハングする問題を修正 (10 秒後に設定なしで続行)
  • https_proxy が host:port 形式のとき非ターミナル環境で起動を拒否する問題を修正
  • WebFetch は 2,000 文字超の URL を権限プロンプト前に拒否。数千の未クローズタグや @ メンションによるストールも修正
  • リモート MCP サーバーが長い障害後に切断されたままになる問題を修正 (約 1 日バックグラウンドで再試行)
  • コンパクション後の Edit 拒否、Grep のページング時の重複・欠落を修正

🤖 サブエージェント・バックグラウンドエージェント

  • リードと異なるモデルのチームメイトが誤った制限とモデルでコンパクションする問題を修正
  • 終了済みサブエージェントが兄弟のモデルと effort で再開される問題を修正
  • バックグラウンドエージェントの完了通知漏れ、permission プロンプト待機中の誤った実行中報告を修正
  • モデル未指定のサブエージェントは再開時も開始時のモデルを維持

🚀 パフォーマンス・UI

  • 未認識モデルで 32,000 出力トークンで切れた返信は 128,000 トークンの制限で継続
  • Windows: Git Bash と pwsh がない環境での起動時間、PowerShell ツールの速度を改善
  • トランスクリプト検索が編集内容と書き込んだファイル内のテキストも対象に
  • 狭いターミナルでのレイアウト改善 (/model と /effort は約 40 桁でも表示可能)、Ghostty / tmux / kitty / iTerm2 / Windows Terminal の描画修正

💻 VS Code 拡張

  • エクスプローラー右クリックメニューに "Claude Code: Add to Chat" を追加
  • PreToolUse フックの確認理由の非表示 (anthropics/claude-code#85950)、Escape による応答停止を修正
  • 連続する編集の速度改善、未使用の IDE 接続ツール (openFile、saveDocument など) を削除

ユースケース - 開発者への影響

🔐 MCP サーバーを CLI で登録する利用者

トークンを引数で渡しているスクリプトは claude mcp add-json <name> - への移行を検討する。stdin 経由の登録で秘密情報の露出を防げるうえ、.mcp.json の他キー削除・上書きの問題も解消された

📱 Remote Control・セルフホストランナーの利用者

.env などの git-ignored ファイルの削除、GIT_CONFIG_GLOBAL ディレクトリの削除といった破壊的な不具合が修正されたため、早期の更新を推奨する

🏢 auto / bypass モードで自動化を運用する組織

シンボリックリンクの拒否、作業ディレクトリ判定の変更、blockReadsOutsideWorkingDirectories の強化、パッケージ実行系 allow ルールの無視拡大など、無人実行に影響し得る変更がある。更新後に /status で無視された権限設定を確認し、必要なら明示的なルールへ書き換える

必要なアクション

  1. アップデートの適用: データ消失やハングに関わる修正が多いため、早期の更新を推奨
  2. MCP 登録スクリプトの見直し: トークンを引数で渡している場合は claude mcp add-json <name> - への移行を検討する
  3. /status での設定診断: 更新後に /status を実行し、破損ファイル・無視された権限設定・一致しないフックマッチャーが報告されないか確認する
  4. 自動化ワークフローの確認: シンボリックリンクの拒否、作業ディレクトリ判定の変更、PowerShell の確認追加などにより、権限プロンプトや拒否が増える可能性がある。auto モードで Bash(pnpm dlx *) のようなルールに依存している場合は明示的なルールへ書き換える
  5. auto モードのクラシファイア通知の確認: 課金対象クラシファイアリクエストへのフォールバックは今後のリリースで削除され、該当アクションは確認または拒否されるようになると告知されている
移行ガイド (該当する場合): ネストした claude 実行で独自トークンを使う場合、セッションのトークンを受け取らないコマンドには CLAUDE_CODE_OAUTH_SCOPES が渡されなくなったため明示的に設定する。シェル起動ファイルの先行実行を避けたい環境は CLAUDE_CODE_DISABLE_SHELL_HEAD_START=1 を設定する。mod 開発者は $.model.complete / $.model.classify が使用上限到達時に API のエラーを即座に返すようになったためエラーを処理する。Anthropic ホストのクラウドセッションでは、リポジトリのフラグ・プラグイン配信設定はさらに多くが無視され、CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC は最大でも DISABLE_TELEMETRY として扱われる

まとめ

Claude Code v2.1.327 は、stdin からの MCP サーバー登録や /status の破損ファイル一覧といった運用性を高める新機能に加え、.env や .mcp.json の意図しない削除・上書き、セッション復元時のメッセージ消失など、データ保全に関わる重要な修正を多数含む約 175 項目のリリースである。権限面ではシンボリックリンクの拒否や auto モードの allow ルール無視の拡大など厳格化が継続しており、自動化ワークフローを運用する環境では更新後の動作確認を推奨する。VS Code 拡張もエクスプローラーからの Add to Chat 追加や編集速度の改善など、着実な進化を見せている
