v2.1.245 — glibc 2.44 起動クラッシュ修正 v2.1.246 — 約 60 項目の修正・改善

概要 — キーポイント

Claude Code v2.1.245 および v2.1.246 (いずれも 2026 年 8 月 25 日、npm レジストリ基準) がリリースされた。v2.1.245 は単一項目の緊急パッチ、v2.1.246 は約 60 項目におよぶ広範なフォローアップリリースである。

🐧

v2.1.245: glibc 2.44 での起動クラッシュを修正

glibc 2.44 を搭載した Linux ディストリビューション (Arch Linux、CachyOS、Fedora Rawhide など) で Claude Code が起動できなかった問題を修正する単一項目のパッチ。該当環境のユーザーには必須のアップデートとなる。

🛡️

v2.1.246: 権限管理を強化する新機能

サブコマンドの前にワイルドカードを含む Bash allow ルールへの起動時警告、/permissions への Auto mode タブ追加、ターン完了時刻の表示という 3 つの新機能が追加された。

🔑

サードパーティゲートウェイの API キー送信を修正

ANTHROPIC_BASE_URL に設定したサードパーティゲートウェイ用の API キーが、Anthropic へのテレメトリ・メトリクスリクエストに付与されていた問題を修正。認証情報の取り扱いに関わる重要な修正である。

🧰

約 60 項目の広範なバグ修正

フルスクリーンモード、トランスクリプト表示、バックグラウンドセッション、プラグイン、MCP、テーマ、サードパーティエンドポイント利用時の問題など、広範囲のバグ修正が含まれる。

背景 — リリースの流れ

同日の v2.1.243 は、プロンプトキャッシュ TTL 設定やモデルピッカーのカスタマイズ、起動・メモリの大幅な改善を含む大規模リリースであった。v2.1.245 はその後に発生が確認された glibc 2.44 環境での起動クラッシュに対応する緊急パッチであり、v2.1.246 は権限管理の強化と広範なバグ修正をまとめたフォローアップリリースという位置付けになる。

主要機能 — v2.1.245 の修正と v2.1.246 の新機能

🐧 glibc 2.44 での起動クラッシュ修正v2.1.245 Fixed

glibc 2.44 を搭載した Linux ディストリビューション (例: Arch Linux、CachyOS、Fedora Rawhide) での起動時クラッシュを修正。該当環境では Claude Code が起動できない状態だったため、影響を受けていたユーザーには重要な修正となる。

⚠️ Bash allow ルールの起動時警告v2.1.246 Added

サブコマンドの前にワイルドカードを含む Bash allow ルール (例: Bash(git * main)) に対して起動時に警告を表示。このようなルールはサブコマンドの前に挿入されたオプションにもマッチしてしまうため、意図しない許可を防ぐための注意喚起となる。

🛡️ /permissions に Auto mode タブを追加v2.1.246 Added

/permissions に Auto mode タブが追加され、auto モードの分類器ルールを表示・編集できるようになった。

⏰ ターン完了時刻の表示v2.1.246 Added

ターン終了時の所要時間表示に完了時刻が追加された (例: ✻ Sautéed for 23s · done 6:05 PM)。

v2.1.246 修正のハイライト Fixed

約 60 項目の修正のうち、主要なカテゴリごとのハイライトは以下のとおりである。

🖥️ フルスクリーン・トランスクリプト表示

  • リサイズ後の最下部ジャンプでトランスクリプトが空白になる問題を修正
  • 非常に長い 1 行 (例: base64 文字列) を含む diff の深刻な表示遅延を修正 (マーカー付きで切り詰め)
  • 過去メッセージ位置でのフルスクリーンスクロールの乱れを修正
  • 最初の 500 文字に markdown がないと全体のレンダリングが無効になる問題を修正
  • セッションが長くなるほどメモリが増加する問題を修正
  • 中断されたコマンドが中断の形跡なしに表示される問題を修正
  • クリックだけでキーボードフォーカスが移動する問題を修正

🔄 バックグラウンドセッション・エージェント

  • 起動ディレクトリ削除・スリープ後などにセッションが 45 秒後に開けなくなる問題を修正
  • npm 再インストール中の EACCES エラーで開けない問題を修正
  • 完了済みサブエージェントの意図しない再起動を修正 (事前確認と台数表示を追加)
  • claude agents の二重表示や起動直後の停止問題を修正
  • ユーザー作成の .claude/worktrees/ 配下の worktree が削除される問題を修正
  • フォーク済みセッションからの /fork が空の会話になる問題を修正

🔌 MCP・プラグイン

  • 中断された MCP ツール呼び出しが「completed with no output」と報告される問題を修正
  • 空スキーマの MCP ツール引数が JSON 文字列として送信される問題を修正
  • プラグインスキルのプレフィックス二重表示、短縮名での update 失敗、UTF-8 BOM でのインストール失敗などを修正
  • /reload-plugins が 0 skills と報告する問題を修正
  • --strict-mcp-config セッションが読み込まれない .mcp.json サーバーの承認を求める問題を修正

🔐 権限・セキュリティ・認証

  • サードパーティゲートウェイ用 API キーが Anthropic へのテレメトリに付与されていた問題を修正
  • 大きなセッションで auto モードのツール呼び出しが拒否される問題を修正
  • 末尾に && や || が残る不正コマンドは必ず承認を要求するように修正
  • サンドボックス権限プロンプト待機中に Notification hook が発火しない問題を修正
  • 短命な JWT を返す apiKeyHelper 利用時の API エラーを修正

🎨 テーマ・キー入力・UI

  • /rename がテーマのプロンプト枠線色を上書きする問題を修正
  • カスタムテーマの diff 色が無視される問題を修正
  • 未知のアクション名でキーバインディングが無効になる問題を修正
  • /stats ヒートマップのタイムゾーンずれを修正
  • /-- で始まるプロンプトの拒否、@ ファイルピッカー、ステータスラインのリセットなどを修正

🌐 サードパーティエンドポイント・その他

  • id なし tool_use ブロックのストリーミングで UI が停止する問題を修正
  • 再開セッションが毎ターン 400 エラーで失敗する問題を修正
  • 大きなファイル上書き後の Write ツールの「Out of memory」を修正
  • インストールスクリプトの「Raw mode is not supported」失敗を修正
  • プランモードの再開、クラウドセッションのタスク進捗欠落、セルフホストランナーの終了問題などを修正

v2.1.246 改善と変更

📈 改善 Improved

📂/cd の改善: 移動先ディレクトリのプロジェクト設定、hook、.mcp.json サーバー (通常の承認プロンプトあり)、スキル、エージェントが、--resume 時ではなく移動直後に有効になる。
⚡Bash ツールのレイテンシ改善: スナップショット関数の再生で、関数ごとの base64 サブシェルを使用しなくなった。
🤖サブエージェント結果の明確化: maxTurns 制限で停止したサブエージェントの結果が部分的 (partial) とマークされ、SendMessage で継続するためのヒントが付く。
🔁非対話セッションの自動継続: -p、SDK、クラウドセッションが、サーバーエラー・接続断・ストールでストリーム途中に切断された応答を、エラー終了せず自動的に継続する。
📊テレメトリ帰属の改善: ワークロードアイデンティティフェデレーションセッションなどで、使用状況テレメトリの組織への帰属を改善。

🔀 変更 Changed

🔍/code-review: Bedrock、Vertex AI、Foundry、Claude アプリゲートウェイ経由、およびテレメトリや非必須トラフィックが無効な環境でも、Claude が自発的に開始できるように変更。
🎯/goal: アイドルセッションが長時間のバックグラウンド作業に対して開始するチェックインを、ゴールごとに最大 3 回に変更。次のメッセージを送るとさらに 3 回許可される。
📥claude install / claude update: 保留中の managed-settings 同意プロンプトをコマンド実行中に表示せず、次の対話セッションに延期するように変更。
📡プラグインの OpenTelemetry イベント: plugin_id_hash がプラグインの実際のマーケットプレイスを反映し、管理者インストールでは enabled_via が admin-install になる。

技術的な詳細 — 注目すべき 2 つの修正

⚠️ ワイルドカードを含む Bash allow ルールの挙動

Bash(git * main) のようなルールは、git と main の間に任意のオプションが挿入されたコマンドにもマッチするため、想定より広い範囲を許可してしまう可能性がある。v2.1.246 では該当ルールに対して起動時に警告が表示されるため、既存の allow ルールを見直す契機となる。

🔑 サードパーティゲートウェイの認証情報の取り扱い

ANTHROPIC_BASE_URL でサードパーティゲートウェイを利用している環境では、これまでゲートウェイ用の API キーが Anthropic へのテレメトリ・メトリクスリクエストにも付与されていた。v2.1.246 以降は認証情報が自身のホストにのみ送信されるため、ゲートウェイの認証情報が外部に送信される経路が解消されている。

Before (v2.1.245 以前)

サードパーティゲートウェイ用の API キーが、Anthropic へのテレメトリ・メトリクスリクエストにも付与されていた。

After (v2.1.246 以降)

認証情報は自身のホストにのみ送信され、ゲートウェイの認証情報が外部に送信される経路が解消された。

🎯 対象

⚠️ワイルドカードを含む Bash allow ルールを設定しているユーザー: 起動時警告の対象となる。
🌐ANTHROPIC_BASE_URL でサードパーティゲートウェイやプロキシを利用しているユーザー: 認証情報送信の修正、tool_use レンダリングエラーや 400 エラーの修正が適用される。
🔄バックグラウンドセッション、claude agents、動的ワークフローを利用しているユーザー: 多数の安定性修正が適用される。
🔌プラグインや MCP サーバーを開発・利用しているユーザー: インストール・更新・スキル読み込みまわりの修正が適用される。
🎨カスタムテーマや keybindings.json を利用しているユーザー: テーマ色やキーバインディングの修正が適用される。

🔀 移行ガイド

✅ 移行作業は不要

破壊的変更はアナウンスされていないため、移行作業は不要である。

まとめ — 3 つのポイント

1

glibc 2.44 環境は必須アップデート

v2.1.245 は glibc 2.44 環境 (Arch Linux、Fedora Rawhide など) での起動クラッシュを解消する緊急パッチであり、該当環境のユーザーには必須のアップデートとなる。

2

権限管理の強化と約 60 項目の修正

v2.1.246 は、Bash allow ルールのワイルドカード警告や /permissions の Auto mode タブなど権限管理の強化に加え、フルスクリーン表示からサードパーティゲートウェイまで約 60 項目の広範な修正・改善を含む。

3

ゲートウェイ利用環境は速やかに更新

サードパーティゲートウェイの API キーがテレメトリに付与されていた問題の修正は認証情報の取り扱いに関わるため、ANTHROPIC_BASE_URL を利用している環境では速やかなアップデートを推奨する。
