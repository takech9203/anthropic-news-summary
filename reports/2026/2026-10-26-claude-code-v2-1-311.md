## 概要

Claude Code v2.1.311 が公開された。修正中心の大型リリースで、50 件を超える修正に加え、改善と動作変更が幅広く含まれる。注目点は、CLAUDE.md の非常に長いリスト項目が原因で起動時やファイル編集後に長時間フリーズする問題の修正、リクエストが 200K トークンを超えた際に「Usage credits required for 1M context」で停止せず自動的に圧縮 (コンパクション) して継続するようになった修正、および `self-hosted-runner` への `--hold-idle-file` / `--max-hold-min` オプションの追加である。

動作変更としては、対話ターミナルでの `ultrathink` が Anthropic API 経由の Opus 5.5 / Sonnet 5.5 / Haiku 5.5 / Fable 5.1 でそのターンを xhigh effort で実行するようになり、効果のないモデルではモデル名・ID から `[1m]` サフィックスが削除された。また、Bedrock / Mantle / Vertex / Foundry 上の Claude Code は、モデル設定を downloads.claude.ai の署名付きファイルから読み込むようになった。VSCode 拡張、Cloud sessions、Claude Tag (Slack 連携)、Code Review の各プラットフォームにも修正・改善が及んでいる。

## 詳細

### 背景

v2.1.311 は新機能の追加よりも、日常利用で遭遇しやすいフリーズ・停止・誤動作の解消に重点を置いたリリースである。起動時や大規模ファイル編集後のパフォーマンス、コンテキスト上限到達時の継続性、MCP・サブエージェント・フックまわりの信頼性、Remote Control やクラウドセッションの安定性など、運用上の問題点が広範に修正されている。

### 主な変更点

#### 追加機能

- **`self-hosted-runner` の保持オプション**: `--hold-idle-file` と `--max-hold-min` が追加された。ホストが残したプロセスを処理している間、アイドル状態のセッションを維持できる
- **Explanatory 出力スタイルのヒント**: Claude に説明を求めた際に、Explanatory 出力スタイルのヒントが表示されるようになった

#### 修正

**パフォーマンス・コンテキスト関連:**

- **起動時・ファイル編集後の長時間フリーズ**: CLAUDE.md に非常に長いリスト項目が含まれる場合に、起動時およびファイルの読み取り・編集後に長時間フリーズする問題を修正
- **200K トークン超過時の自動継続**: 標準コンテキストのセッションで、リクエストが 200K トークンを超えると「Usage credits required for 1M context」エラーで停止していた問題を修正。会話を圧縮して継続するようになった
- **Write / Edit の停止**: 数千行規模の変更時に、Write と Edit が実行後最大 5 秒停止し、変更行数を 0 行と報告する問題を修正
- **圧縮直後の古いファイル内容**: セッション中に編集した MEMORY.md や CLAUDE.md について、自動圧縮の直後に Claude が古い内容を参照する問題を修正

**MCP・サブエージェント・フック関連:**

- **割り込みの遅延**: MCP サーバーがリソース読み取りに応答していない間や、スキルのダウンロード中に、Claude への割り込みがタイムアウトまで効かない問題を修正
- **サブエージェントの MCP ツール**: サブエージェント開始後に接続が完了した MCP サーバーのツールを、サブエージェントが利用できない問題を修正
- **`SubagentStop` フックの多重実行**: 実行中のサブエージェントごとに 1 分間に約 2 回フックが実行されていた問題を修正。終了時に 1 回だけ実行されるようになった
- **サブエージェントの worktree**: バックグラウンドのサブエージェントが作業中にもかかわらず、親サブエージェントの分離 worktree が削除される問題を修正
- **`claude mcp` コマンド**: リポジトリルートより下で実行した場合に、`claude mcp add` / `claude mcp remove` / `/mcp` がローカルスコープサーバーを保持する `~/.claude.json` のプロジェクトエントリではなく現在のフォルダーを指す問題を修正

**セッション・リモート関連:**

- **トランスクリプトの順序**: `claude -p` と SDK セッションが、トランスクリプトメッセージを順序を乱して保存したり、取り消されたメッセージを保持したりする問題を修正
- **Remote Control の接続**: ネットワークプロキシが起動時のリクエストをブロックすると、約 2 分間「Connecting」のまま止まる問題を修正
- **モバイルアプリでの表示**: Claude がクラウドセッションや Remote Control セッションに送信したメッセージが、Claude モバイルアプリで自分のメッセージとして表示される問題を修正
- **クラッシュしたバックグラウンドセッション**: アタッチ中、ピン留め中、またはスケジュールタスクやウェイクアップが設定されたバックグラウンドセッションが、ターン間でクラッシュしても再起動されない問題を修正
- **エージェントチームのタスクリスト**: `--resume` / `--continue` / `/resume` / `--session-id` で復帰した際にタスクリストが空になる問題、および `/branch` が元のセッションのリストに書き込む問題を修正

**その他:**

- **@ ファイルピッカー**: git-ignore されたファイルを再度含める `.ignore` / `.rgignore` の否定ルールが無視される問題を修正
- **リトライの保留**: API がリトライ不可とマークしたリクエストをリトライし、ターンが数分間、または無人リトライモード (`CLAUDE_CODE_RETRY_WATCHDOG`) では無期限に保留される問題を修正
- **隠し思考の切断**: 思考の進捗更新を送信する Google Vertex AI、Microsoft Foundry、Claude Platform on AWS で、長い隠し思考がアイドルとして切断される問題を修正
- **`DISABLE_COMPACT`**: 設定時にエージェントのチームメイトが履歴を圧縮する問題と、rewind メニューに要約オプションが表示される問題を修正

このほか、`/ide` のインストール表示、`/mcp` の認証状態表示、`/usage` のプロンプトキャッシュミス表示、画像パスの貼り付け、スクリーンリーダーモードなど、多数の修正が含まれる。

#### 改善

- **起動時間**: Pro / Max アカウントでは、直近 1 時間以内にチェック済みの場合に 2 つのネットワークリクエストをスキップして起動が高速化された。また、`claude --model opus` のようにオプションと値のみを引数とする起動も高速化された
- **`/teleport` の警告**: 圧縮済みのクラウドセッションが最後の圧縮時点から読み込まれる場合に、要約されたメッセージがローカルコピーに含まれない旨を警告するようになった
- **シェルコマンドのタイムアウト**: タイムアウトに達したコマンドの結果に、それまでの出力と、コマンドがバックグラウンドで実行継続中である旨が表示されるようになった
- **圧縮の再試行**: モデルの応答に要約が含まれない場合、会話を置き換える前に要約をもう一度要求するようになった
- **Slack 連携の投稿ルール確認**: 名指ししていないチャンネルにメッセージを送る前に、チャンネルのトピックで投稿ルールを確認するようになった

#### 動作変更

- **`ultrathink` の挙動**: 対話ターミナルでの `ultrathink` は、Anthropic API 経由の Opus 5.5 / Sonnet 5.5 / Haiku 5.5 / Fable 5.1 において、そのターンを xhigh effort で実行するようになった。Claude の作業中に入力すると、そのターンの残りの effort を引き上げる。また、`ultrathink` のレインボー表示は、キーワードが effort を引き上げられる場所でのみ表示され、引用符内やファイルパスの一部では表示されなくなった
- **`[1m]` サフィックスの削除**: サフィックスが効果を持たないモデルでは、モデル名と ID から `[1m]` サフィックスとそのラベルが削除された。サフィックス自体は引き続き受け付けられる
- **モデル設定の署名付きファイル読み込み**: Bedrock、Mantle、Vertex、Foundry 上の Claude Code は、モデル設定を downloads.claude.ai の署名付きファイルから読み込むようになった。`CLAUDE_CODE_MODEL_CATALOG=off` で無効化できる
- **`DISABLE_COMPACT` の制限**: 設定ファイルおよび mod の `$.env.set` での `DISABLE_COMPACT` は、圧縮を無効化する方向にのみ作用し、再有効化はできなくなった
- **JSON 出力のエスケープ**: `--output-format json` と `stream-json` の出力で、文字列内の DEL、C1 制御文字、Unicode 書式文字が `\uXXXX` エスケープで書き込まれるようになった。パース後の値は変わらない
- **`claude purge` の表記**: このコンピューター上のデータのみを削除し、Anthropic が保存するデータは削除しないことを明示するようになった

#### プラットフォーム別の修正・改善

**VSCode 拡張:**

- Claude の返信内のコードブロックに、ライト・ダーク・ハイコントラストダークの各テーマでシンタックスカラーリングが追加された
- VS Code や JetBrains のパネルから送信したカスタムスキル・カスタムスラッシュコマンドに、通常のメッセージには含まれる開いているファイルや選択行が含まれない問題を修正
- macOS と Linux で、ログインシェルが起動ファイルを実行して PATH を読み取る間、拡張ホストがフリーズする問題を修正
- VS Code のテレメトリー設定がオフの間、拡張は `DISABLE_TELEMETRY` を設定してセッションを開始し、使用状況メトリクスやエラーレポートを送信せず、フィーチャーフラグも取得しないよう変更された

**Cloud sessions:**

- Anthropic ホスト環境のルーティンが、オーナーが組織を離脱して再参加した後もロックされたままになる問題を修正。オーナーが再度有効化できるようになった
- クラウド環境ダイアログ (管理ダイアログを含む) が重複した名前を受け付ける問題を修正

**Claude Tag (Slack 連携):**

- Claude Tag アナリティクスに Skills ビューが追加され、Slack チャンネルで各スキルが実行される頻度と未使用のスキルを確認できるようになった
- 新しいセッションで実行されるルーティンが、報告する内容がない場合にチャンネルへの不要なメッセージ投稿なしに終了できるようになった

**Code Review:**

- 自動リトライでもモデルが変更を分析できない場合に、チェック実行がそれ以上の自動レビューは開始されない旨を示すようになった
- 一時的なサーバー障害でセッションの開始に失敗したレビューは、自動的に 1 回リトライされるようになった

## 開発者への影響

### 対象

- 長いリスト項目を含む CLAUDE.md を使用していて、起動時やファイル編集後のフリーズに遭遇していたユーザー
- 標準コンテキストで大規模な会話を扱い、200K トークン超過エラーで停止していたユーザー
- MCP サーバー、サブエージェント、フックを組み合わせたワークフローを運用しているチーム
- Bedrock / Mantle / Vertex / Foundry 経由で Claude Code を利用しているエンタープライズユーザー
- `self-hosted-runner`、Remote Control、Cloud sessions、Claude Tag、Code Review を利用している組織

### 必要なアクション

- **アップデートの適用**: `claude update` または npm 経由で v2.1.311 に更新する
- **`ultrathink` の挙動確認**: Opus 5.5 / Sonnet 5.5 / Haiku 5.5 / Fable 5.1 では `ultrathink` がそのターンを xhigh effort で実行するようになったため、コストと所要時間への影響を踏まえて利用方針を確認する
- **`[1m]` サフィックスの表記確認**: モデル名・ID から `[1m]` サフィックスが削除されたモデルがあるため、モデル名を参照するスクリプトや設定を確認する。サフィックス自体は引き続き受け付けられる
- **Bedrock / Mantle / Vertex / Foundry 利用組織**: モデル設定が downloads.claude.ai の署名付きファイルから読み込まれるようになった。この挙動を避けたい場合は `CLAUDE_CODE_MODEL_CATALOG=off` を設定する
- **`self-hosted-runner` 利用者**: アイドルセッションの保持が必要な場合は、`--hold-idle-file` と `--max-hold-min` の利用を検討する

### 移行ガイド (該当する場合)

破壊的変更はない。ただし、以下の動作変更に注意が必要である。

- `ultrathink` が対象モデルで xhigh effort 実行に変わった
- `DISABLE_COMPACT` は圧縮の無効化のみ可能になり、再有効化には使えなくなった
- JSON 出力で一部の文字が `\uXXXX` エスケープに変わった (パース後の値は不変)
- Bedrock / Mantle / Vertex / Foundry でのモデル設定の読み込み元が変わった

## まとめ

v2.1.311 は、起動時・編集後の長時間フリーズや 200K トークン超過時の停止といった、日常利用に直結する問題を解消した修正中心の大型リリースである。`ultrathink` の xhigh effort 化、`[1m]` サフィックスの削除、署名付きファイルによるモデル設定の読み込みなど、モデルまわりの動作変更も含まれるため、エンタープライズ環境の管理者は変更点の確認を推奨する。MCP・サブエージェント・フックの信頼性向上も幅広く、ほぼすべてのユーザーにとって更新する価値のあるリリースである。
