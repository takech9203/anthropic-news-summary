## 概要

Claude Code v2.1.247 が 2026 年 8 月 26 日 (npm レジストリ基準) にリリースされた。

本リリースでは、セッション中に問題が発生した際に Claude 自身がフィードバック報告を下書きする `SendFeedback` ツール、既存プロジェクトの Claude API 支出をプロファイリングしてコスト削減策を段階的に適用する `/claude-api cost-optimize` コマンド、組織独自のヒントをローテーション表示できる `spinnerTipsOverride` の拡張などの新機能が追加された。また、Sonnet 5 のデフォルト auto-compact ウィンドウがフル 1M コンテキストに変更され、auto-compact の発動が約 934K トークンから約 967K トークンに引き上げられた。

修正面では、サブエージェントのフォールバックモデルチェーン対応、フックやバックグラウンドエージェントの大量エラー出力による会話オーバーフローの防止、プラグインマーケットプレイスのハードニングなど、安定性とセキュリティに関わる約 20 項目の修正・改善が含まれる。

## 詳細

### 背景

前日の v2.1.246 は権限管理の強化と約 60 項目の広範なバグ修正を含むリリースであった。v2.1.247 はそれに続き、フィードバック体験の改善、API コスト最適化の支援、エンタープライズ向けのカスタマイズ (組織独自のスピナーヒント) といった新機能に加え、サブエージェント、フック、クラウドセッション、プラグインまわりの安定性修正をまとめたリリースとなる。

### 主な変更点

#### 新機能 (Added)

- **`SendFeedback` ツールの追加**: セッション中に問題が発生した場合、Claude がフィードバック報告の下書きを作成し、ユーザーは内容を確認したうえで `/feedback` から送信できる。この機能は `feedbackDrafts` 設定でオフにできる
- **`spinnerTipsOverride` の拡張**: `{id, text, cooldownSessions, priority}` 形式のエントリ、`tipsFile`、`label` が追加され、組織が独自のヒントを組み込みのヒントと一緒にローテーション表示できるようになった
- **Bash 権限プロンプトに auto mode への案内を追加**: auto mode を紹介するヒントが表示され、「Yes, and switch to auto mode」をワンキーで選択できるようになった
- **`/claude-api cost-optimize` の追加**: 既存プロジェクトの Claude API 支出をプロファイリングし、コスト削減策 (キャッシング、トークンハイジーン、バッチ処理、effort、モデル選択) を計測しながら 1 つずつ適用していくコマンド
- **`/claude-api` スキルの Admin API 対応**: 組織メンバー、招待、ワークスペース、API キー、レート制限レポート、ワークロードアイデンティティフェデレーション、CMEK をカバーするようになった

#### 修正 (Fixed)

**入力・キーボード・UI:**

- 履歴検索、`/config`、`/mcp`、`/skills`、バックグラウンドタスク、`/model` で、矢印キーと Enter を素早く連続入力すると移動先の 1 つ上の行に対して操作が実行される問題を修正
- kitty プロトコル対応ターミナルで、非ラテン系 (例: キリル文字) キーボードレイアウト使用時に Ctrl キーボードショートカットが発火しない問題を修正
- エスケーププレフィックス直後にマウスレポートが分割されて届いた場合に、`<35;150;7M` のようなテキストがプロンプトに挿入される問題を修正

**サブエージェント・フック・バックグラウンド:**

- サブエージェントが初回呼び出しのモデル 404 で停止する問題を修正。セッションのフォールバックモデルチェーンを使用するようになり、親に返されるエラーにはエラー種別、ステータス、リクエスト ID、モデルが含まれる
- フックやバックグラウンドエージェントが数メガバイトのエラー出力を出した場合に、会話がオーバーフローして「Prompt is too long」でセッションが動かなくなる問題を修正
- フックやバックグラウンドタスクの出力ファイルが書き込めない場合にメモリが際限なく増加する問題を修正。ファイルには出力が失われた箇所が記録される
- フォアグラウンドから引き継がれたシェルコマンドがバックグラウンドセッションで完了した際に、内部エラーをログに記録したり誤解を招く `[exited with code -1]` 行を表示したりする問題を修正
- ターミナルのホストプロセスが終了した後、バックグラウンドセッションが `claude agents` で「opening…」のまま表示され続ける問題を修正。数秒以内に理由付きで失敗として表示され、Enter で再起動できる

**セッション・クラウド:**

- Bash サンドボックスのコマンド後クリーンアップが、サンドボックスの書き込み可能領域の外を指すように再設定された dotfile 管理の `~/.claude/settings.json` シンボリックリンク (nix / home-manager、stow) を削除する問題を修正
- `/terminal-setup` が Zed の `keymap.json` 全体を上書きしてしまう問題を修正。キーバインディングをマージするようになった
- セッションレジストリを更新できなかった場合に `/rename` が静かに完了扱いになる問題を修正。他のセッションでは古い名前が表示される可能性がある旨を通知するようになった
- `--agent` で開始したセッションの `/compact` と「Summarize from here」が、会話自身のシステムプロンプトではなくデフォルトのシステムプロンプトで要約する問題を修正
- SSH 経由の `/install-github-app` を修正。コピーショートカットは常に成功と表示するのではなくサインイン URL がどのようにコピーされたかを表示し、ブラウザを開けない場合は URL が即座に表示される
- バージョン指定のないマーケットプレイスプラグインのライブキャッシュディレクトリが、2 つ目のスコープへのインストール時に削除・再作成され、そのプラグインを使用中のセッションに影響する問題を修正
- `/remote-control` で開始した Remote Control セッションが、接続クライアントに作業ツリーの diff を報告しない問題を修正
- セルフホストランナーのセッションが Claude Code の起動前に `running` を報告し、Claude デスクトップアプリから早すぎる「Claude is waiting for your input」通知が発生する問題を修正
- managed settings で Claude アプリゲートウェイサインインが構成され、Anthropic エンドポイントに到達できない場合に、初回セットアップが「Unable to connect to Anthropic services」で終了する問題を修正
- クラウドセッション (Claude Code on the web、デスクトップ、モバイルアプリ) で、メッセージ送信直後にモードを切り替えると以前の権限モードが表示されることがある問題を修正
- バックグラウンドエージェント、シェル、モニターの実行中にターン間でコンテナが再起動すると、クラウドセッションが無応答になる問題を修正。再開したセッションが失われた作業を報告するようになった

#### 改善 (Improved)

- **プラグインマーケットプレイスのハードニング**: 制御文字や不可視文字を含む名前は拒否され、`/plugin` と `claude plugin` の出力に含まれるマーケットプレイス提供のテキストはエスケープ処理される
- Bedrock、Vertex、Foundry のセッション (およびテレメトリが無効なセッション) で、構成済みの MCP サーバーが接続に失敗した場合に、Claude がツールが存在しないと結論づけるのではなく、接続失敗を通知されるようになった

#### 変更 (Changed)

- **Sonnet 5 のデフォルト auto-compact ウィンドウをフル 1M コンテキストに変更**: 1M ウィンドウのセッションは、約 934K トークンではなく約 967K トークンで auto-compact されるようになった
- クロスセッションのピアメッセージがデフォルトで `Message from @<sender>: <first line>` の 1 行プレビューに折りたたまれるようになった。Ctrl+O で全文を展開できる
- レンダリングされた markdown 内のターミナルハイパーリンクについて、ネットワークパスや自動マウントパスを指すもの、制御文字を含むもの、不可視文字で始まるものはプレーンテキストとして表示されるようになった
- プロンプトフッターの PR バッジが、直前のチェックから 1 分未満の場合はターミナルの再フォーカス時に GitHub への再チェックをスキップするようになった
- managed settings がゲートウェイログインを強制する場合、またはカスタム OAuth デプロイメントが構成されている場合に、アナリティクスがログイン後だけでなく起動時から無効になるようになった
- Claude アプリゲートウェイのサインインリクエストが Claude Code を識別するようになった (`surface=claude_code` デバイス認可パラメーターと `claude-code/<version>` User-Agent)
- 組織のサインイン強制が、ホスト提供またはユーザーごとの Windows レジストリ設定が存在する場合でも、管理者の managed settings を読み取れないときは起動時に終了するように変更

### 技術的な詳細

`SendFeedback` ツールは、セッション中の不具合をその場で報告可能にする仕組みである。Claude が問題の内容をフィードバック報告として下書きし、ユーザーは `/feedback` で内容をレビューしてから送信する。自動送信ではなくユーザーの確認を挟む設計で、不要であれば `feedbackDrafts` 設定で無効化できる。

`/claude-api cost-optimize` は、Claude API を利用する既存プロジェクトのコスト構造を分析し、プロンプトキャッシング、トークンハイジーン、Batch API、effort パラメーター、モデル選択といったコスト削減レバーを、効果を計測しながら 1 つずつ適用していくワークフローを提供する。同時に `/claude-api` スキルは Admin API (組織メンバー管理、ワークスペース、API キー、レート制限レポート、CMEK など) にも対応し、組織管理系のタスクにも利用できるようになった。

コンテキスト管理では、Sonnet 5 の 1M コンテキストウィンドウを使用するセッションのデフォルト auto-compact 発動点が約 934K トークンから約 967K トークンに変更され、コンパクト化までに利用できるコンテキストが約 33K トークン拡大した。

セキュリティ面では、プラグインマーケットプレイスのハードニング (制御文字・不可視文字を含む名前の拒否、出力のエスケープ処理) と、ターミナルハイパーリンクの安全化 (ネットワークパスや制御文字を含むリンク先のプレーンテキスト化) により、悪意あるマーケットプレイスやドキュメントを経由した攻撃面が縮小されている。

## 開発者への影響

### 対象

- Claude API を利用するプロジェクトのコストを最適化したい開発者 (`/claude-api cost-optimize`)
- 組織で Claude Code を展開し、独自のヒントを表示したい管理者 (`spinnerTipsOverride`)
- Admin API を利用する組織管理者 (`/claude-api` スキルの対応拡大)
- Sonnet 5 の 1M コンテキストウィンドウを利用しているユーザー (auto-compact 発動点の変更)
- サブエージェント、フック、バックグラウンドセッション、クラウドセッションを利用しているユーザー
- nix / home-manager や stow で `~/.claude/settings.json` を管理しているユーザー
- Bedrock、Vertex AI、Foundry 経由で MCP サーバーを利用しているユーザー

### 必要なアクション

以下のいずれかの方法で最新バージョンに更新できる。

```bash
# Claude Code 組み込みコマンド
claude update

# npm でのアップデート
npm update -g @anthropic-ai/claude-code

# 現在のバージョン確認
claude --version
```

Claude によるフィードバック下書きが不要な場合は、`feedbackDrafts` 設定で無効化できる。組織独自のヒントを表示したい場合は、`spinnerTipsOverride` の新しいエントリ形式 (`{id, text, cooldownSessions, priority}`) や `tipsFile` を設定に追加する。

API コストの削減に取り組む場合は、対象プロジェクトで `/claude-api cost-optimize` を実行し、提示されるコスト削減策を計測しながら適用していくことを検討するとよい。

### 移行ガイド (該当する場合)

破壊的変更はアナウンスされていないため、移行作業は不要である。ただし、Sonnet 5 の 1M コンテキストウィンドウを使用している場合、auto-compact の発動タイミングが約 967K トークンに変わる点に留意する。

## まとめ

Claude Code v2.1.247 は、2026 年 8 月 26 日に公開されたリリースである。`SendFeedback` ツールによるフィードバック体験の改善、`/claude-api cost-optimize` による API コスト最適化支援、`spinnerTipsOverride` の拡張による組織向けカスタマイズと、利用者層ごとに価値のある新機能が追加された。

また、Sonnet 5 の auto-compact ウィンドウのフル 1M コンテキストへの拡大により、長時間セッションで利用できるコンテキストが実質的に増加した。サブエージェントのフォールバックモデルチェーン対応やフック出力オーバーフローの防止など安定性の修正、プラグインマーケットプレイスやターミナルハイパーリンクのハードニングも含まれており、幅広いユーザーにアップデートを推奨できる内容となっている。
