# Claude Code v2.1.220: 安定性の向上

## 概要

Claude Code v2.1.220 は、前日にリリースされた v2.1.219 の安定性を向上させるためのパッチリリースである。バグ修正と信頼性の改善に焦点を当てており、新機能の追加や破壊的変更は含まれていない。

## 詳細

### 背景

v2.1.219 では以下の大規模な変更が導入された。

- **Claude Opus 5 のデフォルト化**: Opus モデル選択時のデフォルトが Claude Opus 5 に変更
- **サンドボックスネットワーク制御**: 新しいネットワークアクセス制御機能の追加
- **DirectoryAdded フック**: 新しいフックイベントの追加
- **ネストされたサブエージェント深度の拡張**: 最大深度が 3 に増加
- **ワークフローサイズガイドライン**: 新しいガイドラインの導入

これらの大規模な変更に伴い、一部のユーザー環境で安定性に関する問題が報告された。v2.1.220 はこれらの問題に対処するため、翌日に迅速にリリースされたパッチである。

### 主な変更点

- バグ修正
- 信頼性の改善

### 技術的な詳細

本リリースは安定性に特化したパッチであり、内部的なバグ修正と信頼性の改善のみが含まれている。API の変更や新しい設定項目は追加されていない。v2.1.219 で導入された機能 (Opus 5 サポート、サンドボックスネットワーク制御、DirectoryAdded フックなど) の動作をより安定させることが目的である。

## 開発者への影響

### 対象

- Claude Code を利用している全ての開発者
- 特に v2.1.219 にアップデート済みのユーザー

### 必要なアクション

v2.1.219 を使用中のユーザーは、安定性向上のため速やかに v2.1.220 へのアップデートを推奨する。以下のいずれかの方法でアップデートが可能。

```bash
# Claude Code 組み込みコマンド
claude update

# npm を使用する場合
npm update -g @anthropic-ai/claude-code

# Homebrew を使用する場合
brew upgrade claude-code
```

破壊的変更は含まれていないため、アップデートによる影響は最小限である。
