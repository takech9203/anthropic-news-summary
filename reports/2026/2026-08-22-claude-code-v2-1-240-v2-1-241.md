## 概要

Claude Code v2.1.240 および v2.1.241 (いずれも 2026 年 8 月 22 日、npm レジストリ基準) がリリースされた。2 つのバージョンとも changelog の記載は「Bug fixes and reliability improvements (バグ修正と信頼性の改善)」のみであり、個別の変更項目は公開されていない。新機能の追加や破壊的変更のアナウンスは含まれていない。

v2.1.240 は同日 13:03 UTC、v2.1.241 は 23:58 UTC に npm へ公開されており、約 11 時間の間隔で 2 つのパッチが連続してリリースされた形になる。前日の v2.1.239 が約 60 項目におよぶ大規模リリースであったことを踏まえると、その直後の安定化を目的としたフォローアップパッチと位置付けられる。

## 詳細

### 背景

直前の v2.1.239 (2026 年 8 月 21 日) は、プロキシ環境での Bedrock ストリーミング課金 2 倍問題の修正、Python SDK 1.x 移行コマンド `/claude-api upgrade` の追加、Windows でのクロスセッションメッセージング対応など、約 60 項目の変更を含む大規模なリリースであった。

このような大規模リリースの直後には、安定化のためのパッチが短い間隔で提供されることが多い。v2.1.240 と v2.1.241 は同日中に連続してリリースされており、v2.1.239 で導入された多数の変更をより安定した状態で利用できるようにするためのフォローアップと考えられる。ただし、これはリリース間隔からの位置付けであり、修正対象の詳細は公開されていない。

## 開発者への影響

### 対象

- Claude Code を利用しているすべてのユーザー
- 特に v2.1.239 にアップデート済みのユーザー (大規模リリース直後の安定化パッチであるため)

### 必要なアクション

以下のいずれかの方法で最新バージョンに更新できる。

```bash
# Claude Code 組み込みコマンド
claude update

# npm でのアップデート
npm update -g @anthropic-ai/claude-code

# Homebrew でのアップデート
brew upgrade claude-code

# 現在のバージョン確認
claude --version
```

破壊的変更はアナウンスされていないため、アップデートによる影響は最小限と考えられる。v2.1.239 以前のバージョンを利用している場合は、v2.1.239 に含まれる重要な修正 (Bedrock ストリーミング課金 2 倍問題の修正など) もあわせて適用されるため、アップデートを推奨する。

### 移行ガイド (該当する場合)

移行作業は不要である。破壊的変更や設定の変更はアナウンスされていない。
