## 概要

Claude Code v2.1.306 は、2 件のバグ修正のみを含む小規模なメンテナンスリリースである。Cloud sessions 内での `claude -p` 実行時の認証エラーと、多数の MCP ツールを持つセッションでの API エラー表示および不要なコンパクションが修正された。

## 詳細

### 主な変更点

本リリースに含まれる修正は以下の 2 件である。

- **Cloud sessions での `claude -p` の認証エラー修正**: Cloud sessions 内で、セッションの環境変数なしで `claude -p` を起動した場合に「Not logged in」と報告される問題を修正
- **MCP ツール多数時のエラー表示とコンパクションの修正**: 多数の MCP ツールを持つセッションで、API エラーが「prompt is too long」というメッセージに置き換えられ、不要なコンパクションが実行される問題を修正

## 開発者への影響

### 対象

- Cloud sessions 内で `claude -p` (ヘッドレスモード) を利用するユーザー
- 多数の MCP ツールを登録したセッションを利用するユーザー

### 必要なアクション

- **アップデートの適用**: `claude update` または npm 経由で v2.1.306 に更新する。該当する問題に遭遇していた場合は、更新により解消される

破壊的変更はなく、移行作業は不要である。
