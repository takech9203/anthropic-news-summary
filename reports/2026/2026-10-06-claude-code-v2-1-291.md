## 概要

Claude Code v2.1.291 がリリースされた。変更は修正 (Fixed) 2 件のみで、いずれも過去バージョンで混入したリグレッションを解消するホットフィックスリリースである。新機能の追加や挙動変更は含まれない。

修正されたのは、**v2.1.290 で発生した、クラウドセッションが権限プロンプトへの回答を取りこぼすことがある問題**と、**v2.1.288 で発生した、終了時にセッションの最後のメッセージが失われることがある問題**の 2 件である。どちらもセッションの入出力の信頼性に直結する不具合であり、該当バージョンを利用しているユーザーには早めの更新が推奨される。

## 詳細

### 背景

Claude Code は 2026-10-02 の v2.1.288 (89 項目)、2026-10-03 の v2.1.289、v2.1.290 (モッド向けフックの拡張や `claude attach` の追加など 60 項目超) と、大型の機能追加・修正リリースを続けてきた。本バージョンはこれらの大型リリースで混入した 2 件のリグレッションを素早く解消することに絞った、小規模なフォローアップリリースである。

### 主な変更点

#### 1. クラウドセッションの権限プロンプト回答の喪失を修正 (v2.1.290 のリグレッション)

v2.1.290 で、クラウドセッションが権限プロンプトへの回答を取りこぼす (drop する) ことがある問題が発生していた。クラウドセッションでは、ツール実行などの承認をリモートから回答する仕組みになっているが、回答がセッションに反映されず、承認したはずの操作が進まない、あるいはプロンプトが未回答のまま残るといった影響が考えられる。本バージョンでこのリグレッションが修正された。

#### 2. 終了時のセッション末尾メッセージの喪失を修正 (v2.1.288 のリグレッション)

v2.1.288 で、Claude Code を終了 (quit) した際にセッションの最後のメッセージが失われることがある問題が発生していた。この場合、`--resume` などでセッションを再開してもターン末尾のやり取りが復元されず、会話履歴の一部が欠落する影響が考えられる。本バージョンでこのリグレッションが修正された。

### 技術的な詳細

本バージョンの変更は上記 2 件の修正のみである。影響範囲と混入バージョンを以下に整理する。

| 修正内容 | 混入バージョン | 影響する利用形態 |
|---------|--------------|----------------|
| 権限プロンプトへの回答の取りこぼし | v2.1.290 | クラウドセッション |
| 終了時のセッション末尾メッセージの喪失 | v2.1.288 - v2.1.290 | ローカルセッション全般 (終了・再開の操作) |

## 開発者への影響

### 対象

- クラウドセッションを利用しているユーザー (v2.1.290 を利用中の場合、権限プロンプトの回答が反映されないことがある)
- v2.1.288 以降を利用しているすべてのユーザー (終了時にセッション末尾のメッセージが失われることがある)

### 必要なアクション

- **アップデートの実施**: v2.1.288 - v2.1.290 を利用している場合は v2.1.291 への更新を推奨する。特にクラウドセッションの権限プロンプトが未回答のまま進まない事象や、再開したセッションで直前のやり取りが欠けている事象に心当たりがある場合は、本バージョンで解消される
- **欠落した履歴の確認**: 旧バージョンの終了時に失われたメッセージは本バージョンでは復元されないため、重要なやり取りが欠けていないかを必要に応じて確認する

### 移行ガイド (該当する場合)

破壊的変更や挙動変更はない。アップデートのみで対応は完了する。

## コード例

アップデートは通常の手順で実施できる。

```bash
# バージョンの確認
claude --version

# npm でインストールしている場合の更新
npm install -g @anthropic-ai/claude-code@latest
```
