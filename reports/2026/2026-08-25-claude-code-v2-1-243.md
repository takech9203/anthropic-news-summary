# Claude Code v2.1.243 リリース — プロンプトキャッシュ TTL 設定・モデルピッカーのカスタマイズ・大幅な起動とメモリの改善

## 概要

Claude Code v2.1.243 がリリースされた。約 60 項目におよぶ大規模なリリースであり、`/usage` への Loops 内訳の追加、`/model` ピッカーをカスタマイズする `modelPicker` 設定、プロンプトキャッシュの TTL を制御する `promptCacheTtl` / `subagentPromptCacheTtl` 設定、組織の契約単価を反映する `modelPricing` 管理設定、Anthropic Console アカウントでのキーレスサインインなど、コスト管理とエンタープライズ運用に関わる新機能が多数追加された。

パフォーマンス面の改善も大きい。起動時のサンドボックスと MCP の初期化が初回描画をブロックしなくなり、ネイティブバイナリは zstd 圧縮によりダウンロードサイズが約 340 MB から約 75 MB (Linux x64) に縮小、コードのオンデマンド読み込みによりセッションあたりのメモリ使用量が約 40〜70 MB 削減された。あわせて、リモート MCP サーバーの自動再接続、API 無応答時のタイムアウト処理、CI でのワークロードアイデンティティフェデレーションの修正など、信頼性に関わる多数の修正が含まれる。

## 詳細

### 背景

v2.1.239 (2026 年 8 月 21 日) の大規模リリースの後、v2.1.240 / v2.1.241 (8 月 22 日) は「バグ修正と信頼性の改善」のみのパッチリリースであった。v2.1.243 は再び多数の変更を含むリリースとなり、コスト可視化 (Loops 内訳、契約単価の反映)、キャッシュ戦略の制御、組織管理機能の強化という方向性が明確に表れている。

### 主な変更点

#### 新機能 (Added)

**コスト管理・可視化:**

- **`/usage` に Loops 内訳を追加**: `/loop` タスクごとの実行回数、合計トークン数、実行あたりのトークン数、最終実行時刻を表示する。暴走したり無駄に会話の多いループタスクを容易に発見できる
- **`modelPricing` 管理設定**: 組織が契約しているモデル別単価とディスカウント率を設定でき、`/cost`、ステータスライン、テレメトリのコスト表示に定価ではなく契約価格が使用される

**モデル・キャッシュ設定:**

- **`modelPicker` 設定**: `/model` ピッカーに表示するモデルを、順序付き・ラベル付きのリストでカスタマイズできる。Vertex / Bedrock 形式を含む任意のモデル ID 表記に対応し、組み込みリストへの追加または置き換えが可能
- **`promptCacheTtl` / `subagentPromptCacheTtl` 設定**: API キーおよびクラウドプロバイダー経由のユーザーが、メイン会話のプロンプトキャッシュを 1 時間に延長しつつ、サブエージェントは 5 分のまま維持するといった制御ができる

**認証・組織管理:**

- **Console アカウントでのキーレスサインイン**: `/login` → Anthropic Console に「Sign in with your Console account」(推奨) が追加された。API キーの発行を許可していない組織でもサインインできる
- **`/status` に `Skipped sources` 行を追加**: より優先度の高い管理ソースが有効なために適用されなかった管理設定ソース (例: `managed-settings.json`) を一覧表示する
- **`/mcp` と `/plugins` に `managed` マーカーを追加**: 組織が認証を管理している claude.ai コネクタを識別できる

**その他:**

- `/tasks` とエージェント詳細ダイアログに、各サブエージェントが実行されたモデルと effort レベルを表示
- `/status` に Claude Code on the web (Pro/Max) の GitHub 接続状態を表示し、未接続の場合は `/web-setup` を案内

#### 修正 (Fixed)

**接続・信頼性:**

- 非対話モード (`-p`) および SDK セッションで、リモート MCP サーバーが切断後に復帰しない問題を修正。自動的に再接続するか、失敗として報告されるようになった
- Anthropic API が応答を開始しないままセッションが 10 分以上沈黙する問題を修正。約 3 分でタイムアウトして 1 回リトライし、それでも失敗した場合は `API Error: No response from API` を表示する
- CI でのワークロードアイデンティティフェデレーションを修正。同一ジョブ内のプロセスが交換済みトークンを共有するようになり、単回使用トークンの再交換による失敗がなくなった
- API が一時的に過負荷の際、auto モードのツール呼び出しが約 1 分の待機後に「temporarily unavailable」として拒否される問題を修正
- バックグラウンドの Bash タスク完了時にバックグラウンドサブエージェントが起床しない問題を修正

**設定・CLI:**

- `--agents` が不正な JSON やエージェント定義を黙って無視していた問題を修正。`--mcp-config` と同様に明確なエラーで終了する
- hook の `if` 条件 (例: `Bash(cat *)`) が、`$()` やバッククォートによるコマンド置換を含む無関係な Bash コマンドで発火する問題を修正
- `/resume` が直近 50 セッションしか表示しなかった問題を修正。スクロールで追加読み込みされる
- `HTTPS_PROXY` 環境で `NO_PROXY` の大文字表記しか設定していない場合に、ローカル IDE 接続がプロキシ経由になる問題を修正 (小文字表記 `no_proxy` との両対応)
- Ctrl+R 履歴検索と上矢印履歴が、`~/.claude/history.jsonl` の破損エントリで壊れる問題を修正
- サンドボックスのネットワーク違反の詳細が、ブロックされたコマンドの終了コードが 0 の場合に Bash ツール結果から欠落する問題を修正

**VSCode 拡張:**

- 機能フラグ取得前に開始したセッション (インストール直後など) が、auto モードや設定済みのデフォルトモードではなくデフォルト権限モードで開く問題を修正
- サブエージェントのツールアクティビティ中に、展開した Focus ビューのセクションが勝手に折りたたまれる問題を修正

#### 改善 (Improved)

- **起動時間の改善**: サンドボックスと MCP の初期化が初回フレーム描画をブロックしなくなり、引数なしの起動ではサブコマンド登録をスキップ。ワークフロー検出、設定、トラストストア処理も軽量化された
- **ダウンロードサイズの削減**: ネイティブインストールと自動更新のバイナリが zstd 圧縮され、Linux x64 では約 340 MB から約 75 MB に縮小
- **メモリ使用量の削減**: コードがオンデマンドで読み込まれるようになり、セッションあたり約 40〜70 MB のメモリ削減。長時間セッションではヒープ増大時により早くガベージコレクションが実行される
- SSH 経由の `/login` を改善: サインイン URL が即座に表示され、`c` キーによるコピーの結果が正確に報告される
- `/loop` で Claude が何もすることのない連続起床を、ターミナル上で 1 行にまとめて表示

#### 変更 (Changed)

- サンドボックス化された Bash ツールのプロンプトから許可済みネットワークホストの一覧を削除。Claude が未掲載のホストをブロック済みと仮定せずリクエストを試行し、ユーザーが新しいホストを承認できるようになった
- `/model` ピッカーと同梱の `claude-api` スキルで、Sonnet 5 の $2/$10 per Mtok 価格を期間限定プロモーションではなく標準の定価として表示
- `/model`、`/fast`、`/effort` が Bedrock / Vertex / Foundry 環境およびテレメトリ無効時も、ターン終了を待たず即座に実行されるようになった
- macOS の computer use で、デスクトップ・Dock・Finder ウィンドウのクリックには他のアプリと同様に Finder へのアクセス許可が必要になった

### 技術的な詳細

新しい設定項目の位置付けは以下のとおりである。

| 設定 | 種別 | 用途 |
|------|------|------|
| `modelPicker` | ユーザー / 組織設定 | `/model` ピッカーの表示モデルをカスタマイズ |
| `promptCacheTtl` | ユーザー設定 | メイン会話のプロンプトキャッシュ TTL (例: 1 時間) |
| `subagentPromptCacheTtl` | ユーザー設定 | サブエージェントのキャッシュ TTL (デフォルト 5 分相当) |
| `modelPricing` | 管理設定 (managed) | 組織の契約単価・ディスカウント率をコスト表示に反映 |

プロンプトキャッシュの TTL 制御は、API キーおよび Bedrock / Vertex などのクラウドプロバイダー経由の利用者が対象である。長時間の作業ではメイン会話のキャッシュを 1 時間に延長することでキャッシュミスによる再課金を抑えられる一方、短命なサブエージェントは 5 分のままにしてキャッシュ書き込みコストを抑える、といった使い分けができる。

## 開発者への影響

### 対象

- Claude Code を利用しているすべてのユーザー (起動時間・メモリ・ダウンロードサイズの改善)
- `/loop` を活用しているユーザー (`/usage` の Loops 内訳)
- API キーや Bedrock / Vertex 経由で利用し、キャッシュコストを最適化したいユーザー
- 契約単価でコストを管理したい組織、API キー発行を許可していない組織の管理者
- 非対話モードや SDK でリモート MCP サーバーを利用しているユーザー (再接続修正)
- CI でワークロードアイデンティティフェデレーションを利用しているチーム

### 必要なアクション

以下のいずれかの方法で最新バージョンに更新できる。

```bash
# Claude Code 組み込みコマンド
claude update

# npm でのアップデート
npm update -g @anthropic-ai/claude-code

# 現在のバージョン確認
claude --version
```

新しい設定を利用する場合は、`settings.json` (組織の場合は managed settings) に追記する。

```json
{
  "promptCacheTtl": "1h",
  "modelPicker": [
    { "label": "Opus 4.6", "model": "claude-opus-4-6" },
    { "label": "Sonnet on Bedrock", "model": "us.anthropic.claude-sonnet-4-6" }
  ]
}
```

macOS で computer use を利用している場合、デスクトップや Finder の操作には Finder へのアクセス許可のダイアログ承認が新たに必要になる点に注意する。

### 移行ガイド (該当する場合)

破壊的変更はアナウンスされていない。クロスセッションメッセージングのインボックスソケットは、30 秒以内に完全な行を送信しない接続を切断するようになったため、ソケットへ投稿するスクリプトはデータの準備ができてから接続するように変更することが推奨される。

## まとめ

Claude Code v2.1.243 は、コスト管理 (Loops 内訳、契約単価反映、キャッシュ TTL 制御)、組織向け機能 (キーレスサインイン、managed マーカー、Skipped sources 表示)、パフォーマンス (起動高速化、バイナリ約 75 MB への縮小、メモリ約 40〜70 MB 削減) の 3 つの軸で大きく前進したリリースである。

リモート MCP サーバーの自動再接続や API 無応答時のタイムアウト処理など、長時間運用や自動化パイプラインでの信頼性に直結する修正も多く、SDK や CI で Claude Code を利用しているチームには特に恩恵が大きい。破壊的変更はないため、速やかなアップデートを推奨する。
