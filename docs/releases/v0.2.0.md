# Anthropic News Summary v0.2.0

*Released: 2026-03-07*

---

## English

### 🚀 What's New

This release overhauls the infographic pipeline and CI workflow: a card-grid index page with Anthropic brand colors, infographic generation integrated into the orchestrator, and a consolidated workflow file.

### 📝 Changes

#### Added
- ✨ Infographic generation integrated into the orchestrator prompt
- ✨ Infographic index generator with card grid layout (Anthropic brand colors)

#### Changed
- 🔄 Combined workflows into a single `anthropic-news-summary.yml`
- 🔄 Simplified index page to show only infographics
- 🔄 Simplified workflow structure

#### Fixed
- 🐛 Continue processing after receiving `ResultMessage`
- 🐛 Handle missing directories in workflow
- 🐛 Add git user config before commit in CI (and remove hardcoded values)
- 🐛 Add debug input and fix default days in workflow

- 🔄 ワークフローを単一の `anthropic-news-summary.yml` に統合
