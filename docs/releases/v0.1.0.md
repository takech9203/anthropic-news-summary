# Anthropic News Summary v0.1.0

*Released: 2026-03-07*

---

## English

### 🚀 What's New

Initial release of Anthropic News Summary — a Claude Agent SDK skill that collects Anthropic news and generates detailed Japanese reports.

### ✨ Features

- **Report Generation Skill**: Collects Anthropic news and generates detailed Japanese reports with the Claude Agent SDK
- **Infographic Generation**: Creates HTML infographics for reports with an Anthropic brand theme
- **GitHub Pages Deployment**: Workflow to publish generated content via GitHub Pages
- **IAM Deployment Scripts**: OIDC authentication setup scripts for CI/CD (AWS IAM role + OIDC provider)
- **CI/CD Setup Guide**: Documentation for configuring GitHub Actions with AWS credentials

### 📝 Changes

#### Added
- ✨ Initial project setup (skill definition, orchestrator, parsers)
- ✨ GitHub Pages deployment workflow
- 🛠️ IAM deployment scripts for OIDC authentication
- 📝 CI/CD setup guide and comprehensive CLAUDE.md guidelines
- 📊 Improved Mermaid diagram templates
